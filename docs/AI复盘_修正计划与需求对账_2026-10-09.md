# AI 复盘修正计划与需求对账

日期：2026-10-09。状态：已开始按模块执行；实际修改、验收与未完成项见 [模块修正与验收](AI复盘_模块修正与验收_2026-10-09.md)。本文保留原计划与 39 条需求依据，不能把计划完成条件全部视为已经通过。基线：用户指定的最新本地工作区。

## 一、固定正确目标

AI 结合完整攀爬过程、计算数据和预设提示词，输出有依据的动作分析与评价。完整过程用于判断上下文，本地时间与计算数据用于定位和核对。重点动作可以重点展开，普通动作不机械凑评语，但不能先删掉普通过程、让模型只看四类本地标签。

“本地”是用户在本地网页/App 使用复盘，不意味着本地阈值生成的固定句子能替代用户配置模型的 AI 分析。外部发送仍独立授权；本地计算、回看和资料导出可以先完成。

本轮优先解决完整动作与 AI 复盘链路。不以新模型名单、额外总结卡片、训练系统或新业务实体代替当前修复。

### 用户最新补充：这是给真实用户使用的 App

流程能简单则简单。产品交付前必须确定好默认参数、服务协议、采样和处理策略，不能把未解决的技术问题变成用户选项。用户界面不出现开发者诊断、实验档位、研究开关、预览能力或待选择的技术方案。开发阶段的比较与验证留在内部，验证未通过的能力不进入用户流程。

默认主流程为：选择视频并取色 → 上传识别、补点并确认岩点 → 开始复盘 → 查看分析、回看或导出。点击开始后，程序自动安排本地处理和已配置 AI 分析；必要的外部发送与费用授权在进入该流程时清楚完成，不再要求用户理解并依次点击“整理动作、生成解说、解析返回”等内部阶段。

设置仅用于必要的一次性配置，不暴露 API 协议、采样档位、算法版本或阈值作为普通用户选择。能检测或由适配器确定的内容自动处理；遇到不支持的配置给出具体可解决说明。失败恢复提供一个清楚的下一步，内部自动选择恢复阶段；会产生新增费用时仍明确告知并授权。

此原则覆盖下文所有实现和验收步骤：表中的对照采样、诊断、实验及技术合同仅属于开发工作，不是用户端功能。界面精简也必须验收，不能只完成分析算法。

## 二、需求对账：现行要求

以下按功能整理用户原话和已确认记录；“需验收”表示不能凭历史完成记录认定当前效果已达标。

| 编号 | 要求 | 本轮处理与验收 |
|---|---|---|
| R01 | 核心是评价分析，AI 读视频、数据和提示词后解释及评价 | 重写输入、提示词、返回及展示合同；真实完整结果验收 |
| R02 | 不再只做重要动作点评 | 移除四类筛选作为整个 AI 分析前置门槛；保留重点展开 |
| R03 | 每个有证据动作有清楚结果，证据不足不编造 | 逐段说明可确认事实、评价或具体不可判断项；避免一律空白或套话 |
| R04 | 分析需有改进价值，指出最值得调整或回看的一项 | 以具体动作及依据呈现，不恢复已删除的总结卡片；专业建议仍受证据约束 |
| R05 | 一级对象是动作事件，不是五个身体部位复制整段时间 | 一个事件含参与肢体和阶段；允许协同、调整、未成功动作 |
| R06 | 明显横/纵重心变化、重要动作可形成分段，稳定 0.5–1 秒收尾 | 默认以 0.8 秒验证，起始、变化、收尾分开；完整动作不截半 |
| R07 | 时间轴只有编号与时间，不写解说 | 时间轴与 AI 分析区独立；没有评语也能回看 |
| R08 | 高抬腿、重心调整、蹬腿、侧挂要得到关注 | 作为重点线索；不将四类当成全部可分析动作 |
| R09 | 蹬腿需屈膝快速伸直与重心同步快速变化 | 核对角度/速度/时间，慢速伸腿与噪声作反例；不宣称真实受力 |
| R10 | 侧挂按可见身体倾斜观察，角度应有依据 | 25°仅为旧工程候选阈值，需真实样本校验，不能自动当专业结论 |
| R11 | 中心点改为估算重心，不能只改名 | 保留全身质量加权二维估算；缺测留空并断线，不冒充真实重心 |
| R12 | 左原片、右分析图等宽同尺度 | 右侧岩点、配准骨架、重心和轨迹；缺测留空，拖回不显示未来轨迹 |
| R13 | 视频与时间轴同时适屏并共同全屏 | 竖屏、横屏、小窗口实测；不挤扁、不裁四肢 |
| R14 | 基础统计为视频外黑边小球，点击展开 | 不遮视频、不恢复常驻大统计块 |
| R15 | 删除总结卡片、自动总结、翻页/跳过/圆盘 | 保持删除；分析内容放视频下，不烧录长评语 |
| R16 | 逐段点击回看，慢放、循环、上一段/下一段及动作修正 | 默认完整播放与导出 0.75 倍；按原片时间定位，避免双重慢放 |
| R17 | 导出只有“复盘视频”“视频＋全部资料”，删除更多资料 | 两种内容、保留范围/速度；核对当前运行 App 与网页 |
| R18 | 全部资料含提示词、时间、身体角度、本地数据等 | 包含可用原片、复盘、帧索引、姿态、重心、证据与时间换算；可交给自己的 AI |
| R19 | 当前配置模型可使用，更换模型需要正确接口 | 服务协议和能力明确配置；不得按名称前缀猜视频字段 |
| R20 | 正确上传数据/视频并接收反馈 | 实际发送内容可核对；图片模式不得声称读了完整视频 |
| R21 | 原始返回立即保存，解析失败免费本地重试 | 保存先于解析；重启、重传、版本更新后的复用需验收 |
| R22 | 防重复收费，未完成只续未完成部分且独立确认 | 区分已成功、确定失败、结果未知；未知不自动重发；显示已有可用内容 |
| R23 | 旧返回不能因升级再次收费，不能套到新时间段 | 旧结果只读保存；新请求与免费恢复明确区分，用户明确授权新分析才允许新增请求 |
| R24 | 无效重复整片窗口不得收费解释 | 检查时序与证据，显示具体失败原因；至少两段旧门禁针对伪序列，不能把真实单动作视频误判为坏数据 |
| R25 | 费用估算/预算隐藏且默认关闭，不填价格也可用 | 开启才检查价格；保留填写值；仍独立授权费用，未知不显示零元或预算保证 |
| R26 | 配置统一在设置→AI 服务，长表单可滚动 | 不另设配置页面；账号不重复模型信息 |
| R27 | 视频准备只留取色面板，取色后上传并识别岩点 | 不恢复关联线路、分页、重复授权表单；预览/加载状态清楚 |
| R28 | 先逐点补齐、确认全部岩点，再用户开始分析 | 前置确认有效；入口显眼；分析后仍可增删点并本地重算 |
| R29 | 岩点精修支持手绘、修改轮廓、单帧放大局部识别 | 默认自由描边，缩放顺滑，候选轮廓需确认；保留小脚点核验 |
| R30 | 高清本地复盘、原片保留、不自动删除 | 常见副本 720×1280，保持原片帧率/方向/时间；不静默降清晰度 |
| R31 | 更细真实骨架采样，资源可控 | 10 FPS 基础、4 FPS 对照、重点 15/20 FPS 实验；插值不算新证据 |
| R32 | 正确锁定攀爬者，左右手腕不能频繁丢失/交换 | 十条真实视频复核，分别报告身份、腕点、覆盖、边界问题 |
| R33 | 30 秒视频本地处理尽量三分钟 | 分阶段测量；人工补点/API等待另计；失败、取消可恢复 |
| R34 | 网页做好后同步当前 App | 同源代码与资源、实际运行版本、重开恢复和导出验收；不只核对打包文件 |
| R35 | 本地抱石专用，账号并入设置 | 保持当前范围；不恢复旧定线后台，历史版本和数据保留 |
| R36 | 拍照定线成熟流程同源搬到 App | 上传原图→原图取色/调色盘→主动识别→复核补点→保存；不因复盘修改破坏 |
| R37 | 有真结果再谈训练和专业准确率 | 首批十条可复核对照；既有十二条试标/类别卡作为参考，不能当已训练模型 |
| R38 | 本地数据、照片、密钥不覆盖上传，生产另行授权 | 仅新结果另存，不改旧媒体；本轮不部署 |
| R39 | 正式用户 App，流程简单、方案确定、无开发或实验内容 | 固定经过验证的默认策略，取消实验档位和技术选择；合并重复步骤与确认，逐页核对选择和点击是否必要 |

## 三、旧要求如何处理，防止再次倒退

| 旧约定 | 现行处理 |
|---|---|
| 只给筛选出的重要动作解说 | 被完整 AI 复盘要求覆盖；保留“不要粗略凑评语”的质量诉求 |
| AI 任意决定片段时间 / 每个部位占整片 | 本地真实时间是依据；AI 可提出带证据的边界修正，校验后另存，不自由编时间 |
| 所有动作逐条写一句话 | 普通过程用于上下文，不机械补齐；有分析价值的动作明确展开 |
| 肩髋均值叫中心/重心，路线结束后才出现 | 使用估算重心及随播放累积轨迹，缺测不伪造 |
| 真人上也叠骨架、双侧标点 / 70:30 布局 | 左原片、右等宽同尺度分析图 |
| 结束自动总结、翻页圆点、小圆盘 | 已删除，不恢复 |
| 上传授权分页、关联线路、处理后删除 | 已移除；保留必要的外部 AI 独立授权和用户主动删除 |
| 未知价格不准调用、默认一元预算 | 可选计费控制覆盖；开启后才执行估价/预算约束 |
| 第三个独立资料入口、更多资料按钮 | 仅两种导出内容 |
| 百炼自动启动/失败回退、按模型名猜协议 | 当前用户配置服务与明确协议优先，旧服务仅历史兼容 |
| 首批高抬脚/交叉手及后续专业技巧研究 | 保留研究目标，不是阻塞当前完整复盘的前提；专业命名需真实独立验证 |

## 四、执行顺序与完成条件

### P0：先复现当前失败，确认实际运行版本

确认本地网页与当前 App 实际加载的资源和后端版本，解释截图为什么仍有已删除的“更多资料”和旧标题。用用户截图对应记录的非敏感诊断以及可用测试素材，保存本轮独立审计结果，不读取输出密钥或改写历史数据。

逐阶段记录：原始有效姿态数、人物身份、重心有效率、候选起止、重叠合并前后、稳定计时重置原因、最终窗口、重要筛选否决原因、实际 AI 请求内容、请求/返回/解析状态。形成可回看时间清单，明确哪一步丢掉哪个动作。

**完成条件：**每个异常大段与空分析都能定位到阶段及时间；当前记录的原因经过复现，不能仅凭代码猜测。

### P1：修正动作切分，先证明本地回看可用

将候选变化、完整动作边界、局部证据质量和专业标签分开。重心明显变化、主动肢体变化和可见姿态变化产生候选；稳定用于收尾，不能因为单个无关关节缺失就吞掉所有边界。允许局部证据质量不一致，清楚记录哪些边界是确认、哪些待核对。暂未稳定的尾段标为未完成，仍可回看其已观测过程。

保留去相机运动、区分肢体主动运动与躯干带动、防左右链交换的必要逻辑。检查重叠合并是否跨过已有可靠停留；按时间长度、关节可靠性及真实画面诊断，不靠固定均分或强制凑两个动作。

可用关节稳定判定与短缺测容忍是待验证方案，不把新阈值直接当成准确答案。对连续运动、微调、单动作、遮挡、快蹬腿、侧倾、起攀/完攀尾段分别核验。

**完成条件：**同片列出参考边界与程序边界、漏切/误切/截半；多动作样本不再只剩整片大段；真实单动作不被强行拆分；没有评语也能操作时间轴。

### P2：让 AI 处理完整过程与数据

先核实当前服务具体支持的视频协议，构建完整过程输入：支持视频时发送经确认的完整视频及对齐数据；仅支持图片时明确标为图文分析，覆盖全程抽样并加密关键窗口。若要达到完整视频输入目标，必须完成可用的视频服务适配，不能悄悄以图片代替后宣称完成。

视频使用原速与明确时间映射，保留用户要求的完整复盘上下文；计算数据包含逐帧姿态、角度、位移/速度、估算重心、岩点、动作候选、有效性及缺测。常规过程不能在本地筛选后消失。不要逐帧付费调用，也不默认对每三个事件切成相互失去上下文的独立请求。

新提示词要求：先看全程，再定位动作，区分画面事实、数据依据、分析评价和不确定项；输出具体时间与引用；解释身体配合、动作衔接、做得好的地方及有依据的改进点；不把停顿自动当缺点，不编造力量和承重。不再使用“只解说四类动作”的主提示词。

返回结构包含整次分析、动作级分析、证据、未确认项和回看/调整重点。已有本地时间可引用；边界修正必须带原片时间和证据，经过本地核验后另存。重点识别失败不阻止对其余可见过程的分析。

**完成条件：**能核对实际送出的媒体/数据/提示词与接收结果；至少一条真实视频完成经授权的端到端分析，或明确保留未验证状态。模拟返回通过只能记为工程通过。

### P3：恢复与收费链路必须可解释

先保存服务原始返回与请求信息，再解析。已有返回的整理、展示、导出、重启恢复都不重新调用。分批确有必要时，保存每批身份和结果，只续未完成批次，不能丢弃已成功内容。

界面明确显示：调用次数、已保存结果、失败发生在发送/返回/解析哪一步、本地重试是否零新增请求、继续是否是新收费请求。对网络中断后的未知结果先核对，不自动重发。不能承诺服务侧失败必然免费。

免费恢复与用户明确要求的新分析分开。历史结果保留，新证据或模型的重新分析明确列为新请求；旧返回不得偷套新事件，也不得无提示自动升级收费。

**完成条件：**成功返回后解析失败、保存失败、重启、重传、双击、部分返回、超时未知都做故障验证；免费路径新增外部调用为零。当前账单与服务异常是否可追回，需服务记录支持，不虚构退款结论。

### P4：精简页面，核对导出，再同步 App

主展示为视频、纯时间轴和下方 AI 复盘分析。内部阈值与技术诊断留在开发验收材料；用户只看到状态、可执行的恢复说明和分析结果。保留统计小球、原比例双画面、慢放、循环和动作修正。

导出仅两种内容。核对片段/整段与慢放时间映射、缺测空值、数据覆盖范围、提示词是否与当前实际分析一致。资料包不能只给过时的“重要动作解说”提示词；失败时也要能导出已有本地资料，不依赖 AI 成功。

网页和 App 使用同一份最终代码；检查当前快捷入口、运行资源、重开恢复，证明用户看到的是修正后的版本。另存新结果，保留历史媒体和返回。

**完成条件：**真实窗口中复盘、分段、恢复及两种导出跑通；截图中的旧入口消失；网页和 App 相同行为，不以“打包成功”代替运行验收。

## 五、验收证据与汇报规则

首批十条视频形成一张逐片记录：参考动作、程序动作、误合并/误切/截半、骨架误选/左右交换、AI 引用和评价问题、阶段耗时及新增调用次数。当前失败记录必须进入回归集。不能只挑最好的一条展示。

4/10 FPS 与重点 15/20 FPS 在同一片、同一岩点和同一参考标注下比较；记录真实帧数，缺测不是零、插值不是证据。更换模型前后用相同材料比较覆盖和内容质量，不能仅凭模型名称认定更好。

专业类别正式验收沿用原计划的独立样本与审核要求，尚未达标就不写“准确识别已完成”。30 秒/三分钟性能目标记录机器与阶段耗时，不静默降采样或清晰度。

每次汇报分别写：工程完成项、真实素材效果、未完成项。当前问题的完成标准是用户得到可回看的动作段和有用的 AI 复盘，而不是又多了一个版本号和几十个模拟测试。
