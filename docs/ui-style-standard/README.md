# 定线助手 UI 风格统一标准

> 状态：当前有效（Approved）
> 版本：2026.09.04
> 适用范围：桌面端、平板/窄桌面端、移动端，以及后续新增的前端页面与组件。

本目录把本轮聊天中已经确认的 UI 方向、实现提示词、效果图和机器可读约束收拢为一个可独立交接的“设计快照包”。后续设计、实现、评审和生成效果图均以此处为统一基准。

## 文件导航

- [DESIGN.md](./DESIGN.md)：视觉语言、排版、布局、组件与响应式硬规则。
- [PROMPTS.md](./PROMPTS.md)：可直接复用的总提示词、页面提示词、负面约束和验收提示词。
- [EFFECTS.md](./EFFECTS.md)：效果图目录、使用范围和已知边界。
- [design-standard.json](./design-standard.json)：供自动化工具和生成式工作流读取的结构化设计约束。
- [effects/](./effects/)：本轮确认方向下的桌面、596px、390px 和岩板比例参考图。

## 冲突处理顺序

发生描述冲突时，按以下优先级判断：

1. 本文件“最新交互决策”；
2. 本目录 `DESIGN.md`；
3. 本目录 `design-standard.json`；
4. 本目录 `PROMPTS.md`；
5. `effects/` 中的效果图。

效果图用于表达气质、层级、密度与响应式关系，不是像素级业务合同。真实数据、可用状态和交互逻辑以生产代码及产品需求为准。

## 最新交互决策

- 标准板库线路预览默认只显示当前线路岩点。
- 用户可通过“显示其他岩点”查看完整底板，选择需在刷新、切换线路和修复对比间保持。
- 标准板库线路预览不再叠加任何荧光圆点、实心点、圆环或文字徽标；线路由保留下来的真实岩点及页面信息识别。
- 该规则只限定标准板库主预览和修复对比，不禁止定线编辑器为“当前选中”等真实操作状态提供必要反馈。
- 岩板外框严格按物理尺寸 `2440:3660`（约 `2:3`）等比缩放；`11×18` 仅代表孔阵，不能作为画布长宽比。
- 当前应用品牌统一为“定线助手 / CLIMB SETTER”。

## 使用方式

开始设计或开发前，先阅读 `DESIGN.md`，再从 `PROMPTS.md` 复制“主提示词”，追加对应页面的补充提示词。完成后用“视觉验收提示词”检查 `1440×1000`、`596×800`、`390×844` 和最低 `360×800` 四种视口。

新增效果图只有在符合本目录全部硬规则时才能进入 `effects/`。旧版蓝色侧栏后台截图、木纹岩板、满板背景岩点加荧光标点的截图均属于废弃方向，不应继续引用。

## 来源与维护

本标准由根目录 `DESIGN.md`、`.impeccable/design.json`、生产设计变量、已确认效果图和本轮最新反馈整合而成。根目录文件仍保留用于当前工程运行，本目录作为可复制、可交接、带版本号的统一风格包。

最初确认方向为“方案 B：样品架”，概念生成种子为 `386d2c68`。概念图只用于追溯方向，不作为生产素材；本包效果图均优先采用项目当前真实界面和真实岩点资产。
