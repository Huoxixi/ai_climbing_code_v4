# 定线助手设计系统

## 1. 视觉方向

界面是一套成熟、任务导向的攀岩定线工具，而不是通用管理后台或营销页面。视觉北极星为“岩点样品册与技术板”：暖粉笔白负责稳定的工作环境，真实岩点负责物件感和主要色彩，中性技术板负责孔位、尺寸与线路的精确表达。

整体气质应当精确、实用、平静、有现场工具感。香蕉黄是稀缺的操作信号，不是装饰背景。视觉可借鉴成熟运动和攀岩应用的信息层级与操作效率，但不得复制品牌、商标或专有页面。

交互层级参考方向包括 TopLogger、Kilter Board、Keep 与 Stōkt：只吸收任务组织、画布优先、训练上下文和移动操作效率，不复制其品牌资产、图标或专有布局。

- 岩板始终是冷中性技术表面，不使用木色、木纹或商业岩板材质。
- 保存、错误、归档、同步等状态必须同时提供文字，不得只靠颜色表达。

## 3. 字体与排版

全站使用项目内自托管 MiSans WOFF2，声明 `font-display: swap`，并回退至 `PingFang SC`、`Microsoft YaHei`、`system-ui`、`sans-serif`。不请求外部字体服务，不修改或裁剪字体文件；项目应保留 MiSans 来源与授权说明。

| 层级 | 字号/字重 | 行高 | 用途 |
|---|---|---|---|
| 页面标题 | 桌面 `28px/600`，移动 `22px/600` | `1.35` | 页面最高层标题 |
| 区块标题 | `20px/600` | `1.35` | 样品架、主工作面 |
| 卡片标题 | `18px/600` | `1.35` | 当前岩板、最近编辑 |
| 强调正文 | `16px/500` | `1.5` | 关键值、操作上下文 |
| 正文/控件 | `14px/400–500` | `1.6` | 说明、字段、按钮 |
| 元信息/标签 | `12px/500` | `1.2–1.4` | 状态、坐标、规格 |

中文不使用负字距。数字、坐标、尺寸和统计启用等宽数字。标题依靠字号与字重形成层级，不使用营销式巨型字号，也不以大量粗体制造强调。

## 4. 布局骨架

### 桌面端

- 顶部应用栏固定为 `64px`，含品牌、横向主导航、同步状态、编辑模式和用户入口。
- 内容最大宽度 `1440px`，常规左右边距 `32px`，采用 12 列栅格。
- 总览顺序为：页面标题/主动作 → 横向岩点样品架 → `3fr / 2fr` 主辅区 → 全宽状态带。
- 定线工作台为约 `240px / 1fr / 300px` 三栏，画布是绝对视觉中心。
- 列表详情页采用列表与常驻预览；流程页采用清晰的步骤推进，不堆叠等权卡片。

### 移动端

- `860px` 以下进入移动结构；最低完整支持宽度 `360px`。
- 品牌栏 `56px`、上下文栏 `48px`、固定五入口底栏 `64px`。
- 五入口固定为：`首页 / 定线 / 板库 / 资产 / AI`。
- 岩板与岩点共享“资产”入口，通过页内二级切换区分。
- 定线页画布优先；岩点、属性、Beta 由底部抽屉承载，保存直接执行。
- 定线工具坞位于主导航上方，四项为：`岩点 / 属性 / Beta / 保存`。
- 触控区域最小 `44×44px`，页面不得产生横向溢出。

响应式只改变排列和入口，不改变信息故事：样品与上下文在前，当前任务居中，辅助信息随后。

## 5. 岩板几何合同

- 标准训练板物理外框：宽 `2440mm`、高 `3660mm`，宽高比约 `0.6667`。
- 孔阵：`11×18`；孔距：`200mm`。
- 孔阵范围：`2000×3400mm`；左右边距各 `220mm`；上下边距各 `130mm`。
- 所有全尺寸画布与缩略图只允许等比缩放，容器多余空间保留为空白。
- 禁止把 `11 / 18` 写入外框 `aspect-ratio`，禁止为填满容器而拉伸岩板。
- 孔位与岩点位置必须由同一套物理尺寸、边距、孔距坐标函数换算。

## 6. 形状、层级与组件

- 主要卡片圆角 `12px`，常规控件 `10px`，小按钮 `8px`；胶囊只用于短状态与计数。
- 普通容器使用一像素暖灰边线，不使用阴影；浮动工具坞、登录容器、技术板和真实岩点可使用克制浅阴影。
- 主按钮至少 `44px` 高、香蕉黄底、香蕉墨色文字；同一工作区只保留一个主要下一步或保存动作。
- 输入框至少 `44px` 高、白底、暖灰边线；键盘焦点使用清晰的半透明香蕉黄外环。
- 桌面活动导航使用底部 `3px` 香蕉黄短线；移动活动入口使用柔香蕉黄底。
- 岩点卡使用真实透明切图和原始不规则剪影，不裁成统一圆形或方形，不用几何占位替代可用资产。
- Element Plus 可以保留，但必须继承本标准的字体、色彩、圆角、边线、焦点和触控尺寸。
- 图标必须来自同一套线性图标，不使用 Emoji。

阴影建议：

- 浮动工具：`0 14px 34px rgba(33,31,26,.12)`。
- 技术板：桌面 `0 16px 32px rgba(43,47,51,.14)`；移动 `0 14px 30px rgba(43,47,51,.16)`。
- 岩点切图：`drop-shadow(0 9px 8px rgba(0,0,0,.26))`。

## 7. 页面模式

### 总览

顶部横向岩点样品架展示真实岩点，桌面 6–8 个，移动横向滑动。主区左侧为当前岩板和唯一“继续定线”主动作，右侧为最近编辑和规格/模板。统计压缩为信息状态带，禁止回退成四张等权统计卡墙。

### 定线工作台

桌面使用岩点样品区、技术画布、属性/Beta 检查器三栏；移动端首屏先看到完整岩板，辅助工具进入底部抽屉。保留放置、选择、旋转、缩放、删除、Beta、保存和未保存离开提醒。

### 标准板库

桌面优先使用线路列表与常驻预览；移动先展示线路列表，再进入详情与岩板预览。线路预览默认隐藏非线路岩点，用户可开启“显示其他岩点”，偏好需跨刷新、线路切换与修复对比保持。

标准板库主预览和修复对比禁止叠加额外荧光点、实心点、圆环或文字徽标。只显示线路岩点时，真实岩点图片本身就是线路表达；显示完整底板时，以不破坏画面美观的选中/层级方式区分，不能重新引入漂浮标点。

### 资产与 AI

岩点库使用图片优先的样品网格和紧凑筛选；移动上传表单默认折叠。岩板资产展示真实缩略图、状态与标签。AI 页保持“选岩板 → 设目标 → 运行 → 查看结果”四步，并明确安全边界和结果依据。

### 登录与状态页

登录界面预填默认账号，用户点击即可登录；仍需有清晰的错误、加载和不可用状态。加载、空、错误、归档和无编辑权状态全部沿用同一视觉系统。

## 8. 禁止项与验收线

禁止使用：蓝色管理后台侧栏、桦木或胶合板纹理、任何虚假材质、装饰渐变、玻璃效果、外部字体、Emoji 图标、大面积香蕉黄、等尺寸卡片墙、营销式 Hero，以及与孔位无关的漂浮线路标点。

每次新增或重构页面至少检查：

- `1440×1000`、`596×800`、`390×844`、`360×800` 四种视口；
- 桌面和移动信息优先级一致；
- 画布比例、孔位和岩点坐标未被拉伸；
- 主操作键盘可达、焦点清晰、触控尺寸达标；
- 无页面级横向溢出、空白页或 Vue 控制台异常；
- MiSans 从本地加载，失败时系统字体回退正常；
- 截图中不出现木纹、旧蓝色侧栏或标准板库额外荧光标点。
