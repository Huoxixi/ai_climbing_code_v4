# UI 设计与实现提示词

以下提示词用于后续界面生成、页面实现和视觉评审。先使用“主提示词”，再追加对应页面补充；不要只复制单个页面段落而遗漏硬约束。

## 1. 主提示词

```text
为“定线助手 / CLIMB SETTER”设计并实现一套成熟上线的攀岩定线应用界面。产品模式是 Operate：高频、任务导向、精确、实用、平静，不做营销网站，也不做通用蓝色管理后台。

视觉北极星是“岩点样品册与技术板”。使用暖粉笔白 #F7F5EF 作为环境、白色工作面、石墨黑 #1C1E21 文字、暖灰边线和稀缺的香蕉黄 #F4C430 主操作。页面主要饱和色来自项目内真实岩点透明图片。香蕉黄只用于关键动作、当前选择、活动导航和键盘焦点，不作为大面积装饰。

岩板必须是无材质暗示的中性技术画布：板面 #E8EAED、框体 #C9CDD2、孔位 #2B2F33、辅助线 #A5ABB2。禁止木纹、木色、胶合板、渐变、玻璃效果、虚假纹理、外部字体、Emoji 图标和等权卡片墙。

全站使用项目内自托管 MiSans WOFF2，font-display: swap，系统中文字体回退。正文和控件 14px，强调正文 16px，区块标题 20px，页面标题桌面 28px、移动 22px；正文 400、控件 500、标题 600，正文行高约 1.6。中文不使用负字距，数字、坐标和尺寸使用等宽数字。

桌面端使用 64px 顶栏、横向主导航、最大 1440px 内容区和 32px 页边距。860px 以下切换移动结构：56px 品牌栏、48px 上下文栏、64px 五入口底栏，入口固定为“首页 / 定线 / 板库 / 资产 / AI”。最低支持 360px，触控区域至少 44px，禁止页面级横向滚动。

所有岩板外框必须由物理尺寸计算比例。标准板宽 2440mm、高 3660mm，宽高比约 0.6667；11×18 只表示孔阵，绝不能作为外框比例。孔位和岩点使用同一物理坐标函数，画布只允许等比缩放。

先建立真实组件骨架，再填充真实业务内容；保持现有 props、events、服务、API 和数据结构。保留 Element Plus，但统一覆盖字体、颜色、边线、圆角、焦点与控件尺寸。页面必须包含加载、空、错误、归档和无权限状态。
```

## 2. 总览页补充提示词

```text
总览页先呈现页面标题和一个明确主动作，然后是横向“岩点样品架”。桌面展示 6–8 个真实岩点槽位，移动端保持 112px 左右的横向滑动样品。下方采用约 60/40 主辅布局：左侧为当前岩板的只读技术预览、岩点/Beta/难度统计和唯一“继续定线”按钮；右侧为最近编辑与岩板规格/模板。底部统计压缩成横向信息状态带，避免四张等权统计卡墙。
```

## 3. 定线工作台补充提示词

```text
定线工作台让画布成为视觉中心。桌面使用约 240px / 1fr / 300px 三栏：左侧岩点样品册，中间等比技术板，右侧按“岩板 / 岩点 / Beta”组织检查器。移动端首屏先出现完整岩板；岩点、属性、Beta 通过底部抽屉打开，保存直接执行。四项工具坞固定在五入口导航上方，前三项白底，保存项香蕉黄。保留放置、选择、旋转、缩放、删除、Beta、保存和未保存离开提醒。
```

## 4. 标准板库补充提示词

```text
标准板库桌面采用线路列表加常驻岩板预览，移动端先浏览线路列表再进入详情。线路预览默认只渲染当前线路包含的真实岩点；提供紧凑的“显示其他岩点”开关，打开后显示完整底板，并通过本地偏好跨刷新、线路切换和修复对比保持。

不要在标准板库主预览或修复对比上绘制任何额外荧光圆点、实心点、圆环、文字徽标或漂浮标记。禁止把线路标记绑定到经过旋转或缩放的岩点元素。岩板孔位保持清晰，线路由真实岩点图片和页面文字信息表达。
```

## 5. 资产、AI 与登录补充提示词

```text
岩点资产使用图片优先的样品网格，筛选器是紧凑标签或字段，归档数据独立呈现；移动端上传表单默认折叠。岩板资产展示严格等比的真实缩略图、状态和标签。AI 页面按“选岩板 → 设目标 → 运行 → 查看结果”四步推进，并明确安全边界和结果依据。登录页预填默认账号，用户点击主按钮即可登录，同时保留加载和错误反馈。
```

## 6. 负面提示词

```text
不要：蓝色管理后台侧栏；木纹、木色、胶合板或真实墙面纹理；玻璃拟态；装饰渐变；噪点背景；外部字体；Emoji；过度圆润的气泡组件；大面积阴影；营销式巨型标题；等尺寸卡片堆叠；把真实岩点替换为彩色几何块；把 11×18 当作岩板比例；拉伸岩板以填满容器；移动端长期展开侧栏；第六个底部导航入口；标准板库额外荧光点、圆环或文字标点。
```

## 7. 骨架生成提示词

```text
先只生成可确认的 UI 骨架，不填入最终业务文案和复杂数据。使用真实页面结构组件：应用外壳、桌面导航、移动顶栏、五入口底栏、页面标题、上下文栏、操作栏、筛选栏、状态条、主辅列、三栏工作台、列表详情、步骤流程、面板、字段、标签、空状态、错误状态、加载占位、底部抽屉和移动工具坞。占位必须保持最终组件尺寸和响应式行为，禁止用大块灰色矩形掩盖真实布局问题。骨架确认后再填充项目中的真实岩点、岩板、线路和操作。
```

## 8. 视觉验收提示词

```text
依据本标准审查 1440×1000、596×800、390×844 和 360×800 四种视口。逐项检查：信息层级是否清晰；主任务是否第一眼可见；MiSans 字号、字重和行高是否统一；香蕉黄是否只用于动作与选中；触控区域是否至少 44px；桌面与移动是否讲述同一信息故事；移动定线是否画布优先；五入口底栏是否正确；页面是否存在横向溢出；技术板是否严格保持 2440:3660；孔位与岩点是否共用坐标；标准板库是否默认隐藏非线路岩点且完全没有额外荧光标点；是否出现木纹、渐变、玻璃、Emoji、旧蓝色后台或等权卡片墙。输出问题清单时按阻断、明显、轻微三级排序，并给出可直接实施的修复建议。
```
