# AI 复盘：选人与骨架修正计划

日期：2026-10-06。状态：实施计划，尚未实施或完成真实视频验收。

## 目标与范围

先解决误选旁人、跨人物连接骨架、缺失手腕被补画的问题，再用用户指定的十段视频判断现有姿态模型是否够用。执行顺序为：免费修正已有显示 → 新分析锁定目标与裁剪 → 十段视频对照 → 必要时评测其他模型。

本轮计划只涉及本地视频复盘。保留左侧真人和彩色骨架／岩点、右侧线路动作图、底部动作顺序，以及原片时间、默认 0.75 倍速和现有岩点确认流程。原始视频、原始姿态、旧复盘均保留；修订结果和视频独立保存。写计划不代表授权执行真实记录修订、新增云请求或生产部署。

用户随后明确右侧线路动作图只高亮当前四肢所在的岩点：其余点为中性轮廓，离开即取消高亮；移除历史用点填色、连接线、累计动作编号和“已触及”统计。无当前有效记录时留空，不沿用最后一次用点。该显示规则已于 2026-10-06 修改本地渲染代码，并用构造视频验证；已有真实视频尚未重新生成，选人和骨架质量修复仍属于后续计划。

## 当前代码依据

- `backend/core/climb_replay.py` 的 `_pose_frame` 每帧按面积、置信度选取一个人物，并统一写入 `track_id=0`；后续 `_choose_track` 不能据此证明是同一个人。
- 同文件 `build_pose_render_timeline` 主要按采样间隔和关节置信度插值，没有检查人物身份、关节突跳或肢体链交换；只有一端有效时仍延续坐标。
- `backend/core/replay_action_trajectory.py` 已有采样缺口、链长变化、突跳和左右整链交换检查，可作为统一质量判断的基础，但不能用这些检查代替真实的人物身份确认。
- 已有独立付费启动门禁及复用 `pose_samples` 的本地重算路径，应扩展复用；`replay_pose_comparison.py` 只提供部分关节对照能力，仍需补充人工真值、人物匹配和误差统计。

## 第一步：免费修正现有记录

1. 基于保存的原始采样建立独立修订层，记录每个采样的目标确认状态、每个关节的有效状态、断段原因和人工修订。保留原始坐标与置信度，不把旧 `track_id=0` 当作身份凭据。
2. 优先修正用户指出的错人片段。能结合保存画面确认的，屏蔽旁人骨架；证据不足的显示“未确认”，提供按时间段确认／排除的入口。无法恢复目标人物的姿态时留空。
3. 取消跨人物、突跳、疑似左右链交换、采样缺口的骨架连接。手腕缺失时隐藏该点及依赖该点的连线，不从邻帧复制、不根据岩点补点。
4. 修订草稿逐项保存，用户点击“确认修订并本地分析”后，统一重算受影响的动作、用点关系和统计，生成独立修订视频。草稿和失败期间保留上一版可用结果。
5. 原片或必要画面已经不可用时，仍可做保守断段和屏蔽；明确哪些片段无法核实，不宣称恢复了缺失手腕或确认了人物。

交付：修订预览、独立修订结果／视频，以及屏蔽、断段、留空的时间清单。验收：新增姿态和百炼请求均为零，原始记录不被覆盖；修订后的动作统计不能继续使用已排除的错误骨架。

## 第二步：新分析前锁定攀爬者

用户流程扩展为：上传 → 本地准备 → 补齐并确认全部岩点、框选并确认攀爬者 → 单独授权开始付费分析。岩点确认和选人均不启动付费请求。

1. 在可辨认的原片帧上框选攀爬者，保存选人帧、目标框和选择版本。允许换帧和重新框选；付费启动必须同时满足岩点确认和目标确认。
2. 本地跟踪目标，使用位置、躯干尺度、外观和连续性等证据匹配；不再按“画面最大的人”逐帧选取。区分已确认、暂时遮挡和未确认状态。
3. 跟丢或多个候选无法区分时停止接受姿态证据，显示“未确认”，不自动切到旁人。只有重新建立可靠匹配或用户重新确认后才继续；失联区间保留断段。
4. 围绕目标做动态裁剪，预留伸手、伸脚和快速移动余量，受原片边界约束。裁剪范围不确定或肢体可能出框时先扩框；仍无法确认时留空，不静默回退到全画面选最大人物。
5. 保存每帧裁剪、缩放和填充变换，将返回关键点还原到原片坐标，再进行墙面配准、岩点关系计算和显示。输出记录绑定目标身份及连续片段编号。
6. 分析授权绑定当前目标选择和岩点版本；修改任一项后旧授权不能用于新分析。重试、重启和历史任务均不得绕过服务端门禁。

交付：桌面和手机选人界面、目标跟踪与裁剪、坐标还原、授权版本校验。验收：多人交叉、遮挡和目标出画时不切人；伸展肢体在原片可见时应尽量保留在裁剪中；框选和确认过程云请求为零。

## 第三步：统一骨架有效性与平滑规则

建立页面、基础视频、动作片段导出、轨迹分析和统计共同使用的判断结果，避免只修显示却继续生成错误动作。

| 情况 | 处理 |
| --- | --- |
| 相邻采样身份已确认、同一连续片段、关节两端有效且变化合理 | 允许仅用于显示的短间隔平滑 |
| 人物身份变化或未确认 | 整段断开，不计算跨段动作 |
| 单个关节缺失、低置信或明显突跳 | 该关节及相关连线留空，不用单端坐标延续 |
| 疑似左右整链交换 | 相关肢体断段，保留原始左右标签等待核实 |
| 正常交叉手、交叉脚 | 不能仅按画面左右顺序认定交换 |
| 遮挡、长采样缺口或墙面配准失败 | 不跨缺口推断运动；配准失败的样本不参与岩点关系判断 |

阈值按时间差、人体尺度和镜头运动确定，先用构造用例与标注样本校准，再固定评测。平滑产物与实测样本分开保存；插值不能增加手腕可用率，也不能作为接触、停留或动作判断的新证据。

## 第四步：十段视频验证手腕与选人

先确认用户指定十段视频的清单、文件是否可用、目标人物和现有采样是否可复用；当前计划未读取或核实这些真实素材。

1. 固定相同模型版本、原片采样时间和目标人物，对比 A：完整画面加目标匹配，B：目标裁剪加同样匹配。已有无目标匹配结果单列为历史基线，避免把选人改善误算为模型改善。
2. 人工标注目标身份、左右手腕位置与可见性。覆盖旁人靠近、多人交叉、背身、伸手、快速移动、交叉手和遮挡。可见但模型漏检计入失败；真实不可见的手腕单独统计。
3. 在十段中按场景预先固定调参与验收划分；调参后冻结规则，留出视频不再用来调阈值。每段分别报告，避免整体均值掩盖某一段失效。
4. 统计以下指标，所有识别指标只按原始采样计算：

| 指标 | 口径 |
| --- | --- |
| 误选旁人 | 错误接受的采样数、独立切换事件数和持续时间；“未确认”单列 |
| 目标覆盖率 | 正确确认目标的采样数／目标可见采样数，防止全部隐藏却获得零误选 |
| 左／右手腕可用率 | 人工标为可见的目标手腕中，身份和左右标签正确、置信度合格且误差达标的比例 |
| 手腕位置误差 | 还原到原片后的像素误差、按人工参考人体尺度归一化的误差，报告中位数和 P95 |
| 左右交换与突跳 | 经人工核实的事件数，单列正常交叉手误报 |
| 裁剪完整性 | 原片可见的手腕／脚踝被裁出画面的次数 |
| 请求、费用与耗时 | 实际请求数、重试数、费用记录和处理时长，不假设对照复用会免费 |

建议预设验收目标：留出集误选旁人 0 次、跨错误片段连接 0 次；可见目标覆盖率至少 95%；左右手腕可用率各至少 90%；有效手腕 P95 误差不超过参考躯干长度的 10%。这些是待验证的工程目标，不是已有准确率承诺；开始评测前固定口径。达不到时同时报告原因和失败片段，不只调整阈值追求通过。

若裁剪后仍不达标，再在相同目标、采样、人工真值和坐标体系下评测候选姿态模型。先核实候选模型的运行环境、许可、资源与调用成本，再按手腕准确率、目标覆盖率、错误接受、延迟和费用决定是否更换；本计划不提前指定新模型。

交付：十段视频逐段对照表、失败片段清单、标注说明与模型选择结论。

## 验证与执行边界

- 后端构造测试：旁人更大、多人交叉、跟丢重入、缺失手腕、单端有效、瞬间突跳、左右整链交换与正常交叉手；同时验证裁剪坐标还原和旧记录兼容。
- 前端与视频验证：桌面／手机选人、重新框选、重启恢复、未确认提示；页面与各类导出在同一时间显示相同有效骨架，动作和统计不使用屏蔽区间。
- 成本验证：模拟接口调用计数证明上传、选人、岩点编辑、历史显示修订、本地重算与导出不调用姿态或百炼；真实新增请求必须通过独立付费授权。
- 真实对照先列请求数和预计费用：若有 N 个采样，双分支最多先按 2N 次基础姿态请求规划，可复用的合格历史响应另行扣除，重试单独计入。授权应明确视频、分支、请求预算和重试上限，预算耗尽即停止，不自动扩展至其他模型。
- 所有结果另存；不删除、覆盖或上传 `.local/` 数据和密钥，不执行生产部署。

完成条件：已有记录可免费保守修订，新分析能锁定目标，骨架与动作统一断段，十段视频形成可复核对照，模型是否更换有明确证据。新增付费评测未获授权时，交付已完成的本地修复和待执行评测清单，不把模拟通过写成真实质量通过。
