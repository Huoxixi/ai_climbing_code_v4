# 岩壁孔阵识别与连续展开：技术调研与试验路线

## 结论摘要

当前瓶颈不是“缺少更强的圆检测器”，而是三个相互耦合的问题：候选孔的真假判断、候选点的整数行列编号、以及从规则板坐标到照片坐标的连续映射。继续用“检测候选点 → 选最高分两行两列 → 单向外推”的串行方案，会把早期误检放大为整墙错网格。

下一轮最值得验证的是一个**联合、可回退、保留不确定性**的方案：

1. 先在现有照片内估计镜头畸变影响并限定墙面有效区域；
2. 用高召回候选器保留所有可能孔位，再用专门的孔/螺钉/污渍/阴影分类器给外观概率；
3. 同时生成多个格点假设，用局部邻域、整数行列、全局间距和连续形变共同打分，而不是先认定一个骨架；
4. 用“全局投影变换 + 平滑局部残差”或按真实板面分片的连续网格拟合照片中的孔阵；
5. 只把有图像证据的点标为“识别孔”，遮挡位置始终标为“推断孔”；
6. 用同一个坐标函数逐点变换岩点中心和轮廓，禁止最近孔吸附；
7. 行列数和毫米尺寸由可见边界、孔阵整数范围及板材规格联合确认；证据不足时输出“未确认”，不猜固定值。

这一路线的核心不是换掉 Discorpy，而是把 Discorpy 降级为候选生成或局部基线，把最终决策交给“外观证据 + 格点拓扑 + 连续几何”的联合优化。

## 1. 问题的正确建模

设规则岩板上的孔为整数坐标 \((i,j)\)，照片中的像素位置为 \(p=(x,y)\)。需要估计：

- 未知行列范围 \([i_{min},i_{max}]\times[j_{min},j_{max}]\)；
- 从板坐标到照片坐标的连续函数 \(F(i,j)=(x,y)\)；
- 每个图像候选点 \(q_k\) 是真实孔、螺钉、污渍、岩点阴影或其他背景的概率；
- 每个真实孔候选对应哪个整数格点，或者是否为离群点；
- 哪些格点只是由邻域推断而来，并没有直接图像证据。

可把目标写成以下联合代价的加权和：

\[
E = \sum_k \rho(\lVert q_k-F(i_k,j_k)\rVert/\sigma_k)
    - \alpha\sum_k \log P_k(\text{hole})
    + \lambda_s E_{smooth}(F)
    + \lambda_g E_{grid}
    + \lambda_b E_{boundary}.
\]

其中，\(\rho\) 应使用 Huber、Cauchy 或类似鲁棒损失；\(E_{smooth}\) 约束相邻单元的尺度、方向及二阶变化；\(E_{grid}\) 阻止重复编号、跳格和单元翻折；\(E_{boundary}\) 只在墙面边界或真实板材规格已确认时启用。这个表达清楚地区分了“看起来像孔”和“放进网格后合理”两类证据。

### 必须保留的输出层级

| 输出类型 | 含义 | 可否参与最终误差统计 | 建议显示 |
|---|---|---:|---|
| observed | 有明确图像中心证据且通过联合一致性检查 | 是 | 实心圆 |
| inferred | 由已确认邻域和连续模型推断，没有直接图像证据 | 否，单独统计 | 空心圆/虚线 |
| rejected | 候选存在，但被判为污渍、螺钉、阴影或拓扑离群点 | 否 | 默认隐藏，可调试查看 |
| ambiguous | 多个格点解释接近，无法可靠编号 | 否 | 警告色 |

“推断孔”不能反过来作为下一轮拟合的等权观测，否则系统会用自己的预测证明自己正确。

## 2. 推荐的主技术路线

### 2.1 现有照片的几何预处理

第一步应尽量拆开镜头畸变、透视变化和墙面真实弯折。OpenCV 的相机模型明确区分径向与切向畸变，径向畸变会让越靠近画面边缘的直线弯曲。[^1] 但目前不新增标定照片，因此不能把“已完成相机标定”作为前提。

建议：

- 先检查三张照片的 EXIF、分辨率和镜头信息是否一致，但不读取或输出任何敏感元数据；
- 如果已有可信的同设备标定参数，可以直接复用；没有则不得假称完成了去畸变；
- 若照片来自相同设备和镜头档位，可尝试“每张照片独立单应性 + 三张照片共享低阶径向畸变参数”的联合估计，并用成块留出验证；
- 若设备信息不一致，则把每张照片的全局投影和低阶平滑残差分别估计，并明确这些残差混合了镜头与墙面因素；
- 路线2、路线3先独立求解。只有两张图都获得可靠网格后，跨图对应才作为额外复核证据。

如果岩壁确实由多个不同朝向的板面组成，单个全局单应性在物理上不成立。此时应沿真实板缝分片，每个板面先拟合单应性，再在公共边界施加连续约束。如果只是镜头畸变或轻微非平面误差，则可采用全局单应性加平滑局部残差。

### 2.2 孔候选：高召回生成，专门分类

候选生成阶段不需要追求高精度。可以并行合并：

- 多尺度 LoG/DoG 暗斑响应；
- 局部对比度和径向对称性；
- 椭圆边缘及内部明暗分布；
- 经粗透视校正后的模板相关；
- 现有 Discorpy 候选。

随后使用一个小型中心热图网络或“候选裁块分类器”判断 `hole / screw / stain / hold-shadow / other`。CenterNet 将对象表示为中心点并预测中心热图，形式上比大框检测更贴合“小而密集的孔中心”任务。[^3] 前景孔相对整张图极少，Focal Loss 的目的正是降低大量简单背景负样本对训练的支配，并聚焦困难负样本。[^4]

数据策略比网络大小更重要：

- 先标路线2、路线3中的真实孔中心和四类困难负样本；
- 特别标注现有照片中的文字笔画、告示牌边缘、岩点螺钉、黑墙粉尘、划痕和岩点阴影；
- 使用现有算法的高分误检做 hard-negative mining；
- 训练/验证必须按照片或大块墙面区域切分，不能随机拆分相邻小裁块，否则同一纹理泄漏会造成虚高指标；
- 输出校准后的概率和中心位置不确定度，而不仅是二值结果。

CVAT 支持点、椭圆、多边形、掩膜以及遮挡属性，适合建立这种中心点与困难负样本集。[^5] 目前只有三张照片，且路线1暂停使用，因此深度模型极易记住照片纹理。更合适的定位是：先把冻结的 DINOv2 特征或小型裁块分类器作为候选重排器，而不是声称已经训练出可泛化的孔检测模型。DINOv2 官方模型卡说明其特征可直接接简单线性层作为下游分类器。[^6] 验证只能按大块空间区域进行，所得结论仅适用于现有照片，不能外推到新岩墙。

### 2.3 格点发现：局部拓扑优先，保留多个假设

`calib-targets-rs` 是本次调研中最值得借鉴的工程实现。它不是岩壁孔检测器，但其核心做法非常接近当前缺口：先以 Delaunay 三角剖分建立局部邻接，再做轴向单元检查；局部邻域验证能在中等透视和径向畸变下渐进退化，还支持遮挡把网格拆成多个连通分量时分别返回。[^7]

建议借鉴其思想，而不是直接把墙面孔当棋盘角点调用：

1. 对高召回候选做 Delaunay 邻接；
2. 从每个高置信候选的短边邻域中生成两组近似正交的局部基向量；
3. 对尺度比、夹角、四边形闭合误差和外观置信度进行局部投票；
4. 同时保留前 K 个格点假设；
5. 用鲁棒全局模型初始化编号，再用局部平滑模型精化；
6. 对冲突编号、单元翻折、异常跳格和孤立点施加硬约束或大惩罚。

频域方法可用于估计孔距和主方向，但不宜直接输出孔位。LISA 从功率谱高响应中识别晶格，并报告对缺失粒子具有鲁棒性，这使其适合作为“尺度/方向提议器”；它面向规则或叠加晶格，不负责处理本项目的强透视、语义误检和局部板面弯折。[^8]

初始全局模型建议用 MAGSAC++ 或 OpenCV 的 USAC 路线替代普通 RANSAC。MAGSAC++不依赖单一硬内点阈值，并结合从局部到全局的 Progressive NAPSAC 采样；论文在多个真实几何估计数据集上报告了更少失败和更高精度。[^9] 但它只负责鲁棒拟合，不会自动解决整数格点编号。

### 2.4 连续形变：同一个函数服务孔线、图像和岩点

推荐比较三种模型，而不是直接认定 TPS：

| 模型 | 适用情况 | 优点 | 主要风险 |
|---|---|---|---|
| 单应性 | 现有照片可近似为单一平面投影 | 参数少、稳定、易留出验证 | 无法解释真实板面折角或局部弯曲 |
| 全局单应性 + B-spline/TPS 残差 | 整体透视为主，叠加缓慢局部变化 | 连续、能自然生成弯曲孔线 | 控制点错误会产生局部拉扯或翻折 |
| 分片单应性/分片仿射网格 | 多块平面、真实板缝清楚 | 贴近物理结构，局部可控 | 需要板缝拓扑；导数可能在缝处不连续 |

scikit-image 已提供 TPS 和分片仿射估计及图像 `warp`；其 TPS 示例明确说明 TPS 可从少量对应点建立任意位置的非线性坐标变换。[^10] SciPy 的 `RBFInterpolator(kernel='thin_plate_spline')` 还支持平滑参数和仅使用邻近控制点，可用于快速原型。[^11]

实现时应定义**板坐标到照片坐标**的正向函数 \(F(u,v)\)，然后为展开图每个输出像素查询源图坐标并重采样。孔线不是单独检测或拟合的对象，而是对固定 \(u\) 或固定 \(v\) 的坐标曲线 \(F(u,t)\)、\(F(t,v)\) 采样所得。因此，线可以倾斜或轻微弯曲，同时严格穿过同一网格模型。

岩点中心和轮廓的处理必须一致：

- 岩点中心的照片坐标通过同一逆映射转换到板坐标；
- 轮廓的每一个顶点或密集采样点通过同一映射转换；
- 不做最近孔吸附；
- 不只变换中心再平移原轮廓；
- 记录原始轮廓、变换后轮廓和变换版本，便于复核。

必须检查每个输出网格单元的有向面积/Jacobian，出现负值或接近零即说明形变翻折，应拒绝结果。TPS 的平滑参数应通过**成块留出**选择，而不是只做逐点留一；逐点留一无法暴露整个遮挡区由错误外推造成的漂移。

APAP（Moving DLT）通过空间加权的局部单应性处理单一全局投影模型不充分的情况，可作为“全局投影 + 局部偏差”的研究参考。[^12] 但其原任务是图像拼接，目标函数不是规则孔阵和可逆板坐标，因此不建议直接移植为最终展开器。

### 2.5 行列数和实际尺寸的确认

仅凭没有边界的内部周期点阵，绝对行列起止和毫米尺度在数学上不可辨识。在不新增照片的前提下，只能使用现有材料中的以下证据：

- 看清墙面/板材的四周边界，并确认边界到首末孔的规格边距；
- 看清板缝且已知每块板的孔排布和物理尺寸；
- 已有规格资料中明确记录的孔距、板宽高或两点间实测距离；
- 现有照片中已经出现、且尺寸可核实的标尺或已知构件。

因此输出应是：

- `grid_extent_status = confirmed | ambiguous | unknown`；
- 已观测整数范围；
- 候选完整范围及其备选解释；
- 采用的规格名称、孔距、边距和来源；
- 毫米尺度的证据和置信度。

不满足确认条件时，即使视觉上能补成规则网格，也不能宣称得到了真实整墙行列数或实际尺寸。

## 3. 双图配准与线检测应放在什么位置

### 双图配准

LoFTR 的设计目标包括低纹理和重复纹理场景，使用全局上下文建立由粗到细的密集对应。[^13] RoMa 则输出像素稠密变换和匹配置信度，并针对视角、光照和纹理变化做了鲁棒性设计；官方代码还允许匹配指定关键点。[^14] 它们值得用于路线2、路线3的第二轮对照，但应遵守以下限制：

- 先裁到共同墙面并屏蔽告示牌、人物和大岩点；
- 先各自完成可靠的单图格点编号；
- 只比较同一物理墙面区域；
- 使用网格一致性检查匹配，不让匹配结果直接生成编号；
- 重复孔阵天然存在多解，低置信或相邻整周期错配必须拒绝。

若需要轻量方案，可对照 Tiny RoMa。若采用稀疏匹配，LightGlue 支持 SIFT、ALIKED、DISK 等多种特征；其官方仓库提醒 SuperPoint 预训练权重有不同且更严格的许可证，因此工程选型需单独审计。[^15]

### 线检测

SOLD2 面向遮挡下的线段检测和描述，DeepLSD 可重建比传统 LSD 更多且精度较高的线段。[^16][^17] 但照片里的“孔行/孔列”通常不是实际强边缘，直接用线检测器会优先找到文字、板缝、岩点边缘和告示牌。因此：

- DeepLSD/SOLD2 只用于墙面边界、板缝、直线畸变诊断或跨图结构辅助；
- 孔辅助线必须从已编号的孔阵模型生成；
- 不把检测出的自然图像线段当作孔行孔列。

## 4. 只有三张现有照片时的范围与限制

本轮试验不要求或依赖任何新增图像。全部训练、拟合和验证材料都来自现有三张照片；路线1继续暂停，因此主要算法测试仍使用路线2和路线3。

这会带来三个必须公开的限制：

- 不能独立完成标准相机内参标定，只能复用已有可信参数，或在规则孔阵约束下估计低阶畸变影响；
- 只有两张活跃测试照片，不足以证明学习模型对新岩墙、新光照或新相机具有泛化能力；
- 如果现有照片未显示墙面边界、板缝或已知尺度物，完整行列范围和毫米尺寸可能只能保持 `ambiguous` 或 `unknown`。

因此近期目标应是“把现有路线2、路线3可靠展开并建立可复核的失败边界”，而不是宣称形成了通用自动识别能力。

| [TILT](https://people.eecs.berkeley.edu/~yima/matrix-rank/tilt.html) | 利用规则纹理的低秩性同时做整流和稀疏遮挡分离 | 强遮挡、两个不同规则结构叠加或局部非同一变形时会失败；旧 MATLAB 原型较重 [^21] |
| [LISA](https://arxiv.org/abs/1901.02520) | 用频谱识别晶格尺度和方向，对缺失粒子做全局估计 | 不负责语义误检、透视编号和局部连续变形 |
| [APAP](https://openaccess.thecvf.com/content_cvpr_2013/html/Zaragoza_As-Projective-As-Possible_Image_Stitching_2013_CVPR_paper.html) | 全局投影模型与局部偏差的组合方式 | 为拼接设计，缺少整数格点、可逆性和尺寸约束 |
| OpenCV `findCirclesGrid` | 干净圆点标定板的快速基线 | 需要已知 patternSize，并依赖周围留白；与真实岩墙污染、遮挡和未知行列不匹配 [^22] |

## 6. 三组建议实验

### 实验 A：不训练模型的“拓扑优先”基线

目标是确认现有候选里是否已经包含足够真实孔，只是分组失败。

1. 路线2、路线3分别限定墙面 ROI，并按可获得的已有参数或受约束模型处理几何畸变；
2. 合并现有暗孔候选、LoG/DoG 和椭圆候选；
3. Delaunay 邻接生成局部四边形/轴向基；
4. 保留前 20 个格点假设，用外观分数、闭合误差、邻边尺度变化和覆盖范围综合排序；
5. 用 MAGSAC++ 初始化全局单应性，再做带鲁棒损失的平滑残差拟合；
6. 输出 observed/inferred/rejected/ambiguous 四层可视化。

通过条件：整墙范围内不出现明显错行、错列和文字/螺钉入网；未覆盖区域可以拒绝，不要求强行补满。

### 实验 B：小型专用孔分类器

目标是验证语义外观是否能把候选纯度提升到格点求解可用水平。

1. 给路线2、路线3的所有候选裁块标五类；
2. 用冻结通用特征 + 小分类头作为低成本基线；
3. 再训练中心热图模型，并用困难负样本和 Focal Loss；
4. 每次错误分析按来源统计：文字、污渍、螺钉、岩点边缘、阴影、粉尘/划痕；
5. 按照片或空间大块做留出，报告 precision-recall 曲线和中心误差。

通过条件：在不牺牲关键区域真实孔召回的前提下，进入格点求解的误候选下降到不会形成竞争性假网格的程度。不要只用总体准确率。

### 实验 C：现有照片上的几何模型消融

目标是确定单应性、平滑残差和分片模型中，哪一种能以最少自由度解释现有照片。

1. 路线2、路线3分别使用同一批人工确认孔位和同一批空间留出块；
2. 依次比较单应性、单应性 + 低阶径向项、单应性 + TPS/B-spline 残差，以及有明确板缝时的分片单应性；
3. 报告训练点误差、随机点留出误差、连续矩形块留出误差和最小 Jacobian；
4. 选择满足无翻折条件下自由度最低的模型，不以训练点拟合最小作为标准；
5. 用选定模型同步变换路线2、路线3的岩点中心和轮廓，检查其在网格单元中的相对位置；
6. 两张照片各自通过后，再用 RoMa/LoFTR 做已有照片之间的辅助一致性检查。

若所有模型都只能在人工锚点附近成立，应停止整墙外推，并把结果限定为局部展开。

## 7. 验收设计

### 检测验收

- 真实孔 precision、recall 和 PR-AUC；
- 按墙色、亮度、遮挡程度和负样本类型分层；
- 中心误差以当地预测孔距归一化；
- inferred 不计入 detected true positive；
- 空间大块留出，避免相邻纹理泄漏。

### 拓扑验收

- 已观测孔的整数编号正确率；
- 错行、错列、重复编号、跳格和方向翻转数；
- 每个连通网格分量的覆盖范围；
- 备选假设与最佳假设的分数间隔；
- 证据不足时能否正确拒绝外推。

### 展开验收

- 观测孔到规则格点的归一化误差分布；
- 随机点留出和连续矩形块留出两套结果；
- 单元面积/Jacobian 的最小值，必须无翻折；
- 横纵邻孔距的均值、标准差及空间热图；
- 边界和板缝附近单独统计。

### 岩点同步变换验收

- 用人工选取的岩点轮廓特征点做前向—逆向往返误差；
- 检查岩点在对应四孔单元内的归一化重心坐标是否保持；
- 中心与轮廓必须调用同一变换版本；
- 禁止用“是否靠近某个孔”作为成功标准。

## 8. 推荐的决策门

1. **先判几何类型**：在现有照片的初始几何校正后，路线2/3是否可由单一平面解释；若否，是否能看清真实板缝并分片。
2. **再判候选上限**：人工检查现有候选集合的真实孔召回。如果大量真孔根本没有成为候选，先做检测；如果真孔大多在候选中，先做联合格点求解。
3. **不追求一次全自动**：允许用户确认少量分散锚点，但锚点必须覆盖全墙和不同板面，不能只集中在左上角。
4. **先通过路线2**：路线2外观相对容易，可用于验证联合格点与连续映射；路线3用于验证黑墙和困难负样本泛化。
5. **最后才做双图融合**：单图编号通过后，用 RoMa/LoFTR 对共同墙面做交叉检查；跨图证据不能掩盖单图失败。
6. **保持离线**：在检测、拓扑、展开和岩点同步四项门禁全部通过前，不接入正式应用、不改写历史数据。

## 9. 最可能成功的近期组合

若只能选择一条投入路线，建议采用：

> 现有照片的墙面 ROI 与受约束几何校正 → 高召回多源候选 → 五类孔外观重排 → Delaunay 局部格点假设 → MAGSAC++ 全局初始化 → 带防翻折约束的单应性 + 平滑残差 → observed/inferred 分层 → 同一逆映射变换岩点中心和轮廓 → 空间块留出验收。

这条组合与当前已确认的“对应关系正确时局部展开有效”直接衔接，也正面处理了目前失败的两个源头：候选污染和骨架误选。它不依赖预设 20×30，不要求孔行列严格为直线，也不会把岩点吸附到最近孔。
