## 导出

播放器“导出”提供两条入口：本地数据与提示词可直接下载；生成视频后可下载完整包。完整包含 `replay.mp4` 双画面复盘、可用时的 `source.mp4` 分析原片、`analysis.json`、`pose_samples.csv`、`joint_angles.csv`、`prompt_constraints.txt`、App 当前解说约束、`vision.json`、`manifest.json` 及使用说明。可用原片还导出最多 48 张均匀抽样证据图及原片时间索引，供只接收图片的模型使用。

JSON 保存完整姿态、置信度、墙面配准、动作事件、岩点、接触候选、基础统计和估算重心轨迹。CSV 逐帧输出 17 个关节；角度表含双侧肘、膝、髋夹角和躯干相对画面竖直方向倾角。角度为二维像素平面投影，坐标为原画面归一化坐标，不等于三维角度或真实受力。低置信／缺测的坐标不输出为有效值，缺少帧编号时留空。角速度只在连续短间隔观测中计算。

数据始终保留原片时间轴；片段与慢放包明确保存 `analysis_time_seconds = source_start_seconds + replay_time_seconds * speed`，起止按渲染计划的实际帧边界记录。原片已含上传裁切时，`source.mp4` 使用分析片段时间，历史裁切偏移见已有证据来源字段。数据包不触发模型、重新识别或历史记录改写；权限与结果版本仍校验。ZIP 使用可落盘的临时缓冲和分块发送，避免整段视频常驻内存；不包含设置密钥、账号信息或本地文件路径。

## 接口修复

原写法把 `gpt-6` 前缀当作视频能力，加入未经协议支持的 `video_url`，并固定读取 Chat Completions 返回。官方 [GPT-6 Sol 文档](https://developers.openai.com/api/docs/models/gpt-6-sol) 明确其图片输入支持、视频输入不支持。因此当前入口保持模型名称不变，发送带时间锚点的证据画面、关节角度、重要动作测量和证据质量，不再伪称上传整段视频。

“设置 → AI 服务 → 动作评语”新增接口选择。自动模式：官方 `api.openai.com` 使用 Responses，其他兼容网关使用 Chat Completions；完整 `/responses` 或 `/chat/completions` 地址可推断显式协议并去除末尾端点，避免重复拼接。用户可明确选择服务商支持的类型，失败不自动切换协议。

Responses 使用 `input_text`／`input_image`、`max_output_tokens`、JSON 输出约束及 `store=false`；读取 `output[].content[].output_text`，将用量映射为现有计量字段。Chat Completions 保留兼容消息，GPT-5／GPT-6 等推理模型使用 `max_completion_tokens`，其他模型沿用 `max_tokens`。两者都返回并保存原始服务响应，空输出或 incomplete 返回不触发再次付费请求。HTTP 400／401／403／404／413／429 等提供不含原始服务报错体的安全原因。

网络超时／连接中断保留未确认请求收据，阻止直接重复发送；需先核对服务请求记录。已返回内容在本地解析前保存，同账号重复上传及旧视觉返回保护继续保留。不因模型、接口、预算、展示或分析筛选变更重发已成功的返回。
