# 动作评语失败保存与付费恢复（2026-10-09）

用户反馈确认费用后仍显示“处理未完成”。只读检查桌面记录发现一条失败任务，有一次服务成功返回的用量记录。记录没有保存原始返回内容，无法从现有文件恢复当时的评语；用量记录不等于服务账单，未确认实际扣款金额。本轮没有调用真实视觉服务。

原流程在模型返回后继续生成视频，直到视频完成才保存评语结果。视频生成或返回内容解析失败时，已经拿到的内容会丢失，普通重试可能重新付费。

本次修复：

- 先检查本地媒体与动作时间计划，再调用视觉服务。
- 每批返回先记录用量并保存返回内容，再解析和校验。重试绑定服务配置、动作事实和实际证据图片摘要，复用相同返回；部分失败只请求尚未返回的批次。无效 JSON 也保留，重试不自动重新付费获取同批内容。
- 完整评语另存恢复检查点，后续视频失败时提供“使用已保存评语生成视频”。该操作不需要云端授权，不依赖当前服务配置，不调用视觉模型，也不产生新接口用量。
- 恢复检查点绑定原始证据、复盘媒体及动作修正；依据改变后不能继续复用。原始返回不通过公开记录接口输出。
- 失败时区别服务请求、返回内容处理和本地视频生成。确认费用区显示请求数量和账单说明；旧记录返回成功但未保存时明确提示再次生成可能再次计费。失败后清除页面勾选，需重新确认新请求。

保留原片、旧视频、已有结果与历史用量，不改写本次失败的历史数据，不重发真实图片，不修改账户密钥或生产服务。
