# 抱石简化流程：本地实现与验收

2026-09-05。本记录接续并替代旧验收文档中关于临时 harness、逐点确认、强制孔位确认的说明。本次未部署、未推送、未操作 Supabase。

## 使用入口

在项目目录运行 `./start-photo-local.ps1`，打开 <http://127.0.0.1:4176/#/photo-routes>。
启动前检查 4176 和 8004，端口占用时报错；启动后检查实际服务就绪，不切换端口。旧 `/e2e/harness.html` 跳转至固定入口。

页面已接入真实 App：选择照片 → 确认上传 → 选择一种颜色 → 后台提取 → 按需增删 → 保存线路。默认保留目标颜色结果；至少一个岩点即可保存，定线者、起终点、孔位都不构成保存门槛。已保存线路详情支持名称、难度、定线者、起终点、岩点标签及自由备注；类型可写入备注。

## 视觉复核

使用 DeepSeek 官方图片输入模型 `deepseek-v4-flash-vision-exp`，请求仅在服务端发出。发送编号全图和编号局部裁剪，校验候选 ID 与全图归一化坐标。疑似遗漏经本地 MobileSAM 验证后才可能加入；精确轮廓来自本地分割。

服务端读取环境变量 `PHOTO_ROUTE_VISION_KEY` 或 `DEEPSEEK_API_KEY`。也可在被 Git 忽略的 `.local/photo-vision.env` 配置同名变量并重启本地服务。不会自动加载生产 `.env`。

没有有效密钥、超时、异常 JSON 或越界建议时，界面明确显示“AI 复核暂不可用”，保留本地结果并允许保存或重试。

官方协议来源：<https://api-docs.deepseek.com/guides/vision/>，本轮已核对。
