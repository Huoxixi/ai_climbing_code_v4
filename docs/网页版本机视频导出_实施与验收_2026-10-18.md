# 网页版本机视频导出：实施与验收

2026-10-18，用户要求：“视频导出的功能必须在网页里加上”。本次已加入本机视频导出，免账号和原有本机历史保持。

## 使用

1. 打开 [本机网页版](http://127.0.0.1:4317/browser-replay.html)，完成一次骨架分析，或从“我的记录”打开已有分析。
2. 使用画面下方“真人 / 骨架”选择导出组合：两项都开为真人叠加骨架；只开骨架为深色背景纯骨架；只开真人则为已分析片段的原画面。
3. 点击“导出视频”。界面显示实际帧进度，完成后自动下载；浏览器未自动下载时点击“下载已生成的视频”。可取消和重试。

导出只覆盖已分析时间段，时间轴从0开始，**无声音**，不包含未分析的片段。优先本机AVC/H.264 MP4，编码能力不满足时使用VP9/VP8 WebM。固定30fps，最长边不超过1920像素，不放大小视频。编码视频文件限制96MiB，不承诺浏览器总内存只有96MiB。尚未完成跨手机/浏览器/显卡矩阵及完整90秒性能验收；缺少WebCodecs或编码器时明确提示改用新版电脑版Chrome/Edge，没有服务器兜底或隐式上传。

## 实现和保护

`frontend/src/browser-replay/videoExport.js` 在当前设备解码本机视频、绘制每帧及编码封装。固定依赖 `mediabunny@1.61.6`，通过动态本地构建块只在导出时载入；不请求远程CDN。MPL-2.0许可原文、未修改组件的精确版本源码下载地址和仓库地址随 `/browser-models/NOTICE.txt` 及 `mediabunny-LICENSE.txt` 提供。

`replayDrawing.js` 是浏览器回放与导出的共同骨架绘图函数，复用现有圆头几何、坐标、关节资格和缺失留空规则。导出从保存结果读姿态，不重新运行模型，不改原始姿态或本机历史。纯骨架不绘制原画面，不冒充桌面版无人真实墙面背景，也不等同于完整隐私匿名保证。

每帧明确时间戳和持续时间，等待编码背压，不要求按视频时长实时录屏。非0起点片段正确重置时间戳；浮点边界使用容差，避免0.9秒误多生成尾帧。取消/错误/完成均释放私有视频解码元素、源Blob地址、画布及编码器。页面卸载取消任务；处理期间不允许改视频、改画面模式或新建/删除当前记录。取消不会清掉原分析，可重试。切换画面、重新分析、换视频及开始新导出均清理旧导出结果，防止错误下载上一次不同画面；卸载撤销下载Blob地址。

`BrowserReplay.vue` 新增导出面板，保留自动下载和显式重下载入口；`BrowserPortal.vue` 只更新已支持导出的说明。原账号数据库、浏览器历史结构、原片、模型字节和真实桌面App不改，生产未部署。当前4317本机服务已提供新构建，启动仍为 `./start-browser-local.ps1 -Build`。

24项针对性检查通过，独立网页和普通前端构建均成功：

| 组合 | 数量 | 证据 |
| --- | ---: | --- |
| 导出专项浏览器 | 3 | 实际MP4两画面、非0起点时间范围、画面像素、可播放和可拖动、取消/重试、缺WebCodecs提示、强制无AVC的WebM回退、切换模式/取消不留旧下载 |
| 最终打包真实流程 | 1 | 原模型识别1.2秒真实短片、12/12采样、自动本机保存、实际真人/纯骨架视频导出与解码、缓存复用和历史回放；无账号/媒体上传API/外部请求 |
| 骨架数学/缓存/真实源模型/圆形头 | 15 | 原始133点同帧数值一致性、真实短片、缓存损坏恢复、停止释放、几何与资格 |
| 免账号历史界面 | 2 | 旧记录原位读取、原子配额失败保护、复合标识删除、桌面/手机布局 |
| 静态服务 | 3 | 无账号/媒体API、静态页面与安装包Range下载 |

专项使用本机短片与原生帧姿态构造0.2–1.1秒的保存记录，便于独立控制截段与画面，不用该构造记录证明跟踪精度。真人与纯骨架MP4均为720×1280、0.9秒；浏览器可解码/拖动，画面整体像素均值约108.24与25.90，纯骨架可见黄色骨架像素。**独立FFmpeg完整解码**两份MP4及回退WebM，均27帧/0.900秒。最终包另用实际逐帧模型结果导出1.2秒真实短片，两画面都通过，不只验证构造数据。

最近源模型同帧133点与原生平均差0.0353516px、最大0.7836276px保持；这不是独立真实精度证明。当前只有CPU推理路径和本机编码器实测，不泛化为所有设备/高分辨率/长视频性能。

一次最终包长流程检查中，两个视频均导出成功，但刷新缓存断言出现4次模型请求而非2次。加入初次/导出后缓存条目、存储额度及缓存警告诊断后复验通过，没有稳定复现；本次未修改模型缓存实现，不能将此记为已定位修复。浏览器缓存仍可能被拒绝或清理，既有内存回退与页面提示保持。最终带诊断的整条实际识别、两种导出、缓存复用和历史回放检查通过。

专项证据与私有导出文件在 `.tmp/browser-video-export-20261018/`，最终包真实视频位于 `.tmp/browser-local-replay-20261017/compiled-person.mp4`、`compiled-skeleton.mp4` 及报告；它们不进入发布产物。实际浏览器和独立FFmpeg检查都在本机，不上传这些素材。

运行 `npm run test:browser-export` 复验导出专项，需要现有私有 `CLIMB_BROWSER_NATIVE_FIXTURES`；可由 `CLIMB_BROWSER_FFMPEG` 指定独立解码器。`npm run test:browser-compiled` 需要运行中的最终包地址 `CLIMB_BROWSER_COMPILED_URL`，并会真实识别后导出两种视频。测试使用隔离浏览器上下文，没有向用户当前浏览器写验收记录。
