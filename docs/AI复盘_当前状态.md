## 用户确认的页面行为

2026-10-06 已在本地实现成本前置流程：“上传 → 本地识别岩点 → 用户补点／删点并确认全部岩点 → 单独点击开始付费分析”。上传及“重试本地准备”只整理视频、识别岩点，停在 `awaiting_hold_review`，不初始化姿态 SDK、不发出姿态请求，也不启动原视频成功后清理倒计时。局部“轮廓正确，确认补入”和“确认全部岩点”均不会启动付费分析。全部确认绑定当前岩点与参考帧版本，新增、删点或撤销后失效，过期确认在服务端拒绝。独立付费启动接口要求全部确认及有效的新处理授权；姿态分析使用已确认的岩点快照，不重新识别覆盖人工修改。旧排队任务和失败重试也不能绕过门禁，等待确认的草稿在重启后继续等待。

2026-10-06 用户进一步明确先逐个补点、全部补完再确认和本地分析。分析完成后仍可补点、删除所选岩点和撤销补点；每次操作只保存到独立的岩点草稿，不重算接触、不生成视频、不刷新上一版动作结果。全部补完后点击“确认全部岩点并本地分析”，才复用保存的 `pose_samples`，统一重算一次接触关系并生成修订复盘，不新增阿里云姿态请求。草稿期间保留上一版结果和视频，重启后可继续修改；分析失败保留草稿和上一版复盘，可再次确认重试。需要重新获取人体姿态时，可展开“完整重新分析（再次付费）”，重新确认全部岩点并单独勾选授权后启动；新的结果不再播放旧修订视频。“核对动作名称”的百炼调用仍独立计量。本次只修改本地代码，不代表生产已上线或真实云端费用验收。

2026-10-06 恢复岩点“补点与确认”的直接入口：分析完成后在播放器上方常显“补充岩点”，不再放在整个动作区和“更多”之后。进入原片框选漏点，轮廓预览返回后，在同一区域直接显示“轮廓正确，确认补入”和“重新框选”，确认按钮进入可见范围并获得键盘焦点。单点轮廓明确确认后只保存到草稿，可继续逐个补点；全部岩点确认后才统一本地分析。原有查看／撤销补点和返回复盘保留。动作修正与补点历史仍可折叠，不能因此隐藏补点入口及当次确认按钮。

保留左侧真人及彩色骨架／岩点、右侧线路动作图和底部动作顺序。整段页面播放用原速基础文件加 0.75 播放率；统计和动作时间始终使用原片时钟，不能双重减速。动作说明在视频外，主展示只保留肢体、短动作名及起止秒数，修正默认折叠。

完整攀爬结束后，模糊基础画面并依次展示线路总岩点／去重使用点／使用率、其他统计及整体节奏，然后自动收为小圆盘。手动点击圆盘重开后持续显示，主动收起返回圆盘。同一记录再次播放或拖动不重复自动演示，切换记录按该记录已展示状态处理。未观测区间不计为停留。导出完整视频默认 0.75，独立保存，不烧录当前动作说明和页面总结、不覆盖基础视频及历史产物。
