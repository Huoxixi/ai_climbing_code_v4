# AI 复盘当前状态、证据与限制

更新时间：2026-10-01。本文是当前功能入口；旧样片、模板演示和实施过程已移入 [历史索引](archive/pre-release-20261001/README.md)，旧方案不替代 2026-09-30 用户最终确认的设计。

## 用户确认的页面行为

保留左侧真人及彩色骨架／岩点、右侧线路动作图和底部动作顺序。整段页面播放用原速基础文件加 0.75 播放率；统计和动作时间始终使用原片时钟，不能双重减速。动作说明在视频外，主展示只保留肢体、短动作名及起止秒数，修正默认折叠。

完整攀爬结束后，模糊基础画面并依次展示线路总岩点／去重使用点／使用率、其他统计及整体节奏，然后自动收为小圆盘。手动点击圆盘重开后持续显示，主动收起返回圆盘。同一记录再次播放或拖动不重复自动演示，切换记录按该记录已展示状态处理。未观测区间不计为停留。导出完整视频默认 0.75，独立保存，不烧录当前动作说明和页面总结、不覆盖基础视频及历史产物。

## 实现与兼容

统一播放器为 `frontend/src/components/UnifiedReplayPlayer.vue`；动作显示、总结和时钟分别在 ReplayActionNotes、ReplayPageSummary 及 replaySummaryState 中。后端 replay_action 系列负责原片分组、轨迹、局部核对、人工修正、撤销及导出。旧记录兼容读取，旧模板和报告在“更多”中保留；修正重算关系与统计，失效导出不能作为当前结果播放。打开记录不自动新增分析或云请求。

照片与视频共用 `replay_resources` 的高资源互斥锁；兼容旧照片锁文件和名称，避免叠加高内存任务。十二色选择共用前端 routeColors；照片默认识别链仍是专项模型原生掩膜 → 轮廓内分色 → 用户复核 → 个人线路库，不接入未通过门禁的离线模型实验。

## 限制与未完成事项

- 二维骨架只能描述可见轨迹，不能确认抓握、踩实、受力或专业技术。遮挡、采样缺口、链交换和突跳标记不足或冲突；人工确认条件保留。
- 没有独立授权留出集及两名审核者，不能声称 95% 准确率、识别改善或专业动作自动确认。新云端路径尚未用独立真实样本重新验收。
- 抱石知识库 24 个单元保留专业审核、真实视频验证和自动使用缺口；检索命中不等于建议可用。原审核状态未改。
- 生产磁盘已完成缓存及旧发布清理，当前保留三个版本、约 9.2 GiB 可用。当前线上仍为 rc28，新发布及线上验收待完成，不能把本地整理当作已上线。
- 商业公开能力的权利链、供应商合同、SBOM／NOTICE 等限制按原 [PRD](AI攀岩复盘_PRD与使用权审核_2026-09-20.md) 保留，邀请制发布不等于质量或商业验收。
