# 五项优化：第二轮实施与验收

2026-10-11。已修改程序并同步本地 App 0.1.14。优先修选人与姿态输入，其次统一显示/接触有效性；岩点小候选完成进一步目视核验，短触规则没有提前放宽。整体真实识别精度仍未通过，不关闭原专项。

## 1. 自动选人与人物上下文

`replay_pose_rtmw.py` 的多人初选现在比较最多三个人物的同帧姿态候选，保留肩髋可见性、举臂与抬脚依据，并要求连续候选支持。续跟不再永远继承第一次锁定：已确认路线的冲突需持续三次才重新核查；纯骨架中更显著主体的抬脚过程也参与持续比较。多人过程最多每 0.5 秒重新比较一次，最多三个候选，不增加用户选人操作。姿态与颜色直方图仍是启发式，不宣称身份已被专业 ReID 模型验证；两个真实攀爬者同时出现仍可能首次选错。

人物框突增或腕踝跨组异常只触发核查。重试在当前原帧使用两个不同身体上下文，检查两组候选肩髋/腕踝位置一致性与人体链结构。正确新端点不再被强制要求靠近旧错误端点；不交换左右标签、不拉回历史位置、不做速度滤波、不吸附岩点。框突增同时检查与前一实际检测框的面积变化，避免因检测框正常留白而持续重试。每次最多两次追加姿态推理。

已采纳这个受限双上下文复核作为默认，原始观测、候选及接受/拒绝原因同时保留。133 点的 `location_support` 分开记录同帧上下文一致支持与只有有限/分数支持；仍不把饱和响应解释成正确概率。`pose_revision.status` 暂保留既有实验来源标记，是否默认采纳以本报告和构造参数为准。

## 2. 关节及配准统一

新增 `replay_observation_validity.py`，共用 0.5 的有限关节资格、源点/参考点有效范围、变换稳定性、至少 12 个内点和最多 3 个参考原图像素误差。接触通过 `align_pose_record` 使用同一资格；骨架、轨迹、脚形及导出通过 `registered_points` 使用同一资格。前端同样拒绝映射到画面外的点、非有限诊断及不稳定变换。

墙面配准的最终误差在除以缩放比例后判断，不再拿缩小图上的 3.5 像素与原图上的 3 像素混用。误差保留原精度，单位明确为参考原图像素，避免先四舍五入跨过边界。失败原因传入接触追踪记录。

固定复现的 3.2 像素/0.9 分数和 0 像素/0.2 分数现在同时停止端点显示及接触支持；3 像素/0.9 和 0 像素/0.9 有效对照仍支持。该修复消除机制冲突，但不能修好 09 的原始关节错位，也不能用提高分数门槛解释 2432 个饱和腕踝响应。

## 4. 接触规则

保留 0.4 秒持续使用、现有接触部位和脚形。只统一上游资格，不将短触门槛改成零。09 264 的右手与指尖上游错位尚在，不能通过取消停留制造右手错误亮点。

冻结 `backend/experiments/frozen-quality-20261011.json`：02 的选人失败和三个腕踝粗区域、09 的可见正接触锚点与错点负锚点、08 的小候选/重复身份。脚形仍是简单脚踝分叉，不增加独立脚趾，也不作为必然踩点证明。

冻结发生在本轮开发检查之后，供后续回归使用，不能作为本轮独立留出验收。标注基于既有诊断锚点与助手目视检查，待独立人工复核。`score_replay_quality_anchors.py` 强制校验源文件摘要，只输出粗区域/岩点框的关键点落点一致性。18 个粗检查前轮 7 个一致、本轮 15 个一致，不是关节 PCK、接触精确率/召回率或整体准确率；腕点落入/未落入可见岩点框也不等于真实抓握，不能把这些计数换算为接触成绩。完整短碰、经过、遮挡和持续使用的时间区间正负集仍需补齐。
