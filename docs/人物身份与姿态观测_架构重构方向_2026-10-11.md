# 人物身份与姿态观测：架构重构方向

2026-10-11。用户最新优先级：先解决 02 的首次选人与 09 的右手错位，再修改接触规则；不能依靠不断叠加小规则维系系统。

本文件保留批准时的架构依据。随后已部分实现并同步 App：02 首次选人修复，09 右手定位仍未通过，替代权重未采纳。当前状态以[实施与真实验收](人物身份与姿态观测_实施与真实验收_2026-10-11.md)为准，不再以本文的方案阶段作为运行现状。

## 1. 问题在于两个核心假设

| 问题 | 当前机制及已证实的失败 | 应替换的假设 |
| --- | --- | --- |
| 02 首次选错人物 | `replay_pose_rtmw.py` 用局部候选评分选框，随后围绕单个 `_previous_box` 续跟；第二轮加入连续竞争与重查，源帧 180 仍选旁人，186 才恢复 | 不能把“当前最像攀爬者的候选”直接当作整段的目标身份。身份关联和目标选择必须分开 |
| 09 右手错位 | 同源 135 个姿态帧的点位在第二轮完全未变，264 帧右手仍错误；已复核的这 135 帧没有配准拒绝冲突 | 有限、高分、人体结构大致合理，都不能证明手腕落在真实右手位置。必须验证观测模型及左右肢体证据 |

三段材料的 2432 个腕踝响应被截成 1，不能通过再提高分数门槛获得有效区分。现代码已保留原始响应，但原始响应也不是正确概率；需要先核对推理解码与响应语义，再以标注校准定位风险。

此前双上下文复核改善了 02 的部分腕踝粗区域，属于已观察到的局部收益；同一权重在不同裁剪中的错误可能相关，因此“一致”只能作为输入稳定性证据，不能作为定位真值。下一轮停止继续扩大这类纠偏分支。

保留已经必要的基础设施：原始输出与来源、同源文件摘要、坐标体系、配准单位、显示与接触共用资格、旧可视数据只读派生。它们解决可追溯性和口径冲突，不能代替新识别架构。

## 2. 02：重建整段人物身份与目标选择

推荐使用本地复盘的离线优势，将“单框在线锁定”替换为“多人轨迹建立 → 整段目标判断 → 回写该目标的原帧观测”。

1. **先给所有候选建立轨迹。** 每个有效检测保存原帧 ID、检测框、身体可见性、外观特征和关联候选。持续维护多个 `track_id`，处理交叉、遮挡、消失和再出现；关联依靠外观、运动与相机变化的共同证据，不能只保留被选中的一个人。检测框异常与轨迹身份异常分开记录，避免大框同时吞入另一人。外观表示只用于当前视频中的关联，不建立跨用户身份库。
2. **再判断哪条轨迹属于本次复盘。** 比较整段中的攀爬过程、身体可见覆盖、进入/离开过程及画面主体关系。有用户确认的路线时可增加路线关系；纯骨架流程必须能够独立运行。先用可解释的整段轨迹比较形成对照基线；如果两个真实攀爬者无法区分，应标记目标歧义，而不是不断添加举手高度、面积和固定帧数例外。要训练目标选择模型，训练单位应是带目标标签的片段/轨迹，而不是单帧“举手是否像攀爬”。
3. **用后续证据回查起始帧。** 完整视频可用双向关联和整段一致性确定目标，将身份沿其轨迹映射回前面的真实检测。02 的验收包括 180 帧最终结果的正确身份，不能再以“186 恢复”当作首次选人已修复。回写只能选择该原帧存在的目标观测，不能把后续身体位置复制过去。分析中的临时身份与最终身份要分开，避免临时误选进入导出或接触累计。

关联层可隔离对照 [BoT-SORT](https://github.com/NirAharon/BoT-SORT) 的运动、外观和相机运动补偿机制。其官方能力是维持多人身份；“哪位是用户要复盘的人”仍需本项目的目标选择层。这一职责区分是方案设计推论，不是该仓库承诺的功能。不能只接入新跟踪器并继续沿用当前首选锁定。

若视频中同时存在两个同样完整、同样显著的真实攀爬过程，又没有路线或拍摄目标信息，画面本身可能不足以确定用户意图。新架构必须能表达这一状态，并在确有歧义时提供最少的目标确认；不能宣称所有多人素材都能自动唯一选中。

主要实现边界：从 `replay_pose_rtmw.py` 提取人物观测和关联流程；在独立轨迹模块保存多人状态；目标选择模块只读取轨迹证据，输出目标轨迹/片段与歧义状态。姿态提供者接收明确的原帧人物上下文，不再同时承担人物身份锁定。缓存绑定源文件、检测/关联/选择版本，原始观测缓存与最终目标派生缓存分离。

## 3. 09：重建身体、手部和不确定性观测

推荐把“一个 wholebody 模型输出一套可信点”替换为“可对照的身体观测 + 具有独立图像依据的手部观测 + 明确的不确定状态”。新接口先统一证据语义，模型选择由真实对照决定。

1. **先定位最早错误层。** 固定 09 的同一原帧和经核对的目标框，分别复现当前接入与同权重上游预处理/解码，检查缩放、裁剪变换、左右索引和输出响应。再做固定人物框的模型对照，以及完整自动选人流程的对照。这样能够区分接入误差、身体上下文错误和权重本身的领域误差；不能只看到最终手腕错，就把一切归因于模型不够大。
2. **用不同架构验证模型误差。** RTMW 保留为基线；优先隔离评测 [ViTPose / ViTPose++](https://github.com/ViTAE-Transformer/ViTPose) 的相同身体关节语义，具体 wholebody 配置和可部署权重单独核对。若固定框仍不可靠，再比较 [RTMO](https://arxiv.org/abs/2312.07526) 的单阶段多人身体姿态路径，以验证人物裁剪依赖；RTMO 身体点输出不能冒充 133 点手脚细部。两者都是候选，通用榜单不能证明它们已经修好本项目。
3. **把手腕与手部区域分开。** 身体骨架的腕点用于手臂链，真实手部区域用于后续接触观察，二者不能互相冒充。独立手部观测应在身体/前臂上下文及整个人物范围内发现手候选，不能仅围绕已经错位的旧腕点裁剪，也不能以岩点位置作为手部定位答案。左右归属依据同一人的肩—肘—腕链、局部图像和相邻原帧共同确定；无法确定时保留归属歧义。若现有模型对攀岩的背身、交叉手臂和遮挡持续失败，再采集这些类型的标注进行领域微调。

此前已经做过 RTMW 与 InstantHMR 本地对照：[2026-10-06 初测报告](骨架候选本地下载与初测报告_2026-10-06.md)显示 InstantHMR 在部分伸臂、高抬腿和背身画面明显偏移。该报告不是独立定量精度验收，因此不直接恢复 InstantHMR 作为默认，也不把三维输出当作右手位置已可靠。

建议的新观测契约如下；这是拟议接口，不代表已写入程序：

| 数据 | 含义和消费方式 |
| --- | --- |
| `source_frame_id / track_id / model_revision / crop_transform` | 点来自哪一原帧、哪位人物、哪套权重与坐标变换；所有派生结果可追溯 |
| `joint_candidates / raw_response` | 原始关节候选和未裁成概率的响应，允许保留多解与缺测 |
| `visibility / side_status / location_uncertainty` | 可见、遮挡或不可判断；左右归属是否明确；经标注校准的定位风险。未校准时明确记未知 |
| `hand_region_observation` | 实际图像支持的手部区域及归属，和身体腕点分开；没有局部观测就没有该证据 |
| `observed / inferred` | 原帧图像观测与时序推断严格区分；后者不能单独证明接触 |

时间信息用于检查身份和肢体连续性、保留多个解释、调度原帧核查，不通过平滑把错点变成观测。身体结构核验也只提供约束，不能凭肢体长度直接生成“正确手”。若要输出推断轨迹，应在显示和数据里标明，并与接触证据分开。共享有效性层消费该契约，显示、轨迹、接触和导出从同一结果派生。

## 4. 实现顺序与退出旧机制

| 顺序 | 可审查交付 | 替代范围 |
| --- | --- | --- |
| 1 | 02 的多人原帧观测、轨迹及整段目标结果；旧新方案同源逐帧对照 | 替代首帧面积/举手评分加单个 `_previous_box` 锁定；新轨迹关联通过后删除原连续竞争、面积例外和重选分支 |
| 2 | 09 固定框的上游复现与不同架构对照；逐关节误差、左右归属和可见性结果 | 先据证据修正接入或更换观测提供者；独立观测通过后退出当前双裁剪一致即接受的纠偏逻辑 |
| 3 | 两部分接入统一版本化证据契约，全流程重放和原帧叠图 | 保留坐标/配准基础设施；旧格式通过适配读取，不修改历史原始数据 |
| 4 | 在可靠手脚位置上分别评测短碰触与持续使用 | 此前保持现有持续使用规则，随后共同评测真实正负时间区间、邻点竞争和尺度 |

不先扩展抽帧、不继续增加举手/抬脚阈值、不用速度限制拉回快速动作、不交换左右标签来凑结果、不把手吸附到岩点、不将 0.4 秒改为 0。新观测提供者不能演变成大量模型投票再加例外；对照的目的在于确定有证据的最终结构与模型，常规计算预算与困难窗口追加预算分别测量。

采用阶段替换而非立即删除旧实现：新旧模块在隔离实验中并行输出；验证有效后切换默认并移除被替代规则。不是永久叠加更多在线分支。原始数据、共用坐标资格和兼容读取不因规则退出而删除。

## 5. 真实验收与当前状态

1. **02 的验收对象是身份。** 固定兼容版源文件及摘要，对首次可判断段、180 帧、恢复段、人物交叉和遮挡段核对目标轨迹。分别记录首次错误、身份切换、检测缺失、目标歧义和可判断正例覆盖；最终应在 180 帧输出正确人的原帧身体观测。只停止输出或延后分析起点不算通过。
2. **09 的验收对象是关节位置与左右语义。** 对 264 帧及相邻动作窗标注真正的左右腕/肘、手部可见区域和遮挡状态。原有岩点矩形正负锚点只能用于回归，不能当作腕点真值。评测定位误差分布、左右误归属、错误接受和正确可见点覆盖；对不同像素分辨率使用预先冻结的归一化尺度。264 的右手必须在原帧叠图中贴合真实右肢体，同时保留其他正确关节及真实快速动作。
3. **两条失败素材是开发集。** 第二轮冻结锚点发生在开发之后，不能宣称独立留出。此前 2026-10-06 候选初测也已看过首批十段，包括先前计划的 05/06/07/10；这些只能作为本轮未调参的扩展回归，不能再称从未观察过的全新留出。定量验收需要按人物/视频分离、独立复核的新参考，开发与验收标签来源明确。微调数据、校准数据和最终验收数据须分开。
4. **验收先冻结，再选模型。** 在候选运行前固定素材、标签定义、误差容忍尺度、覆盖和误接受的采纳标准，并报告计算/内存开销。两个关键失败通过仍不足以证明整体精度；既有正确高抬腿、背身、交叉动作和快速动作必须共同复测。工程测试只证明接口和流程，不能替代识别结果。

本轮已完成：代码架构核查、既有候选实验复核、官方方案查证，以及上述替换边界和验收设计。未开展新模型推理、标注、微调或真实验收，未改接触规则、运行程序或 App。下一次实施从第 1 项的“多人轨迹与整段目标选择”开始；09 的固定框模型误差实验是紧随其后的第二个交付。
