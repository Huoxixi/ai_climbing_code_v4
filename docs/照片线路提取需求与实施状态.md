# 抱石墙照片线路提取与数字复刻

版本：V1.0；需求确认日期：2026-09-03。

实施接续入口：[三阶段压缩计划](照片线路执行计划.md)、[最新识别验证记录](照片线路识别续接验证记录.md)。完整需求保持本文不变。

**V1.1 用户新增功能**：保留墙面、去除其他线路，新增“净化墙面＋目标线路”模式。详见[背景净化补充需求与原型](照片线路背景净化补充需求.md)。下文“原图仅作对照”的规则现扩展为：原图继续保留对照，另生成独立修补背景，纯色模式仍可用；允许合成被岩点遮住的墙面外观，不生成目标岩点的不可见纹理。

## 产品目标与已确认范围

从一张包含多条彩色线路的抱石墙实拍图中，点击一个目标岩点，同色初选、人工修正后，保存可再次编辑的数字线路。保留实拍颜色、轮廓、纹理、相对位置和相对大小，不提供真实尺寸或三维还原。

- 手机和电脑均可上传、选线、精修、保存，并跨设备继续自动草稿。
- 面向单个平面墙段，允许大型突出造型；造型与其上的岩点独立编辑并保留前后层级。
- 每次提取一条；同一原图可反复提取其他线路，线路之间互不影响。
- 目标对象须完整可见、可辨认。无多图拼接、补拍合并、人物遮挡补全或不可见纹理生成。
- 新增独立照片线路库，使用自由比例坐标，不吸附网格，不进入现有岩板完整性判定和 AI 流程。
- 不连接实体硬件、不编辑动作序列、不预测难度、不识别文字标签、不增加分享和批量导出。
- 图片仅在项目服务器或本机处理，不发送外部模型服务。允许预先下载模型用于本地推理。

现有岩点录入是单岩点白底去除及轮廓提取，不是文字 OCR，不能直接证明整墙照片可用。照片线路是新的资产类型，不能强行复用要求网格坐标与类型的 `Hold` / `BoardAsset` 合同。

## 用户流程

1. 在照片线路库选择“从照片创建线路”。手机提供拍照/相册；电脑提供文件上传。JPEG、PNG、WebP，上限 20 MB / 4000 万像素；先读文件头检查再解码，处理 EXIF 方向。原图保持不变，提供预览、裁剪、旋转和缩放。
2. 尝试自动拉正平面墙，提供前后预览。不以突出造型边缘推定墙面；证据不足时明确提示，可手动标记四角、提供区域宽高比，或保留原视角。不会凭照片报告毫米尺寸或墙面倾角。
3. 点击目标岩点，同色初选。在原图叠加对象轮廓、编号、选中状态和数量。尽量排除标牌、贴纸、人物、孔洞，保留镁粉和反光覆盖的岩点主体。颜色不等于线路归属，不推断起终点。
4. 人工补选/移除，可添加异色公共脚点及造型。支持画笔补擦、拆分/合并、移动/旋转/等比例缩放、叠放顺序、撤销/重做。手机明确区分画布平移和对象编辑，可放大精修。
5. 在原图对照与干净背景实拍抠图视图间切换。造型与其上岩点独立保存，只表示可见区域；移动上层对象不会自动补出下层纹理。
6. 填写名称、颜色，可选原始难度标注、备注、多个起点和终点。难度不强制转 Font。未命名可存草稿；名称非空、至少一个有效对象且用户确认后可标记完成。
7. 保存后重开继续编辑，或复用原图提取下一条线路。

## 照片线路库与持久化

列表显示缩略图、名称、颜色、状态和更新时间；可名称搜索、颜色/状态筛选、重命名、归档、恢复。默认干净背景复刻，原图仅用于对照。

数据能力：

| 对象 | 保存内容 |
|---|---|
| 来源照片 | 不变原图、宽高、方向 |
| 处理任务 | 状态、进度、错误、结果引用 |
| 照片线路 | 名称、颜色、原始难度、备注、状态、来源、独立裁剪与校正、编辑版本、对象列表 |
| 线路对象 | 稳定 ID、岩点/造型、蒙版/轮廓、抠图、自由比例坐标、相对尺寸、旋转、层级、起终点 |

- 同一来源照片可共享引用，各线路的变换、蒙版和布局独立，不覆盖其他线路。
- 提取的岩点随线路保存，不自动加入公共岩点库，不要求臆测 Jug 等攀岩类型。
- 停止编辑约两秒自动保存；展示保存中、已保存、保存失败。
- 刷新、重新登录、服务重启后可恢复已保存内容和已完成识别结果。
- 沿用现有账号、共享数据及单人编辑权，不新增私有空间或多人实时协作。
- 未获得编辑权不写入；失去编辑权保留当前页面修改，重新获得后可保存。
- 请求携带版本，服务器拒绝旧版本覆盖；冲突时保留客户端修改并明确提示。
- 原图及提取素材长期保留；归档是软归档，不物理删除。
- 新接口覆盖上传、开始识别、查询、取消、草稿/完成保存、列表、详情、归档、恢复。旧接口保持兼容。

## 本地识别、错误与性能

后台任务运行识别，不长时间占用普通请求。常见图片首次结果目标为 1–2 分钟；超过 3 分钟结束为超时，保留输入和已有草稿，允许取消或重试。不得将失败报告为成功。

| 情况 | 行为 |
|---|---|
| 同色线路混入 | 人工删除，不声称自动理解归属 |
| 镁粉、阴影、反光 | 尽量保留完整主体，可补擦 |
| 造型和岩点合并 | 可拆分并设层级 |
| 目标遮挡、截断 | 换图或改选完整可提取的线路，不补全 |
| 拉正无可靠线索 | 人工校正或跳过 |
| 没有候选 | 重新点选、圈选或换图，不保存空的完成线路 |
| 网络或保存失败 | 显示未保存，重连重试，离开提示 |
| 编辑版本冲突 | 阻止静默覆盖，保留待提交内容 |

## 验收与实施门槛

首批样本：工作区 `抱石路线1.jpg` 黄色线路；`抱石路线2.jpg` 蓝色线路。蓝色造型与其上岩点独立标注。测试前需人工确认对象清单及可见轮廓，不仅按颜色判断是否完整。

2026-09-03 补充确认：第二张中央造型中部的灰蓝色小岩点属于目标蓝线，需作为独立对象提取与编辑；第二张验收清单共十个对象。用户对归属的确认不等同于对算法轮廓的验收。

- 目标对象召回率 ≥ 90%，候选中正确对象占比 ≥ 90%。拆分、合并、轮廓缺损独立记录；一个合并区域不得按多个独立对象算通过。
- 不应大面积残留背景、切掉主体或把标牌当岩点。熟悉操作的用户通常能在结果返回后 2–3 分钟修正并保存。
- 手机与电脑均可完成全部步骤；保存重开保持颜色、轮廓、位置、大小、层级；跨设备草稿可继续；复用原图后两条线路互不影响。
- 服务重启数据仍存在；旧岩点库、网格岩板、标准线路及 AI 回归通过；确认无照片外传。
- 本地样本通过不等于生产硬件耗时通过，也不等于所有真实墙面达到相同质量。

**实施顺序：先本地识别可行性验证，再接入完整编辑流程。** 如果不能达到质量/耗时，报告测量及需要调整的条件后再讨论硬件或范围；不得擅自外传照片、降低指标或把实验原型当成已验收功能。
