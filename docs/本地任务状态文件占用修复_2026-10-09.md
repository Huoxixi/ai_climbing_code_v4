# 本地任务状态文件占用修复

2026-10-09 用户报告“分析未完成 / 分析任务意外停止，请稍后重试”。当前桌面数据的最新失败记录包含 `worker_failed`；安全诊断为 `PermissionError`，调用链 `_run → _execute → update → _atomic_json`，失败点是替换任务状态文件。该次失败发生在“检查视频”状态写入时，早于视频整理和岩点、骨架识别。不能据此判断所有历史失败都属于同一原因，也不能确认具体占用进程。

旧保存逻辑只尝试一次原子替换。Windows 读取器或扫描器短暂持有不允许删除共享的文件句柄时，替换被拒绝，任务被标记为意外停止。

修复对 `PermissionError` 进行最多 8 次替换尝试，间隔从 25 ms 增加到最多 200 ms，累计等待不超过 1.2 秒。始终保持原状态文件完整；持续拒绝仍抛出错误，其他磁盘错误不重试；退出时清理本次临时文件。重试仅保存本地状态，不重做识别、不发送云端请求。

已将此函数同步到当前 `AiClimbing-0.1.12-key-actions-preview.20261009` 程序包，并更新资源校验、文件清单及本地更新记录。未修改用户任务、照片、视频、账号或配置。

验证包含短暂占用、持续拒绝、其他磁盘错误，以及真实 Windows 文件句柄暂时禁止替换后释放的场景。用户退出当前 App 后重新打开原图标，再点击失败任务的“重试本地准备”。
