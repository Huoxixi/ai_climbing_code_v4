# 复盘画面组合与无人背景：实施与验收

日期：2026-10-15。范围：本地网页及当前 App；未部署生产。

## 已实现的使用方式

复盘准备成功后，视频下面出现“骨架、真人、动作示意图”三个复选项，默认只选“真人＋动作示意图”。至少保留一个画面；切换只重新绘制画布，不重新识别、编码或重置播放进度。生成前的岩点识别、补删点、精修及确认保留，可跳过岩点的按钮统一为“跳过岩点识别”。数据中的 `skeleton_only` 继续表示“未分析岩点”，与画面的骨架开关分开。

| 选择 | 画面 |
| --- | --- |
| 骨架 | 无人真实背景＋骨架，单画面 |
| 真人 | 原视频，单画面 |
| 动作示意图 | 完整现有示意图，单画面 |
| 骨架＋真人 | 真人上叠骨架，单画面 |
| 骨架＋动作示意图 | 左侧无人背景骨架，右侧完整示意图 |
| 真人＋动作示意图 | 默认左右双画面 |
| 全选 | 左侧真人叠骨架，右侧完整示意图 |

示意图独立保留岩点、骨架、估算重心及路线，不受“骨架”开关影响；有无岩点仍依原有分析证据决定。真人叠骨架使用原帧坐标；无人背景骨架使用墙面参考到背景帧的变换。继续遵守共同关节资格、脚踝分叉、缺测断开、最长 0.6 秒的相邻观测插值及末帧用点显示，不改变识别模型、选人、接触定义或已知姿态精度问题。

## 无人背景的边界

新旧记录有原片时，本地自动补查背景，不重新运行姿态模型。单独后台任务通过现有高资源队列串行执行，沿用固定摘要校验的人物检测模型，检查全画面及四块重叠区域；不使用“目标骨架缺失”判断无人。先检查每半秒及末帧；没有合格候选时检查剩余帧，避免漏掉很短的空场景。

全片逐帧对齐墙面参考，沿用至少 12 个内点、最多 3 像素重投影误差等已有配准门槛；角点及中心漂移上限为 3 像素与短边 0.5% 的较小值。移动、切镜、配准失败、模型不可用、解码失败或找不到无人帧均返回不可用，不擦人、不生成或拼接背景。候选保存为实际解码帧 PNG，使用支持 Windows 中文路径的编码/读取方式。

不可用时，真人叠骨架与独立示意图仍可选；界面禁止形成“骨架已选、真人未选”的组合，并显示原因。原片缺失时继续保留旧烧录视频的播放和下载，不提供无法拆开的画面选择。

自动检测不构成人工逐帧无人认证。真实场景、身体比例和运动风格仍可能提供关联线索；本功能不宣称完全匿名，也未进行隐私攻击或专业评价等效性验证。

## 导出与资料

导出面板提供上述三项及“资料”，前三项初始复制观看选择，资料默认关闭；导出选择独立于观看。可选画面导出 MP4；画面＋资料导出 ZIP；仅资料直接返回 ZIP，不调用编码器。视频无音轨；只有视频时才显示范围、速度。导出失败保留旧媒体，重复命中缓存也可再次下载。

资料采用嵌套字段白名单，提供姿态、关节资格、角度、估算重心、可用岩点及接触、基础统计、运动区间、提示词和时间说明。岩点 ID 转为包内数字别名。无原片、截图、声音、模型原始返回、外观特征、账号、原文件名、私人路径或配置。可以包含明确选择的复盘 MP4；该视频内容以用户所勾选画面为准。

接口沿用现有导出入口，新增 `show_skeleton=false`、`show_human=true`、`show_diagram=true`、`include_data=false`。资料版本为 `motion-data-only-v3`，画面版本为 `selectable-scene-and-diagram-v9`。缓存包含组合、背景版本、资料版本、结果版本、范围和速度；ZIP 下载额外绑定导出 ID，旧链接不会悄悄下载新组合。

`POST /actions/background` 仅请求本地检查，`GET /actions/background?version=…` 返回受账号权限及版本检查保护的 PNG。状态读取只返回公开背景信息，不暴露磁盘路径。仅剩旧视频的历史记录保持旧播放下载能力。
