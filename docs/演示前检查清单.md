# 客户演示前检查清单

## 提前一天

- [ ] 在仓库根目录运行 `.\scripts\backup_demo_data.ps1`，确认输出备份目录。
- [ ] 后端运行 69 项非仿真测试并全部通过。
- [ ] 前端运行 `npm.cmd test` 和 `npm.cmd run build` 并通过。
- [ ] 确认总览页不再显示固定线路推荐区，规格、资产统计、最近岩板和当前状态显示正常。
- [ ] 在标准线路库中分别按线路名称、来源 ID 和定线者完成一次搜索，并确认所选线路可载入定线工作台。
- [ ] 准备一条 11×18 完整线路和一条不完整草稿，避免现场从零录入。
- [ ] 不登录 Supabase、不修改远程数据库、不开放防火墙端口。

## 演示前 15 分钟

- [ ] 运行 `.\scripts\start_demo.ps1`。
- [ ] 打开 `http://127.0.0.1:5173`，确认无需登录直接进入工作台。
- [ ] 打开 `docs\攀岩定线辅助系统完整汇报.html`，确认断网时截图、翻页、文稿模式和问答仍可使用。
- [ ] 依次打开工作台、定线工作台、岩点库、岩板库、标准线路库、AI 实验室。
- [ ] 确认页面切换回到顶部，标准线路搜索和分页可用。
- [ ] 归档再恢复一条非关键草稿，确认图片和线路仍可显示。
- [ ] 在 11×18 完整线路上运行一次 AI 组合和一次审核。
- [ ] 在岩板资产页选择 2–4 块已启用岩板，确认设为基准、移出和清空对照可用。
- [ ] 确认 AI 组合直接显示原板和真实候选；若只有一块候选，页面明确说明没有第二块。
- [ ] 断开外网后刷新一次，确认本地确定性审核仍能展示。
- [ ] 浏览器缩放 100%，关闭通知，接通电源，准备鼠标。
- [ ] 演示结束后在仓库根目录运行 `.\scripts\stop_demo.ps1`。

## 演示中不能误报

- [ ] 不说“已经支持账号、多用户或云同步”。
- [ ] 不说“所有岩板规格都支持 AI”。
- [ ] 不说岩板已经确定为木纹、防滑或竞赛材质；当前只确认规格与功能边界。
- [ ] 全程只使用 Font 等级；标准线路称“MoonBoard 原始等级”，自有线路称“MoonBoard 等效难度”。
- [ ] 不说“大模型决定安全性”；应说“确定性规则初审”。
- [ ] 不说“系统替代专业定线员”；最终现场确认仍由人员负责。
- [ ] 不把仿真模块描述为本次已经完成业务审核的功能。

## 异常备用

- AI 文本服务不可用：展示本地规则结果，说明只缺少文字润色。
- 标准线路图片慢：继续展示名称、定线者、等级、来源和坐标，不等待外部网页。
- 现场编辑耗时：打开预先保存的 11×18 完整线路。
- 页面状态意外：刷新浏览器；本地已保存数据不会因刷新丢失。
- 数据误操作：从 `backend\data\demo_backups` 最近一次备份恢复，演示现场不直接覆盖原文件。
