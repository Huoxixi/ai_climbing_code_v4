# 照片线路 V2 标注与验收

本轮识别只在本机运行。正式验收前准备 5–10 张完整正面岩壁照片，其中至少 2 张设置 `holdout: true`，不参与规则调节。

每张照片标注全部岩点与造型的真实轮廓、类别、颜色组，以及对象实际占用的一个或多个孔位。清单使用相对路径：

```json
{
  "samples": [
    {
      "image": "samples/board-01.jpg",
      "holdout": false,
      "objects": [
        {
          "kind": "hold",
          "color_group": "黄色",
          "contour": [[120, 80], [180, 82], [176, 142], [118, 138]],
          "hole_ids": ["H8"]
        }
      ]
    }
  ]
}
```

运行 `python scripts/evaluate_photo_route_v2.py <清单路径> --output <报告路径>`。报告按轮廓 IoU≥0.5 匹配对象，并分别给出对象召回率、精确率、孔位正确率和严重轮廓失败数。通过线为召回率与精确率均≥90%、孔位正确率≥95%、严重轮廓失败数为 0。未提供完整标注集时，不应对外宣称已达到这些数值。

人物、告示牌和贴纸不标成岩点；镁粉或反光区域不应单独成组。多锚点对象必须列出全部孔位。保留照片原文件，调参集与留出集不得互换。
