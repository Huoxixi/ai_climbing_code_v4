# 媒体上传自动处理：改动总结与交接

日期：2026-09-23
范围：抱石项目本地代码。本文测试记录形成时尚未推送或部署；后续发布状态以 GitHub 标签、发布门禁和服务器实际运行版本为准。

## 目标和用户体验

用户只需选择手机里的照片或视频。格式整理、方向修正、视频裁剪与压缩由系统完成；不能处理时，页面和任务记录说明实际原因。上传前明确告知：完整视频先进入本系统，只有抽样画面会送至阿里云人体姿态服务；手机原文件不会被修改。姿态处理仍须用户明确授权，线路颜色仍需选择。

## 实现

| 入口 | 服务器处理 | 用户可见结果 |
| --- | --- | --- |
| AI 复盘视频 | 上传落盘后立即创建可查询任务；后台用 FFmpeg 生成无声 H.264/yuv420p MP4，自动按画面方向缩放、降帧，并截取选定片段（未选且超长默认前 90 秒） | 上传不再等待长时间同步转码；任务显示整理、分析或失败原因；浏览器无法读取视频元数据时仍允许交给服务器尝试 |
| 正式线路、旧版岩板照片 | 服务端识别 HEIC/HEIF 并转 JPEG，校验质量后按原流程建任务 | 不依赖 iPhone 浏览器或 Canvas 对 HEIC 的支持 |
| 线路附加照片 | 直接上传与分块上传完成时都在服务器转换 HEIC/HEIF，文件和媒体类型记为 JPEG | 照片在其他浏览器也可打开 |

关键文件：`backend/core/media_normalization.py`、`backend/core/climb_replay.py`、`backend/core/photo_route_v2.py`、`backend/core/photo_route_workflow.py`、`frontend/src/components/ClimbReplayPage.vue`、`frontend/src/components/PhotoRouteWorkflowPage.vue`、`frontend/src/components/PhotoRoutesV2Page.vue`、`frontend/src/composables/usePhotoWorkflow.js`、`frontend/src/services/photoRouteService.js`。

## 边界和留存

- 视频上传上限 500 MB。分析副本上限 90 秒、2700 帧、200 MB；横屏最长边 1920、短边 1080，竖屏对应旋转尺寸。服务器会尝试不同压缩档位。超上限、损坏或当前 FFmpeg 不支持的编码会显示失败；不能承诺每个容器内的所有编码均可解码。
- 用户可选片段仍上传完整文件，当前不是“先在手机本地截取再上传”。服务器转换成功后删除原始上传文件，后续保留/删除和“原视频”播放针对的是不含原音频的服务器整理副本；失败/取消时按既有 72 小时或私密保留策略处理尚可用的上传文件。手机本地文件从不删除。
- HEIC/HEIF 照片输入最多 25 MB、4000 万像素，转换后的 JPEG 最多 20 MB；过大或损坏会提示明确上限/原因。普通 JPEG、PNG、WebP 仍走原有校验。
- 线路记录中的附加视频目前是资料保存入口，不是 AI 复盘入口；本轮没有把这一路的视频转为跨浏览器 H.264。MOV/WebM 在某些浏览器可能无法直接播放，应在后续单独设计无损完整时长的视频后台转码和留存策略，不应把它误说成已解决。
- 新增 `imageio-ffmpeg==0.6.0` 和 `pillow-heif==1.7.0`。部署前须由发布门禁验证 Linux 依赖安装；FFmpeg 二进制及 HEIF 相关依赖的许可合规仍需在商业公开发布前单独核查。

## 验证和发布交接

- 自动测试覆盖：HEIC 转换及损坏提示、三个照片路径中的转换、视频高帧率/超长/非 MP4 格式、上传后立即返回任务和失败记录。
- 本地完整门禁：后端 `unittest` 310 项运行、0 失败、9 项按环境跳过；前端 93 项运行、0 失败；Vite 生产构建成功（仅有既存的大模块体积提示）。真实生成的 60 FPS 视频产出 30 FPS H.264（50 秒约 1500 帧）；高分辨率竖屏和手机旋转标记分别通过方向与尺寸测试。生产没有执行新的健康检查；不可把本地通过等同于线上已部署。
- 发布时：先检查工作区差异和 `.local/` 排除情况，再推送代码、创建不可变 `pilot-v...` 标签；GitHub `release-gate` 通过后，按 `AGENTS.md` 在阿里云 ECS 上运行 `/usr/local/lib/ai-climbing/deploy_release.sh <完整标签>`；最后核验版本、健康接口、服务状态和正式站点。未经用户明确要求，不执行该步骤。
