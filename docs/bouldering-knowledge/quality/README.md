## 重跑方式

在项目根目录，使用可用 Python 执行：

```text
python -X utf8 .agents/skills/boulder-knowledge/scripts/kb.py check
python -X utf8 .agents/skills/boulder-knowledge/scripts/evaluate_kb.py
python -X utf8 -m unittest discover -s .agents/skills/boulder-knowledge/scripts -p test_kb.py
```

评测脚本只读并输出结果，不覆盖已冻结报告。若知识或检索有变，应另存新报告并说明差异，不能覆盖基线隐去回归。当前 40 项工具测试通过；这些检查验证结构和工具行为，不验证运动效果。
