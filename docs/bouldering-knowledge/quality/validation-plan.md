# B005：独立审核与授权视频验证方案

状态：准备稿，尚无独立评分、教练签字或真实视频结果。本文件规定下一步怎样收集材料与复核，不是已执行记录，也不授权读取、上传个人素材。

## 1. 先做什么

1. 补原作者连续示范：从[来源抽查](source-audit.md)的定位结果继续，优先旗式、Pogo、回脚。实际观看后才记录可复现时段；文字和链接不能填补不可见事件。
2. 独立知识问答：另写未参与调参的问题，保存原始回答后再评分。与当前 40 道开发题、12 个自查答案分开。
3. 专业复核：由了解抱石教学的审核者逐项查看知识单元、证据和适用条件；先处理动态动作、旗式和计时比较的边界。
4. 授权视频小样本试标：先核素材权限，再测试标注合同能否一致执行。结果用于修订，不直接作为自动建议上线验收。
5. 独立视频验证：根据试标的事件分布、可见性和分歧确定样本量、容差与门槛；在看留出结果前冻结方案。

各步骤可分别推进，但不能互相替代：教练认可文字不证明模型识别准确，问答检索通过也不证明建议有效。

## 2. 独立问答的交接规则

- 出题者和评分者不参与本轮检索调参；题目不得只是开发题的同义改写。覆盖可回答、条件不足、库外问题、冲突来源和资料内指令五类。
- 固定知识版本及摘要、检索实现版本、实际回答模型与提示词。当前开发评测未调用回答模型，未来须另存模型原始输出，不能把检索结果当答案。
- 回答者先提交答案，才公开评分依据。记录每项主张的知识 ID、主张 ID、证据 ID、原文位置、适用条件和未知项。
- 逐项评：事实是否有支持，是否把迁移写成定论，是否把本人报告写成所见，是否虚构帧/时刻，是否漏掉遮挡，是否把结果当原因，是否跨入无授权操作。
- 保留错误原文、判定理由和分歧，不只给总分。任何虚构证据、绕过素材权限或未经验证自动建议都单列为阻断项；发生后先修订，再用未见题复测。
- 具体题数与其他验收门槛在独立测试前由负责人确认；本轮不以开发集成绩反推阈值。开发集不得改名为留出集。

## 3. 专业复核记录模板

每次复核新建记录，不覆盖历史。以下字段均待真实审核填写；未填不能视为通过。

| 字段 | 填写要求 |
|---|---|
| 记录编号、日期、审核者、经验范围 | 使用经同意保存的标识；说明是否参与条目编写 |
| 单元 ID / version / 主张 ID | 指向实际版本；不可仅写章节名 |
| 证据 ID / 原文定位 | 审核者实际查看的来源、段落或视频时段 |
| 结论 | 限定范围内可保留 / 需修订 / 证据不足；未审核项明确留空 |
| 条件与风险边界 | 哪些人群、任务、视角不适用；哪些说法不能由画面推出 |
| 修改建议与理由 | 分清术语差异、来源错误、观察规则问题和现场教学判断 |
| 复核分歧、处理者及后续版本 | 不按人数投票当科学定论；保留冲突和最终取舍依据 |

全库单元已有的 58 条具体缺口见[缺口快照](gap-register.json)。专业审核、授权材料、独立评测等全局任务另记，不包含在这 58 条计数中。

## 4. 视频素材：优先使用已有、明确授权的录像

启动所需最小交接：用户指定可用文件、许可范围（本地查看/标注，是否允许模型处理）、是否包含他人及其授权情况、保留和删除要求。没有外部处理许可时不上传；未知权限的片段不进入数据集。公开教学视频的观看权限不等于训练或再分发许可。

不主动扫描 `.local/`，不要求为了填空重新上墙、制造滑脱或复现失败。缺少场景可以保留缺口。正式收集需用户明确指定独立素材位置，身份授权凭据与脱敏标注分开保存，知识仓库不存个人视频或身份资料。

下表是**覆盖目标，不是已收集样本**。同一片段可覆盖多个目标；样本量待实际可用素材与试标分歧确定。

| 目标 | 对照与应保留的未知 |
|---|---|
| 脚部接触与后续转移 | 清楚可见 / 鞋尖被遮挡；碰到不等于可测承重 |
| 同点换脚 | 交接连续 / 只看到前后两帧；不能补成滚动或跳换 |
| 手部匹配、同手连动和原点调整 | 点身份确认 / 身份不清；教学术语与业务标签分栏 |
| 首次触达与后续结束 | 未触到、触后很快离开、保留后任务未完成、保留并继续分开 |
| 身体朝向与旗式 | 可见前后路径 / 只有重叠投影；不由单帧确认深度或真实重心 |
| Pogo 起动 | 起动前支点与摆腿可见 / 仅有接后片段；不反推发力贡献 |
| 回脚 | 可见接近、首次碰到、接触保留及后续动作 / 缺其中阶段 |
| 停顿 | 无新接触但身体仍调整 / 连续运动不清；不标成恐惧或休息原因 |
| 同线路多次尝试 | 同一人、同一线路版本、同一共同任务确证 / 任一项未知 |
| 重复经过同一点对 | 前后事件顺序可对应 / 同点对不同轮次；不强制配对 |
| 失败和完成的时间比较 | 共同任务边界可比 / 一个提前结束；总体结果另列 |
| 熟悉度背景 | 中间试攀历史有记录 / 未记录；不填成零次或协议上限 |

建议用户首先提供已授权的一段完整尝试，以及同人同线路的另一段尝试（若已有）。这只是便于试标的起点，不能覆盖全库，也不要求两次都有成功或失败。

## 5. 试标数据合同草案

不在此建立新的业务实体。未来离线验证清单使用脱敏 clip_id，引用现有动作 ID、线路和岩点复核版本；找不到对应项就记录未映射，不造一个“已识别”代码。

| 分组 | 必备记录 |
|---|---|
| 素材与权限 | 脱敏编号、原文件摘要、授权记录引用、允许用途、处理地点和有效期；未知值不得默认同意 |
| 时间基础 | 原始时长、帧时间戳、恒定/可变帧率、实际抽样时刻、剪辑起点偏移、分析片段边界；缺失写未知，不假定固定帧率 |
| 任务背景 | 活动类型、墙面/视角可知范围、任务起止定义、完成结果、本人报告、中间尝试史 |
| 配对约束 | 同人确认、线路版本、岩点身份及人工复核版本、共同事件顺序；不满足则不生成有效时间比较 |
| 可见事件 | 肢体、接触对象、事件类别、可定位时间或区间、可见/遮挡/抽样未覆盖、标注依据 |
| 人工复核 | 标注者匿名 ID、标注版本、分歧、裁决理由、关联知识版本；原始意见与裁决均保留 |
| 模型运行 | 模型/提示词/检索版本、知识摘要、采样配置、原始输出、人工修正，不用修正值回填成模型初始答案 |

时间区间只表示可定位范围，不自动称为统计置信区间。单目视频不提供真实力、摩擦、关节负荷、动力贡献或医学标签。意图和感受只能来自本人报告，不能由表情或一次脱落补齐。

先由两名标注者对同一批材料独立记录可见事件，再比较分歧；不要先展示模型答案引导标注。只有一名标注者时可做流程试跑，但不得称为独立参考标准。无法裁决的项保留未知，不强制生成真值。

## 6. 评估及放行边界

- 可见事件：在预先定义的匹配规则下分别统计精确率、召回率和漏检/误检数量；遮挡与抽样缺失另组，不能将不可判定项当明确负例。
- 未知处理：统计在不可见时仍断言发生、把本人报告冒充所见、虚构时间戳的数量；报告分母和具体例子。
- 时间：对有人工参考的事件统计误差或区间重叠，容差按实际时间基础预先登记。样本不足不报告虚假的高精度。
- 同线路比较：统计不满足共同任务或身份/版本条件却仍被接受的配对；同时检查反复点对和提前结束场景。
- 问答：另评来源支持、条件、未知与建议边界，不能用事件检测分数代替。任何建议有效性结论需要另行研究，不能由上述检测验证推出。
- 分组与留出：分别报告可见性、动作类别、拍摄方式和成功/未完成情境。按攀爬者与线路分组隔离开发/留出，避免同一尝试的相邻剪辑泄漏；不同测试目的分别定义分组规则。
- 先导集只测试流程和发现缺口。独立集的规模、容差、门槛和用途在运行前审批并留档；不能看到分数后修改规则宣布通过。

即使未来部分审核通过，也须先新增可引用审核记录、独立验证材料和对应校验规则，再升级知识合同。当前所有单元继续保持专业复核 pending、视频验证 not_started、automatic_use=false。B005 当前保留 in_progress，不能用一份方案替代实际验证完成。
