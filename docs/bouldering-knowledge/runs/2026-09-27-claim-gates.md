# 复盘主张与独立验收门槛

日期：2026-09-27。依据[修改报告](../../archive/pre-release-20261001/个性化攀岩复盘_修改报告与建议边界_2026-09-26.md)补齐工程门槛，不开展新的专业审查或真实视频效果研究。

新增主张注册表，将单元解释引用与执行建议权限分开。只有主张版本、来源定位、真实专业审核、独立验收材料与当前运行版本完全对应时才可进入本次条件核验；每个条件还需独立复核及具体帧锚点。风险判断始终关闭。

新增 3 个 `draft` 候选、专业审核及视频验收模板、逐尝试评估格式与离线指标工具。空建议无建议正确率分母；公开覆盖率与不确定区间，防止开发/验收用户或线路泄漏，保留正常/拒绝场景、成本未知与相关样本分组。现有 24 个单元、来源及批次状态均未改写；当前获准主张仍为 0。

构造检查验证了记录缺失/撤回/版本或来源变化、条件未知/证据错配、模型别名与运行版本变化、样本重复/泄漏/相关性、空建议及缺失费用等程序行为。测试数量以本轮实际执行结果为准；全部构造案例不得当作专业批准或真实效果验收。没有声称建议准确率、完攀率或安全性提升。

下一步仍需要有成人抱石教学经验的审核者逐主张审查，并在明确授权、冻结且与开发集隔离的材料上完成独立效果验收；当前任务不伪造这些外部证据，也不安排生产部署。
