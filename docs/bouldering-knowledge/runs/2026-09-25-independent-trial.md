## 发现与修订

1. 额外查询“这是什么？”只因“什么”命中四个条目。修订：过滤常见疑问词；增加无主题问句检查。
2. “What is backstepping?” 因别名子串命中，但未显示命中理由。修订：增加 matched_names，保留实际词项与名称命中。
3. Windows 默认输出编码可能造成中文乱码。修订：脚本显式使用 UTF-8，技能命令示例增加 UTF-8 参数，并补不同进程默认编码的检查。

首轮试用发现的手册未生成问题发生在主任务仍编写时，随后已生成。最终复查结果在首轮运行日志中记录。
