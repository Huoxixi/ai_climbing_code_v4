# 抱石知识库

这是由专用 Agent 按批建设的本地内容库，服务于抱石知识学习和视频复盘研究。

2026-09-27：个性化复盘新增[主张与独立验收合同](claim-contract.md)、3 条未获准候选主张及审核模板。现有 24 个单元状态不变；当前没有可用于自动技术建议的主张，也没有真实视频效果提升证据。单元获准不能连带批准全部主张。

阅读入口：[知识手册](HANDBOOK.md)。源资料：[来源与证据](sources.json)。进度：[批次状态](state.json)。建设方案：[Agent 计划书](../抱石知识库Agent_建设与执行计划书_2026-09-25.md)。

已完成四批的内容编写、累计 24 个知识单元，附 32 张证据卡及 48 个构造例：

- B001：落脚、内外侧踩点、踩墙、换脚、Rock over、高抬脚。见[首轮记录](runs/2026-09-25-bootstrap.md)。
- B002：手点方向、双手匹配与换手、同手连动与原点调整、交叉手、捏握、首次触达与接后任务。见[本批记录](runs/2026-09-25-B002.md)。
- B003：身体朝向、外侧旗式、后/内侧旗式、Drop knee、Pogo、脚离点后的摆动与回脚。见[本批记录](runs/2026-09-25-B003.md)。
- B004：读线方案与实际执行、探索指标、停顿解释、熟悉度与尝试历史、同线路计时比较、参考 beta 与竞争解释。见[本批记录](runs/2026-09-25-B004.md)。

B005 已完成本地开发检查与验证准备，见[质量检查报告](quality/README.md)：40 道固定开发题、8 项来源主张抽查、12 个构造短答自查、58 条单元缺口及后续验证方案。批次仍在进行中，独立问答、连续示范、专业审核和授权视频验证未完成。

以上“完成”均指相应内容编写或本地检查，不表示专业复核或视频验证完成。B003 的原作者连续示范仍未核验，其文字方案不作为实拍时序证据；B004 的比较与假设修订规则也未验证为诊断算法。当前 40 项工具测试通过，不代表运动技术或 AI 视频分析准确率通过。

## 使用

在本项目的 Codex 任务中输入：

> 使用 $boulder-knowledge 读取进度，继续下一批知识库建设。

查询时可以说：“使用 $boulder-knowledge，查一下换脚与落脚调整的区别，并给出来源。”若当前任务没有自动发现技能，明确让 Codex 读取本项目 `.agents/skills/boulder-knowledge/SKILL.md` 即可。项目专用 Agent 名为 `boulder-librarian`；它和主任务直接使用技能共享同一份资料。

这是一套在 Codex 会话内执行的工作流程。进度写入文件供下次续做；本版没有定时任务或独立 API 服务。

## 阅读口径

`AI 已核对来源段落` 仅表示编写时检查了具体文字；专业复核、真实视频验证和自动调用另列。当前内容只用于知识解释和人工复盘辅助，不能把命中条目理解为已经识别出动作原因。

运动知识主张附证据定位；视频观察和比较方法是项目设计，需后续验证。例子均标为构造例。用户参考图片用于组织框架，未作为科学验证材料；图中尚未定位的课程别称、页码等保留在[原完善计划](../AI攀岩复盘_抱石知识库完善计划_2026-09-25.md)的待核范围内。

本目录不保存个人照片、视频、身份资料或密钥。当前 27 项来源中，19 项来自同一机构 Momentum 的不同教学页面，另有 REI 教学、Connor Griffith 专栏、Neil Gresham 署名教学各一项、CEC 协会框架一项，以及四篇论文。四篇论文中一篇为概念系统化整理，并无新实验数据；其余研究的对象和任务各有限制，PLOS 的三个实验使用同一样本。来源数和证据卡数都不等于独立验证次数，不同教学体系的交叉核查仍需继续补充。
