# 复习工坊配套发布

用户明确授权复用现有攀岩SSH/GitHub发布通道，让首页选择进入攀岩或复习工坊。此候选从现网提交0225be90a911acdb7e8b3fa847fd14bfd0ba8024建立，不包含其他尚未验收的本机App修改。

仅manifest指定的pilot-v2026.11.16-rc1走配套发布；其余标签继续原攀岩发布流程，原8GiB全量发布空间检查不改。既有PR与标签release-gate完整保留，新增21文件白名单包校验、4项发布保护测试和账户API套件。

配套发布通过原白名单deploy命令加载已合入main的不可变标签；新增独立study-friends用户、Node24服务与SQLite目录，只在原Nginx域名加入精确首页和/study/。攀岩通过/?project=climbing进入，原API、下载、运行版本、数据和/ai41/保留。不会增加SSH/root shell权限，不替换原Node环境，不修改authorized_keys。

发布前校对原攀岩SHA、空间、包哈希、现存路径冲突和Nginx锚点；原站改变时拒绝。Node24.22.1从官方HTTPS下载，按官方SHASUMS的固定SHA256核验；有合适24.x运行时则直接复用。私有数据库和真实学习记录不随源码或app.zip分发。

install.py默认预检查，再执行应用。记录原Nginx备份和前后攀岩首页、健康、AI41字节哈希；失败恢复Nginx并停止新增服务。新服务数据保留，不自动删除。回退时依回执恢复原Nginx配置并通过nginx -t后reload，停study-friends，保留数据库；不回退攀岩代码，因为本轮未切换攀岩current。

app.zip是已构建的复习资料库网页，非原课程内容。来源涉及用户提供的Auth UI及Card Fan Carousel改编（21st.dev/@jahed/components/auth-ui、21st.dev/@aayush-duhan/components/card-fan-carousel），独立UI片段许可尚待核，不由MIT覆盖。依赖许可见包内THIRD_PARTY_NOTICES.txt；Unsplash本地照片来源写入图像元数据。通用Skill另在Huoxixi/study-review-workshop公开分发，本候选不把第三方组件原提示词附入Skill仓库。
