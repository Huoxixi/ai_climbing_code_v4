# 视频骨架识别：专项优化计划

日期：2026-10-11。状态：方案深化；关节精度和真实跳变改善尚未实测。共同实验约束和其他问题见 [质量优化总入口](视频复盘_岩点骨架接触优化计划_2026-10-10.md)。

2026-10-11 执行更新：源帧基线、选人/人物框、官方适配、密集采样和局部重推理对照已执行。采纳原始证据标记与 133/17 点共同坐标修复，84 项工程回归通过；重推理候选和整体骨架质量未通过。详见 [首轮实施与独立验收](骨架识别_首轮实施与验收_2026-10-11.md)。上句描述原计划状态。

## 1. 本质：从有限观测估计身体运动，并识别不能确定的位置

“手乱飞”不只是画面不平滑，而是模型给出的关节位置可能没有真实运动支持。骨架要表达同一个人的连续运动：人不能换、左右肢体不能换、真实快速动作不能被抹掉、遮挡时不能凭空确定位置。

因此优化目标是降低手脚定位错误，同时保留可见运动和有效观测覆盖。更高 FPS、更多关节点、更平滑的动画或模型高分，都不能单独证明骨架准确。

## 2. 首先分离四个错误层次

| 层次 | 核验方式 | 应处理什么 |
| --- | --- | --- |
| 人物选择 | 在同一原帧画出人物框，看是否为攀爬者且包含可见全身 | 检测框、身份连续性、多人歧义和入画恢复 |
| 原始关节 | 原坐标直接叠在该源帧上，不配准、不插值 | 模型输入尺度、姿态域差异、遮挡和左右交换 |
| 坐标变换 | 比较原坐标叠加与墙面参考坐标显示 | 缩放、裁剪、配准和投影视差 |
| 显示补帧 | 对照实测帧与插值帧、页面与导出 | 插值把错误端点连成假动作、时钟不一致 |

手在原始实测帧已经错位，就不能只修播放器。实测位置正确但参考视图偏移，则先查变换，不把模型换掉。每个错误记录层次及是否可以由原片核验；遮挡下推断的位置不直接视为真实标签。

## 3. 当前机制与需要证明的假设

当前使用本地 RTMW-L 384×288，人物框选择有连续性和外观恢复；`_infer_pose_frame` 保存 133 点，主体链路取前 17 点。人体有效性检查主要依赖整体有足够关节点，不等于每一只手、每一只脚可靠。

重点检验：手脚在真正模型输入中是否只剩很少像素；人物框是否裁掉伸出的肢体；背景与攀岩姿态是否导致高分错位；是否出现左右交换；时序显示是否放大了这些错误。保存的 133 点只证明有细部输出，不证明其在低清攀岩场景可用。

墙面配准是二维图像关系，不能把离墙的人体当成已恢复三维位置。接触和局部核验须明确当前源帧坐标；参考墙面轨迹只说明相对墙面的二维投影。

## 4. 首轮实验：同帧同人，先查输入再查模型

为错误与正常片段标注人物身份、可见腕/踝、肘/膝和左右链，记录遮挡、人物尺寸及真实快速动作。每个乱飞片段至少核验突跳之前、突跳时和恢复之后的源帧，不能只看一张静态截图。

| 实验 | 控制变量 | 判定用途 |
| --- | --- | --- |
| S0 原始证据 | 当前模型，关闭研究修订，仅把原坐标叠到源帧 | 确定错误是否已在模型输出中 |
| S1 框与像素 | 同模型同帧，比较当前框、核对后全身框及合理上下文 | 排除人物框和低有效像素问题 |
| S2 上游核对 | 同帧同框、权重、输入规格，与官方预处理/解码核对 | 分离本地适配错误和模型自身误差 |
| S3 时间核对 | 基础采样与异常附近原生密集采样对照 | 判断跳点是否孤立、快速动作是否漏采；采样不修复固定错位 |
| S4 原始/修订/显示 | 保持原始数据，独立比较质量检查、局部重推理、显示插值 | 找到改善来自真实定位还是只让画面好看 |

若 S1/S2 已纠正错误，先修输入和适配。若框、像素和适配都正确但关节仍频繁错位，才进入替代模型或攀岩数据适配对照，不先把时间平滑当解法。

## 5. 目标方案：逐关节质量状态，异常复核，有限时序修订

每个关节有自己的可见/可靠/冲突/缺测状态，不能因为躯干可靠就接受错手。分数与真实标注残差结合核验，高分也可能错；异常依据包括肢体链关系、前后观测和局部图像支持，不能只凭一个速度阈值。

发现异常时先回到同时间附近的原帧，扩大合理人物框或局部重推理，并比较左右链候选。局部手脚推理需有足够真实像素，额外放大模糊图像不能作为可靠细节来源。若仍无法判定，保留缺测；不依据附近岩点把手拉过去。

时序约束用于发现与修订错误，不能强制所有动作平缓或锁死二维骨长。肩肘腕/髋膝踝应整体核对；透视变化、跨手、转身和真实动态伸展是必须保留的正例。较长遮挡不能桥接成确定轨迹。

数据分为原始观测、经核验修订和显示插值。保留原坐标、修订原因及支持帧；插值只用于播放，不增加观测覆盖或进入确定接触证据。历史已有姿态不被批量改写，新输出独立保存。

## 6. 验收聚焦手脚，同时约束运动失真

腕/踝及可用手脚细部的误差分开报告，使用源帧像素、相对人体尺度和相对附近岩点尺度，不能只给全身平均分。记录身份切换、左右交换、错误跳变次数及持续时长，并报告可靠可见关节覆盖。

定位精度还要对应任务：在相邻小岩点附近，同样的关节误差可能已经足以把接触身份判错；在空旷区域则未必影响判断。把关节残差、岩点边界误差和配准残差合并检查，并与最近竞争岩点的可分辨间隔比较。这里先建立经验误差范围，不假定误差独立或直接相加就是可信概率；误差范围不能排除另一岩点时，不能声称已能可靠支持指定点接触。

已知可见位置被隐藏时仍记为未提供有效定位，不能通过大量留空降低误差。人工也无法确定的位置单列不可判读，不参与位置真值评分；系统在该区间给出确定错位应作为风险案例核验。

用正常静态与真实快速动作共同检验修订：关键移动起止、峰值位置、到点时序是否被拖延或削弱。成功须表现为定位和错误跳变改善，覆盖与真实动态保真无实质退步，并在冻结留出视频验证。平滑度不作为主成绩。

## 7. 效果不足时的 GitHub 路线

[MMPose](https://github.com/open-mmlab/mmpose) 是 RTMW/RTMPose 上游入口；先读同权重的预处理、框扩展和坐标解码。适配一致后仍有稳定错误，再以 [ViTPose](https://github.com/ViTAE-Transformer/ViTPose) 等作为模型对照；仅引用通用榜单成绩不能决定替换。

若单帧尚可但跨帧错误显著，检索视频姿态、遮挡、左右交换及时序一致性项目和已解决 issue/PR，区分“修正图像有支持的关节”与“生成合理但未观测的动作”。高星是找经验的入口，不是本地效果证明。

连续两轮受控改进没有收益、持续高分乱飞或资源无法在当前设备运行时，按总入口启动专项调研。每项新方法在隔离环境同帧对照，再做完整片段；同一人物框、可比较的输入像素和依赖/权重版本必须记录。CPU/DirectML 与桌面依赖可用性是采纳条件，不默认 CUDA。

## 8. 交付物与第一动作

首轮交付四层错误归因、同帧同框输入/上游对照、逐关节误差和运动保真报告。第一动作是把当前原始关键点直接叠回真实源帧，定位“乱飞”出现在哪一层；不先整片换模型或加滤波。

实现涉及 `replay_pose_rtmw.py`、`replay_person_tracking.py`、`replay_sampling.py`、`replay_hold_fusion.py::align_pose_record` 及前后端显示时间线。各层分别验证，最后核验页面/导出的一致性和纯骨架模式；本文没有执行这些实现。
