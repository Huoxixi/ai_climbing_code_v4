# 网页版核心功能免登录：实施与验收

> 2026-10-18 已在此基础上加入浏览器本机视频导出，见 [导出实施与验收](网页版本机视频导出_实施与验收_2026-10-18.md)。下文“尚不支持视频导出”仅代表此前阶段。

2026-10-17，用户最新要求：“不要账户登录吧，只留下核心功能就好。”此项覆盖同日此前的账号版要求。

## 当前交付

打开 [本机网页版](http://127.0.0.1:4317/browser-replay.html) 即进入骨架工作台，无需设置管理员、登录、注册或邀请码。保留选本地视频、确认人物、本机识别、骨架/真人回放、下载骨架JSON、本机历史、存储额度/持久存储申请及现有桌面安装包下载。

仍不包含岩点、线路库、完整多人跟踪、接触、无人墙面和视频导出；本次按用户新范围只保留已实现的核心功能，不声称完整桌面App已迁移。模型首次加载需要网络，CPU/GPU运行与视频、骨架结果保留在用户设备；CPU已有真实验收，真实显卡兼容矩阵尚未完成。当前500MB视频上限、从人物确认处开始最多90秒、浏览器可解码要求保持。

## 移除与数据保留

- `BrowserPortal.vue` 不再加载账号状态或心跳，不再提供注册、用户管理、昵称/密码及退出登录；`BrowserLogin.vue`、`accountApi.js` 和专用 `browser_accounts.py` 已删除。原桌面/主站通用 MemberAccounts 未动。
- `backend/browser_web_app.py` 只服务静态文件、桌面下载和健康信息；旧session/login/register/setup/profile/password/admin和媒体API均404，不创建会话Cookie，不初始化数据库。
- 原 `.local/browser-web/accounts.sqlite3` 及相关既有账号文件保留不用，没有删除、覆盖或迁移。实际桌面App、4176服务、用户原片、密钥和生产未修改。
- 历史仍使用 `climbing-browser-history-v1` 和原 `records/content` 结构。新记录使用固定本机命名空间 `LOCAL_HISTORY_OWNER`；`listLocalHistory()`只读取全部记录，旧账号记录原位统一展示。同一浏览器的人可以看到同一个本机库，不再按登录身份分隔。打开和删除仍用 `owner+id`，相同id的其他记录不误删。没有重新编号、复制原视频或批量覆盖旧结果。
- 模型缓存不清理；空间不足时视频与结果同事务撤回，已有记录保留。清除网站数据会删本机历史，换浏览器/设备不同步。下载仍为现有2026.10.10安装包，不冒充10月17日热修复安装包。

## 启动与复验

项目目录运行 `./start-browser-local.ps1 -Build`；已构建可省略 `-Build`。它启动当前源码轻量静态服务，不接入原账号数据。首次无需任何账号配置。

前端使用 `npm run dev:browser -- --host 127.0.0.1 --port 4330`；仅桌面下载代理到默认4317，可用 `CLIMB_BROWSER_DOWNLOAD_TARGET` 调整。静态 `npm run preview:browser` 可以直接使用工作台，不需要账号服务，但本身不提供安装包下载路由。

后端 `python -m unittest discover -s . -p test_browser_web_app.py -v`；前端 `npm run test:browser-portal`。真实模型验证需私有 `CLIMB_BROWSER_NATIVE_FIXTURES`；源测试设置 `CLIMB_BROWSER_BASE_URL`，最终包测试设置 `CLIMB_BROWSER_COMPILED_URL`，对应 `test:browser-local` 和 `test:browser-compiled`。缺少私有素材时重型验收明确跳过，不能算真实模型通过。

本次没有推送、建发布标签或生产部署，正式域名仍未因本次本机预览改变。
