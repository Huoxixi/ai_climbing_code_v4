## 架构与目录合同

采用 pywebview 6.1 + WebView2 EdgeChromium + 本机 FastAPI + Vue 静态构建。使用随包 CPython 3.12.14 目录式运行时，保留 `python -m core.*` 视频工作进程，无需 PyInstaller 重写工作进程分派。

| 位置 | 用途与写入规则 |
| --- | --- |
| 程序包的 `AiClimbing.exe`、`runtime/`、`backend/`、`frontend/dist/`、`models/` | 安装资源；不存用户数据，运行不需要 Node、Codex 或系统 Python |
| `%LOCALAPPDATA%/AiClimbing/data` | 当前 Windows 用户的独立本地 owner 账号、素材、草稿、照片和复盘结果 |
| 同目录的 `config/cloud.dpapi` | 当前 Windows 用户加密的阿里云／百炼配置；不回显，不写入程序包 |
| `tmp/`、`cache/`、`logs/` | 临时媒体、模型／WebView 缓存、仅含启动阶段与异常类型的日志 |
| `runtime.lock`、`instance.json` | 当前用户单实例锁和短期实例身份；不随分发包保存 |
| 用户在保存对话框选择的目录 | 独立下载或导出文件；不覆盖旧基础复盘 |

服务绑定 `127.0.0.1` 的随机端口，通过健康检查后才显示界面；不复用或结束开发 4176/8004 服务。所有 API、静态文件和媒体需要实例身份；启动链接换取 HttpOnly / SameSite=Strict 会话 Cookie，校验 Host、Origin 和浏览器 Fetch Metadata，拒绝外部网页及 DNS rebinding。启动令牌不输出到访问日志。重复启动只唤起原实例。复用原资源互斥锁，正常退出关闭任务管理器；Windows Job Object 在异常退出时只回收本实例子进程。

本地账号没有引入生产邀请码或数据库。桌面版云配置保留独立授权要求，保存／启动不会连接供应商。未配置时保留本地能力和历史结果。开发 `.env`、测试视频列表、模型绝对路径、代理和云密钥不会从父进程继承。

## 构建与剩余验收

构建入口 `build-desktop.ps1` 接受明确的 Python、Node、依赖目录、Detectron2 编译源目录和已核验权重路径。默认生成新目录，已有目录拒绝覆盖。`desktop/build.py` 强制 Windows x64 Python 3.12、检查依赖闭包和锁定版本；`desktop/finalize.py` 对候选更新重新审计、生成清单和 ZIP SHA-256。Node 仅在构建时使用。

在另一套构建环境可从 `desktop/requirements-windows.lock` 安装固定依赖，在 VS 2022 x64 Native Tools 提示符使用 `desktop/build_detectron.py --source <a2f4a877源码目录> --output <新ASCII目录>` 编译同一 CPU ABI，再将新目录的 `source` 和依赖目录传给打包脚本。此通用编译脚本本轮未重新编译验证；本轮实际使用的是已存在且在包内、跨盘推理通过的 Windows 扩展。不要把“已有编译产物可运行”写成“全新机器从源码构建已通过”。

本次实际包在 `D:/ai_climbing_code/desktop-deliveries/AiClimbing-0.1.0-preview.20261006`。用户双击 `AiClimbing.exe`，无需运行开发启动脚本。完整使用说明随包提供。
