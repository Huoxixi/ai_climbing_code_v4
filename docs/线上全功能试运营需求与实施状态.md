## 4. 当前阻塞项

### OSS `migration/` 权限

现有 RAM 备份账号可以访问 `daily/`，但写入
`migration/20260730T031732Z/` 时被 OSS 返回 403。需要给现有备份账号补充：

- Bucket：`climbing-pilot-backup-sh-2026`
- 资源范围：`migration/*`
- 动作：列出该前缀、上传、读取
- 不授予删除 Bucket、修改 ACL 或公开访问权限

权限修复后必须完成：

1. 上传本批次 7 个迁移制品。
2. 从 OSS 下载至服务器验证目录。
3. 第三次核对两份 SHA-256 和 `manifest.json`。
