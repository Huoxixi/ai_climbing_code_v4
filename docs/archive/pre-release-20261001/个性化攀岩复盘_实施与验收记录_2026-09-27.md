# 个性化攀岩复盘：实施与验收记录

日期：2026-09-27。依据：[修改报告与建议边界](个性化攀岩复盘_修改报告与建议边界_2026-09-26.md)。本次继续修改指定本地工作区，保留原有未提交改动；未操作生产服务器、真实视频、个人历史数据和 `.local/`。

## 当前交付状态

P0 的生成前告知、单项结果、异常费用与去重，以及 P1 的分离观察、局部复核、主张权限和条件门槛已落入代码。P2 已补齐审核、独立验收合同与离线计算工具，但**没有批准任何真实主张，没有完成真实视频效果验收**。当前真实知识库仍只允许观察模式。P3 的反馈入口与可追溯记录已实现，小范围使用及运营监测尚未开展。

这些是程序行为的改进，不代表动作正确率、完攀率、体力节省或安全性已经提高。

## 已实施的行为

| 修改项 | 实现与边界 |
|---|---|
| 结果合同 | `try / review / insufficient` 三种结果，零至一项建议；没有建议说明具体缺失，暂停个性化伤害风险输出 |
| 生成前检查 | 只读核对已有视频可读性、时长、时间范围、当前知识和预算；成人与室内抱石分别校验；无获准知识须明确选择观察模式 |
| 授权与隐私 | 新授权版本说明必要原始分析画面、局部截图及叠加画面的使用；观察不接收个人背景、目标或原因猜测，体重只留本次快照 |
| 画面来源 | 优先仍按原策略保存的无叠加分析副本，缺失才回退已有叠加视频；不恢复删除媒体、不延长保留、不重跑姿态识别 |
| 观察与复核 | 概览最多24帧，最多追加2个候选的局部画面、每个最多12帧。第二次视觉请求寻找反证；未被局部复核的候选不进入报告 |
| 事件证据 | 静态、位置变化、重复、顺序、接触过程分别校验；过程不仅要合法时间引用，还要对应局部帧覆盖。两帧不能证明次数或完整接触 |
| 重点选择 | 普通静态起步不自动成为首要重点；回看重点须通过值得核对、具体原因与问题检查；无法区分多个片段时明确保留不确定性 |
| 主张权限 | 具体主张、版本、内容摘要、来源定位、教练审核记录、冻结独立验收与运行版本共同校验。整个单元获准不等于所有主张可用 |
| 条件证据 | 每个必要条件与排除条件分别检查三态及对应复核帧；非空条件文字、自述或模型编造的审核编号不能授权建议 |
| 技术建议 | 只从三个待验证类别的已审核固定模板中选择一项；当前没有获准模板。正常解释未排除、不适/限制自述、未知条件等均阻止处方 |
| 费用 | 请求前记开始状态，响应到达先记录用量再解析报告；已知部分与未知费用分开，失败、取消及历史重试仍可查看 |
| 预算与重试 | 本次个性化分析公开价预留预算 ¥0.20，最多3次调用；输入/输出上限与调用前预留控制。不是固定报价或供应商精准硬停费，无隐式付费重试 |
| 取消与删除 | 取消后停止后续调用，迟到用量归入原报告或原历史；删除任务后不重建目录。已发内容及已产生费用不能撤回 |
| 旧报告 | 保留原文与版本，页面不把旧规则或失效报告当作当前行动建议；知识撤回、媒体/修订变化会使依赖失效 |
| 反馈 | 三类反馈附可选具体原因；错误/不适用标为待人工审核，“有帮助”仅是体验记录，不自动改知识、模型或历史 |

## 关键实现入口

- `backend/core/replay_coaching.py`：预检查、版本与授权、去重、生命周期、费用账目及历史归属。
- `backend/core/replay_coaching_engine.py`：无背景观察、局部复核、证据与条件校验、有限模板选择。
- `backend/core/replay_coaching_knowledge.py`：主张、来源、审核、独立验收和运行版本的权限合同。
- `backend/core/replay_coaching_evaluation.py`：按独立尝试及分组统计覆盖率、正确率、不确定区间、费用与耗时；空建议无正确率分母。
- `backend/core/replay_coaching_cost.py`：逐次公开价估算、部分费用和未知费用状态。
- `frontend/src/components/ReplayCoachingPanel.vue`、`frontend/src/services/coachingPresentation.js`：生成前选择、三种结果、依据与费用展示。

## 必须保留的限制与下一步

1. 同一模型的第二次查看可能重复第一次错误。结构、帧和来源检查不能证明画面判断正确，局部采样也不能恢复遮挡或未拍到的细节。
2. 主张审核需要真实有成人抱石教学经验的审核者；独立视频须明确授权、冻结开发/验收分组，再由两名审核者盲审及解决分歧。本次只交付填写合同与评估工具，没有制造审核记录。
3. 每类分别达到修改报告提出的样本、正确且适用率、区间下界、重点可接受率、拒绝场景和理解测试门槛后，才能单独开放。没有输出建议不算建议正确。
4. 技术建议要求模型快照和冻结验收版本一致；模型、提示、采样、压缩、排序、主张内容变化触发重新验收。供应商别名用于观察时，不等于技术效果已获验证。
5. 原型每次预算仍须通过真实授权实验测量后再调整；公开价估算不等于账单，未知费用不显示零元。价格来源：[百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)，核对日期 2026-09-27。
6. 本次不安排生产发布。要在本地常驻服务使用新后端，需按项目既有启动说明在没有处理中的任务时重新加载后端；生产仍须单独明确部署任务。
