# AI 攀岩复盘分层实施记录（2026-09-24）

依据《AI攀岩复盘_骨架动作识别与同线路分段对比_PRD_2026-09-23.md》。本记录描述本地代码状态，不代表真实素材验收或生产发布。

## 本地已接入

- P0：沿用现有阿里云降帧姿态、OpenCV 墙面配准与已确认线路岩点；每个姿态样本记录对齐状态与诊断。仅用成功对齐的姿态参与接触判断。新增可见二维肘、髋、膝角作为证据，不据单一角度自动命名技术。
- P0：接触事件增加首次接触和稳定确认的帧及标准化视频时间。基础换点生成 A 点稳定到 B 点稳定的动作段、证据帧、采样误差量级和不可比原因。已保存线路岩点采用所属岩板版本与成员 ID 的摘要固定比较版本。
- P0：用户可在视频仍可访问时复核动作段的肢体、两端线路岩点、稳定时刻，并可手动加技术名。自动结果不被覆盖，修正有版本、时间记录和撤销入口。
- P1：同账号、同线路、同线路版本两次完成的复盘可以比较。用户需确认同一攀爬者；自动配对要求相同肢体和两个相同物理岩点，边界帧对齐且岩点几何匹配足够。页面并排显示两段视频并可跳转证据。差值落在两个片段合计采样误差内时显示“当前精度下无法确认变化”。未配对或证据不足时不计算差值。人工修正后重新请求比较。

## 尚未通过发布门槛

- 当前分析视频经 FFmpeg 转成恒定帧率副本，时间来自该副本的抽样帧号；尚未保留上传原视频的逐帧 PTS。因此时间字段明确标记为 `normalized_video_sample_timestamps`，不能宣称满足原视频 PTS 精度要求。
- 尚未对动作候选区间做高时间分辨率的本地重分析。落点稳定时长仅是现有采样/持续阈值下的证据，准备、移动阶段与调整次数没有可靠单独估计；页面不据此作“动作优化”结论。
- 人工修正目前作用于动作段记录与新生成的比较结果；已经导出的叠加视频和旧动作时间线不会重绘。同步导出与知识库索引仍属于后续工作，页面不应把旧导出视频称为修正后证据。
- 未建立双人独立标注集，也没有完成固定/移动机位、遮挡、不同拍摄设备的分层验收。P2 专业动作名保持仅人工确认，不自动进入默认时间线。
- 自动墙面配准、岩点身份和动作计时仍需真实授权素材验证。未安装新依赖、下载权重、增加付费姿态调用频率或改变视频留存策略。未推送或部署。

## 本地检查

`backend/test_replay_segments.py` 覆盖二维角可见度、未确认岩点/配准失败拦截、同线路版本/同攀爬者约束和误差内变化；`backend/test_replay_review.py` 覆盖复核权限、版本和撤销。已在本机补齐项目原本锁定的 `imageio-ffmpeg==0.6.0`，复盘、分段与复核共 40 个后端用例通过；前端构建和 Python 语法检查通过。仍需用固定机位与真实手持轻/中度移动素材验收识别效果。
