# 网页 Agent 模板复盘实施记录

本轮按照用户最后确认的结构接入网页：**连续动作组慢放讲解 → 基础数据 → 重点动作回看与有依据的修改建议**。用户希望由网页自己的 Agent 根据每条视频创作，而非继续手写这一条样片的字幕和时间。旧样片仍未视为视觉验收通过。

## 本地实现

原有复盘页面内新增“按模板生成复盘视频”。沿用现有资料、云分析同意及预算确认；相同且仍有效的分析优先复用。任务支持排队、取消、播放、下载和失败重试，生成的 MP4 与基础复盘分开保存。没有新增业务展示页面。

模型首轮观察同时输出本视频的连续动作组，每组引用本次实际抽样画面的编号。服务端检查引用、前后顺序、时间与观察文案；不能确认的区间保留完整慢放并标明缺少讲解。该变化没有新增模型请求阶段，也没有重新调用岩点或姿态识别。模型并未被允许执行任意代码或自行修改事实记录。

本地规划器负责固定结构与呈现约束：

- 第一遍按原片顺序完整覆盖，默认 0.5 倍播放，保留最后完攀动作。首轮抽样不足时不能声称全部动作已看清。
- 接着在真人画面上同时显示四肢不同岩点数；重复使用同一点只计一次。没有可靠记录的肢体显示未确认，自动计数注明待复核。
- 节奏分配按原视频时间展示保持、换点与观测不清的连续区间，未知不归入已知动作。未复核离地和结束边界时显示“已观察时长”。
- 最多回看两组已通过局部复核的重点；只有既有知识和适用条件检查通过后，才显示原先获准的调整与下次核对方法。没有可靠建议时明确说明，不补造训练处方。
- 原视频是画面主体，采用思源／Noto 黑体、白字、青色轻强调、文字一侧柔和压暗。字幕快速淡入，动作段读完后退场。数据字幕为暂停时的手机控件保留空间。
- 不连续片段间额外加入约 0.3 秒真实帧溶解，不用转场吞掉动作。统计不包含慢放、定格、回看与转场时间。

## 工程接入

新增 `replay_template_plan.py`、`replay_template_renderer.py`、`replay_template.py`，复用现有教练任务与视频资源保护。渲染器逐帧读取源视频、流式输出 H.264 MP4，最长边限制为 1280，保留原画幅，不添加配音或配乐。

接口为 `/api/climb-replay/jobs/{id}/template-video` 的生成／状态、`/cancel` 与 `/media`。媒体接口保持账号隔离，支持 Range；返回的实际媒体版本与分镜摘要对应成功成片，失败的新任务不会让旧片配上新摘要。

每个任务保存原片证据、分析版本和知识版本的指纹。原片删除或到期、授权撤回、动作修正、知识撤回或版本更新都会阻止继续使用旧讲解。原片删除前先停止并等待渲染器释放。停止模板只取消它自己发起的分析，不误停复用的独立报告。

所有输出先在任务目录的临时位置生成，完整解码后才提交。渲染与原有重任务共享资源名额，并保留进程树内存限制、超时与取消回收；失败保留基础视频和此前仍有效的成片。前端不取得本地私有路径。

## 已完成的验证

- 模板、规划器、模型分组、教练生命周期与资源保护组合回归通过。覆盖全片边界、重复触点、观测缺口、建议依据、版本失效、自有／共享任务取消、失败保留和账号隔离。
- 整链路测试实际运行教练引擎、任务管理、规划器和受保护的 MP4 编码；只有模型响应和知识审核使用合成替身，网络与上游重新识别被禁止。生成动作／数据／重点三类段落，核对完整解码、原片末帧和原素材摘要。
- 前端构建、已有单元检查、原教练交互检查，以及 1280／390 像素的模板生成、取消、下载、切换记录、过期与失败恢复检查通过。界面截图中的构造媒体不代表视频质量验收。
- 用既有真实素材和自动证据运行本地渲染，得到 720×880、30 FPS、1159 帧、约 38.63 秒的检查视频。该次**没有云模型报告**，因此如实输出完整未知慢放与基础数据，没有人工编造动作解说来冒充 Agent 结果。
- 已在浏览器完整播放该真实素材检查视频，并检查手机尺寸。拖动后原生播放器时间从约 13.0 秒变为 31.15 秒，实际呈现对应统计画面。检查后修正孤立标点、统计断行及暂停控件遮字。

本地检查文件在项目 `.tmp/replay-template-integration-20260930/`；输入媒体、原有样片和证据均保留，未上传或提交。最终离线渲染检查为 `template-observation-check-v4.mp4`，其计划为 `plan-v3.json`（v4 只调整字幕安全区），指标在 `render-metrics-v4.json`。

## 尚未完成的验收

本轮实现与受控联调完成，**真实云模型针对用户素材创作的语义质量、用户对新模板的视觉验收、真实手机及 4 GiB 服务器验收仍未完成**。已有知识审核限制没有被绕过；当前可用知识不足时只能输出观察与数据，不能保证每条视频都有修改建议。

没有读取输出或改写 `.local` 中的用户数据、照片或密钥，没有生产部署、推送或上传真实媒体。网页服务重启后加载新功能；真实云调用仍通过现有网页同意与费用确认流程发起。
