# 个性化攀岩复盘 Agent：本地原型

初版日期：2026-09-25；当前合同更新：2026-09-27。范围为成人室内抱石、单次报告，接在现有 AI 复盘之后。本文说明代码与接入方式，不代表已经通过真实视频效果或专业审核，不涉及生产部署。当前以[修改报告与建议边界](个性化攀岩复盘_修改报告与建议边界_2026-09-26.md)收紧后的合同为准。

## 用户流程

1. 完成现有 AI 复盘，保留可播放的分析副本或复盘叠加视频；遵循原有保留与删除选择。
2. 点击「生成个性化复盘」，可以跳过全部个人信息，也可以填写目标、关注片段、身高、臂展、体重、经验和自愿提供的本次感受。
3. 通过本地资料检查，阅读独立的云端处理与费用说明，确认成人室内抱石及本次处理授权。没有获准主张时，必须明确选择仅生成观察。
4. 等待独立报告任务完成。原有复盘仍可查看，不重新运行岩点或姿态识别。
5. 先看「可以尝试／先核对／资料不足」状态，再看唯一重点、验证方法和具体缺失原因；最多一项技术建议。姿态与个性化分析费用分列，失败、取消和此前重试的已知费用也可查看。点击时间回看，在条目上标记「有帮助／看错了／不适用」及可选原因。

第一次没有云端配置时，页面显示服务尚未配置，不生成假报告。生成失败可以重试；相同输入的重复点击复用进行中或成功的报告。停止或撤回授权后，不再继续后续模型调用，已发送的请求不能从供应商端撤回。

## 当前真实能力及限制

- 从仍可用、已授权的无叠加分析副本优先解码；缺失时使用已有叠加视频，不恢复已删素材、不延长保留。以带时间标记的图片序列做概览和候选局部采样，最长边 768 像素；这不是逐帧审阅完整视频。
- 观察阶段只接收画面、媒体类型与必要定位信息，不发送个人背景、目标或原因猜测。第二次查看局部画面寻找遮挡、记录冲突、正常解释和时序反证；通过后才匹配获准主张、核对逐项条件。无获准知识时不调用建议整理。
- 骨架平滑线、二维角和接触持续阈值不充当真实受力、承重、深度或伤害判断。程序校验不能保证模型所述画面事实一定正确，仍需人工核对。
- 当前知识库 24 个单元保留原有状态，未批准任何技术主张。因此实际运行仍为观察模式，不把单元内研究摘要写成个人动作原因，不生成自动技术调整。
- 技术权限以具体主张及版本为单位，要求可核对的来源定位、实际教练审核记录、独立验收记录和全部必要条件证据。一个单元获准不能批准其中其他主张；未知条件、记录缺失或撤回均拒绝。详见 `docs/bouldering-knowledge/` 的主张与验收合同。
- 体重选填，背景缺失不补默认能力；不诊断伤病，不生成个人受伤概率、康复／减重／周期训练方案，也不保证完攀。
- 第一版暂停个性化伤害风险结论，`risk_reminders` 始终为空。自述不适或活动限制会阻止动作处方，不把缺填解释为没有不适。体重只存本次快照，不发送模型；其他信息仅按当前步骤必要性使用。
- 原型没有聊天、长期档案、多次尝试因果分析或知识自动学习。反馈仅保留在本次报告。

## 服务端配置

使用指定项目的 `start-photo-local.ps1` 启动方式。配置通过后端进程环境提供，不从前端填写、返回或记录密钥。

前端热更新不会自动更新运行中的后端。新增接口后需要先确认没有任务正在处理，停止旧的本地后端，再执行 `./start-photo-local.ps1 -BackendOnly`；该模式保留已运行的 4176 前端，使用原数据目录启动 8004 后端，并核验复盘接口已加载。不要直接重复启动仍占用端口的服务。

如果页面提示「个性化复盘服务尚未加载」，先检查后端是否更新；如果提示「服务尚未配置或开放」，接口已经存在，需要配置下表的视觉服务。两种状态均不会偷偷创建云端分析任务。

| 环境变量 | 用途与默认 |
|---|---|
| `ENABLE_REPLAY_COACHING` | 默认为 `true`；设置为 `false` 可关闭新增入口的生成能力 |
| `REPLAY_COACHING_API_KEY` | 专用阿里云百炼密钥；缺省时读取 `DASHSCOPE_API_KEY` |
| `REPLAY_COACHING_MODEL` | 默认为 `qwen3-vl-plus`，报告保留实际响应模型标识 |
| `REPLAY_COACHING_BASE_URL` | 默认为 `https://dashscope.aliyuncs.com/compatible-mode/v1`；支持北京工作空间 `https://<工作空间ID>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |

仅允许上述北京 HTTPS 端点，不跟随重定向。供应商地域、模型可用性、密钥权限及余额需要在实际启用环境确认。本次自动测试不调用真实云端，不读取项目 `.local/`，不上传用户素材。

参考：[阿里云图像与视频理解](https://help.aliyun.com/zh/model-studio/vision)、[OpenAI 兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。模型支持图像输入不等于已通过攀岩专项验证。

## 最小接口

共同前缀为 `/api/climb-replay`，全部通过现有登录账号验证，报告响应禁止缓存。

| 方法与路径 | 行为 |
|---|---|
| `GET /coaching-policy` | 返回是否开放／已配置、模型及本次数据处理告知，不返回密钥 |
| `GET /jobs/{id}/coaching/preflight` | 只读检查视频可读性、时长、媒体版本与知识状态，返回费用预算，不发起付费调用 |
| `POST /jobs/{id}/coaching` | 保存可选背景与目标快照及独立授权，异步生成报告 |
| `GET /jobs/{id}/coaching` | 查询状态、报告、使用的背景快照、依据是否更新及反馈 |
| `POST /jobs/{id}/coaching/cancel` | 停止本次报告的后续处理 |
| `POST /jobs/{id}/coaching/consent/withdraw` | 撤回本次报告的云端处理授权 |
| `POST /jobs/{id}/coaching/feedback` | 对当前报告条目提交三种固定反馈之一 |

生成请求包含 `consent_version`、`consent_granted`、`adult_confirmed`、`indoor_bouldering_confirmed`、`budget_accepted`、无获准知识时必需的 `observation_only_accepted`、可选 `personal` 和 `context`。新授权版本为 `replay-coaching-evidence-v2-2026-09-27`。关注片段若填写则同时提供起止时间，以当前复盘播放器时间为准。

状态为 `none / queued / running / succeeded / failed / cancelled`。`stale` 单独表示报告引用的依据已变化；新数据不会静默改写旧报告。报告包括 `overview`、`observations`、`improvements`、`risk_reminders`、`next_attempt`、`limitations`、`coverage`、`knowledge_status` 及 `provenance`。

报告 `result_status` 为 `try / review / insufficient`；`no_advice_reasons` 给出原因码与具体说明。每个观察／建议都引用实际发送的抽样帧及时间；技术建议引用具体主张版本。模型原始输出、图片、请求头与完整错误信息不持久化。

报告外层返回 `cost`、`usage_ledger` 和 `previous_attempt_costs`；每次请求发出前与响应后记录最小用量，晚到用量归入原任务或其历史，删除后不重建目录。`partial` 只给 `known_amount`，表示已知部分而非总额；`unavailable` 不显示免费，`not_started` 表示尚未发请求。内部每次生成预算 ¥0.20、最多三次调用，通过调用前预留控制，不能保证供应商精确硬停费；价格版本为 2026-09-27，来源为[百炼公开价](https://help.aliyun.com/zh/model-studio/model-pricing)。

## 版本、个人信息与删除

- 报告与个人背景保存在所属复盘任务内；通用任务列表不返回个人报告内容，只有所属账号可通过报告接口读取。
- 指纹覆盖动作与岩点结果、有效人工修正、实际复盘视频、知识库和模型配置。同时保存生成时的数据、人工修正及视频版本快照；不额外保存抽样图片。个人信息改变形成新报告快照；旧报告保留为该任务内的历史，不混作最新结论。
- 动作段复核不会重绘现有叠加视频，报告引用新修正时仍需核对画面。优先无叠加分析副本；仅剩叠加视频时优先最新修订版。审核记录、主张和验收记录也参与版本指纹。
- 视频删除使依赖它的报告失效，并停止在途处理。整次复盘删除会删除报告、历史、反馈与背景；报告写入与删除共用锁，迟到的云端响应不能重建已删目录。
- 服务重启将未完成报告标为失败，保留已知与未知用量，由用户主动重试，不自动重复付费调用。后台报告任务不因切换页面而取消。旧规则报告保留原文，但页面不作为当前行动建议展示。

## 本地验证与后续放行

构造视频和模拟模型测试用于检查程序行为，不作为动作准确率或建议有效性结果。覆盖可定位画面、未知处理、引用过滤、知识审核门槛、个人字段缺失、重复提交、账号隔离、超时、数据修订、撤回、媒体删除、整次删除及重启恢复。前端测试覆盖报告操作、时间跳转、授权、反馈和移动端显示。

初版历史检查（并非当前版本验收结果）：相关后端 108 项、前端检查 108 项、浏览器检查 10 项全部通过，生产构建通过。当时仅支持叠加视频，当前合同已改为优先已有无叠加分析副本。当前检查与未完成的专业验收见[本轮实施与验收记录](个性化攀岩复盘_实施与验收记录_2026-09-27.md)。构造素材与模拟服务检查不证明真实攀岩动作判断准确。

可复现检查入口：

- 在已安装后端依赖的环境中，进入 `backend` 执行 `python -m unittest test_replay_coaching_engine test_replay_coaching_lifecycle test_replay_coaching_integration -q`。
- 进入 `frontend` 执行 `node --test test/*.test.mjs` 验证已有前端行为，`npm run test:coaching` 执行模拟接口浏览器检查，`npm run build` 检查生产构建。
- 浏览器检查自动启停独立的 `4181` 测试服务。已有测试服务时可用 `COACHING_TEST_URL` 指定；`PLAYWRIGHT_MODULE` 可指定本机 Playwright 安装路径。它不会调用生产服务或读取真实复盘。
- 构造案例截图位于 `frontend/test-results/coaching/`，只用于检查界面。视觉风格继承 `docs/ui-style-standard/DESIGN.md`，本次未修改全站设计标准。

专业效果验证另行执行：以明确授权的真实素材形成开发集和独立集，分别评估可见事实、建议适用性和用户能否理解下一步。技术建议需抱石教学经验审核者核对，伤害风险主张需对应专业审核。未取得这些结果前保持当前调用限制，不发布准确率、体力节省或降低受伤率的声明。

## 2026-09-26：重点、表达与费用修正

- 首要重点优先展示有审核知识支持的第一项建议。没有建议时，只有模型明确选出、说明原因且有前后画面支持的片段才可作为“先核对这一段”；不得默认把起步或最早观察当成改进重点。其余观察折叠展示，知识原文放入依据中。
- 生成时不允许用视频标注、骨架或岩点编号作为独立观察事实；单帧不支持换点、转身等动作过程。拦截明显违反这些约束的条目不代表其余观察已经准确，仍须专项验证。
- 每次视觉请求记录实际模型与输入、输出 token。费用按北京 Qwen3-VL-Plus 的单次请求档位估算，页面单列个性化分析费用。历史报告只有合计 token 时显示范围；缺失用量时显示无法估算，不记作零元。公开价格不含免费额度、缓存或活动优惠，实际扣费以百炼账单为准，姿态费用另计。
- 生成规则版本参与新任务去重，用户主动重新生成可以使用新规则；旧报告保留原内容，读取时可补充费用估算。未审核知识的门槛继续保留。

本次修正验证：相关后端 50 项、前端展示与浏览器 13 项通过，生产构建通过。检查使用构造素材与模拟响应；未重新上传真实视频验证新报告质量。
