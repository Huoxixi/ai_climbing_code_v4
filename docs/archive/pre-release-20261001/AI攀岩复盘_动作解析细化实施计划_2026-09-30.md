# AI 攀岩复盘动作解析细化实施计划

日期：2026-09-30。状态：本地首轮功能、三条开发样片和验收工具已交付；独立真实识别验收未完成，未部署生产。用户已确认暂时没有独立审核者和素材，先完成本地交付。具体结果见[本地实施交付报告](AI攀岩复盘_动作解析细化本地交付报告_2026-09-30.md)。

本计划将视频复盘中的“向上移动、移动换点、调整位置”细化为有画面依据的动作描述，让用户看清哪只手脚做了什么、怎样接到岩点，以及哪些专业技术确实可辨认。实施顺序为基础动作、接触关系、专业技术标签，再根据验收结果决定是否训练专用模型。知识库提供术语定义和解释，视频证据决定是否可以使用这些词。

沿用用户确认的岩点修订复盘框架：左侧真人和彩色骨架及岩点、右侧线路动作图、下方动作顺序和旁侧解析字幕。此次升级的主要交付是更准确的动作名称和时序描述。

## 一 当前基础和需要解决的问题

2026-09-30 只读检查发现，解析模型提示、后端校验、前端字幕和视频导出均限制在 `move_up / move / adjust` 三类。仅修改字幕映射，无法补足并手、换脚、交叉手等判断所需的信息。

| 已有基础 | 本次如何使用 |
|---|---|
| [动作命名体系与标签词典](../../AI攀岩复盘_动作命名体系与标签词典_2026-09-21.md)及[中文动作总表](../../AI攀岩复盘_攀岩动作中文总表_2026-09-21.md) | 沿用基础动作、动作关系、技术标签三层结构及既有代码，补充实际判定条件和展示模板 |
| [抱石知识库](../../bouldering-knowledge/README.md)的24个知识单元 | 映射换脚、并手、连续换点、交叉手、高抬脚、旗式和沉膝等内容，保留原审核状态 |
| 原片时间、17点姿态、岩点、接触候选和局部画面复核 | 作为动作整理的输入，接触候选经过核对后才用于命名 |
| [基础复盘框架](基础AI复盘框架_字幕与结尾数据_2026-09-30.md)及三条已有样片 | 回归字幕、时间线、导出和结尾展示，逐条核对新旧描述 |

现有17点姿态没有脚跟、脚尖和手指细节，不能单独支持勾脚跟、勾脚尖或抓握类型。已有知识单元仍有专业审核和真实视频验证缺口；检索命中不能证明视频中发生了对应技术。已有局部模型复核也不能代替独立人工验收。

## 二 用户能够看到的结果

下面均为目标效果的构造示例，不是对现有素材的识别结论。每个句子只在对应证据成立时展示。

| 现在的描述 | 目标描述 | 需要确认的事实 |
|---|---|---|
| 右手向上移动 | 右手向上伸手够点，随后接触上方岩点 | 手的连续路径、目标位置和接触过程 |
| 左脚移动换点 | 左脚抬高，落到上方脚点 | 抬脚过程和新脚点接触 |
| 左手调整位置 | 左手在原岩点重新抓握 | 同一岩点身份及可见重新抓握，不能只是手腕抖动 |
| 右手移动换点 | 右手接到左手所在岩点，形成双手并点 | 两手在同一岩点的接触确有重叠 |
| 右脚移动换点 | 左脚离点后，右脚接替同一脚点 | 先后接触顺序、脚点身份和允许的时间间隔 |
| 右手向上移动 | 右手交叉够点，随后接触目标 | 跨越关系与完整出手路径可见，且已完成对应复核 |
| 左脚移动 | 左脚离点，随后重新接回脚点 | 离点和再次接触均可见；不据此推断脚滑或力量不足 |

动作顺序主标签继续保留“01 左手、02 右脚”等形式，旁边增加准确的中文名称。用户点击动作可以重看片段、查看证据、修改名称或撤销技术标签。识别不足的部分明确说明，例如“左脚换点，中间路径被遮挡”；缺失信息不补成完整动作故事。

## 三 词汇和判定规则

### 基础动作

基础代码优先复用现有 `HAND_MOVE / FOOT_MOVE / HAND_CONTACT / FOOT_CONTACT / HAND_RELEASE / FOOT_RELEASE / HAND_READJUST / FOOT_READJUST / HAND_ATTEMPT / FOOT_ATTEMPT`。伸手、抬脚和落脚属于细化的可见过程；第一阶段确定它们是阶段属性还是必要的新增代码，避免建立第二套同义词典。

| 词语 | 最低判定条件 | 证据不足时的处理 |
|---|---|---|
| 伸手够点 | 确认左右手及连续伸手路径；若点明目标，还须确认目标 | 仅记录可见伸手，不宣称已抓住或成功上点 |
| 手部换点 | 确认前后使用不同岩点 | 起点未知则记录新接触，不编造起点 |
| 抬脚上点 | 确认向上的脚部轨迹和目标接触 | 只看见抬脚则只写抬脚，不写落点 |
| 横向换点或向下换点 | 确认墙面配准、方向和前后岩点 | 配准不可靠时只保留换点 |
| 原点重新抓握或重新踩放 | 确认同一岩点和实际调整过程 | 点内细节不清则写手部或脚部位置调整 |
| 离点 | 接触结束可见 | 遮挡造成轨迹消失不算离点 |
| 尝试触点或尝试踩点 | 触点可见，随后未保留有效接触，观察窗口足够 | 后续缺失则写触及目标、后续未确认 |
| 撑墙或踩墙 | 原片看清接触在墙面区域，接触过程可复核 | 不把无岩点匹配自动归为墙面接触，也不由接触推算承重 |

“抬脚上点”与“高抬脚”分开：前者描述向上落脚，后者是需要身体比例、姿态和可比视角支持的技术标签。触及目标、接触保留、后续继续分别记录，不能用某个停留阈值证明真实受力或稳定完攀。

### 动作关系

| 关系 | 判定依据 | 首轮准入方式 |
|---|---|---|
| 双手并点，内部沿用双手匹配 `HAND_MATCH` | 两手同时接触同一岩点 | 已核对接触关系后自动生成 |
| 双脚并点 `FOOT_MATCH` | 两脚同时接触同一岩点 | 已核对接触关系后自动生成 |
| 换手 `HAND_SWAP` | 原手离开，另一手接管同点 | 连续画面核对；与先并手再离手分别记录 |
| 换脚 `FOOT_SWAP` | 原脚离开，另一脚接管同点 | 连续画面核对；脚尖局部被挡则保留候选 |
| 同手或同脚连续换点 `BUMP` | 同一肢体连续接不同点，中间没有完整稳定段 | 确认事件和时间阈值后生成候选 |
| 手脚同步动作 `SIMULTANEOUS` | 两个以上肢体活动区间确有重叠 | 保存各原子事件，不制造先后顺序 |
| 交叉手 `CROSS` | 手的完整路径、留手和身体中线关系可辨认 | 首轮候选或人工确认 |

时间窗、接触保留时长和稳定阈值先在开发材料上确定并冻结。任何合并关系都保留组成事件；双手并点不能被误写成换手，顺序不清时不用“随后”。

### 专业技术标签

| 批次 | 标签 | 必要补充证据 |
|---|---|---|
| 优先研究 | 高抬脚、侧身转髋、交叉手、外侧旗式 | 可靠身体尺度、肩髋及四肢轨迹、支撑脚接触和完整阶段 |
| 第二批研究 | 后旗式、内侧旗式、沉膝或埃及式、Rock over | 腿部前后关系、膝髋旋转、脚点和身体经过过程；深度关系不清则不细分 |
| 局部细节研究 | 勾脚跟、勾脚尖、撑上 | 鞋与岩点接触部位、手部动作及平台或边缘关系 |
| 高频时序研究 | 动态够点、跳跃、双手跳跃 | 原片较密采样，起动、接点及可能的腾空全过程；快速伸手本身不能证明跳跃 |
| 后续人工标签 | 半扣、全扣、捏握、侧拉、反扣、卡膝等 | 手指形态、接触方向或复杂身体关系，普通全身视频不足时只人工添加 |

优先研究不等于自动放行。每个标签独立通过定义、画面判定和留出集验收后，才允许自动确认为该技术。技术状态独立于基础事件状态：基础换点已确认、旗式仍为候选时，主字幕只陈述换点，详情显示旗式候选。

每个词条要保存中文首选名、英文名及别名、已有代码、简明定义、必要画面、排除条件、易混动作、合格及不合格构造例、来源和版本。名称描述发生的动作；省力、力量不足、动作错误和失败原因属于另一类判断，不随命名升级自动开放。

## 五 识别流程和记录结构

计划采用以下处理顺序：

1. 核对原片、基础复盘、线路岩点及当前分析版本的对应关系。
2. 通过姿态轨迹定位候选窗口，读取动作前、动作中、目标接触和后续衔接的原片画面。
3. 核对肢体身份和接触变化，生成可见基础事件。
4. 在确认事件上计算并点、换手、换脚、连续换点等关系。
5. 仅对具备必要画面的片段判断专业技术候选，按标签分别复核。
6. 从受控词典和模板生成名称及短字幕，供页面、时间线和独立导出共同使用。
7. 保存版本、依据和用户修改；复核不足则回退到已确认的较基础描述。

### 采样和时序

保留现有全片粗采样，用于定位而非证明精细技术。候选区间按原片时间局部增加采样，慢动作先试8至12帧每秒，快速动作先试原片帧率且最高30帧每秒；这些是实验起点，最终按原片质量、误差和成本确定。低帧率素材不能插帧后当成新增事实。

短时腾空或鞋部接触变化未被采样覆盖时，记录证据不足。优先读取固定范围的身体裁剪及相关岩点局部；脚部放大仍须保留膝髋和左右连续性，不能凭单张鞋图猜肢体归属。

准备、肢体转移、接触建立、稳定或衔接各阶段允许缺失。采样不足时记录边界区间及时间误差，不输出伪精确时间。重叠动作使用“同时”，连续且顺序明确才使用“随后”。

### 数据合同

沿用既有动作词典字段，并以新分析版本增量保存；具体字段命名在第一阶段冻结。

| 信息组 | 必需内容 |
|---|---|
| 身份和版本 | 动作ID、顺序、肢体、原片与线路版本、命名及模型规则版本 |
| 事件和接触 | 基础动作代码、原片起止时间、阶段区间、起点和终点及其独立确认状态 |
| 组合关系 | 关系代码、组成事件ID、重叠或先后时间依据 |
| 技术标签 | 标签代码、候选或确认状态、各自的必要条件及排除条件检查 |
| 证据和复核 | 帧ID及时间、可见性、遮挡和冲突、自动复核来源、人工修改记录 |
| 展示 | 统一短名称、字幕、可跳转证据；展示内容由已放行字段生成 |

模型只能返回受控字段，不直接写面向用户的自由解释。必要条件使用满足、不满足、未知三态；未知不能被当成满足。模型自报置信度只作辅助，不单独决定标签放行。

旧版 `locally_verified` 表示既有局部检查通过，不等于接触身份、专业技术或人工审核均通过。升级时拆分基础事件、接触关系和技术标签的审核状态，不能将一个旧状态复制成所有字段已确认。

基础事件和专业标签支持一对多关系，技术名称可以同时出现；短字幕优先显示一个主动作及必要补充，详细标签放入详情。一个动作可以同时包含抬脚、转髋和伸手，不强制用一个互斥分类覆盖整段。

## 六 分阶段实施和交付

下列时间是单人顺序开发的初步工作量估计，非承诺发布日期。真实素材取得、人工标注、专业审核和模型训练另计。每阶段都先完成可核对产物，再按验收结果进入下一阶段。

| 阶段 | 主要工作 | 可核对交付 | 完成条件 | 初步工作量 |
|---|---|---|---|---|
| 第一阶段 统一词典和证据合同 | 对齐旧词典、补齐易混定义、冻结字段和标注规则、记录当前基线 | 词条清单、字段合同、标注说明、新旧描述对照表 | 每个词均有条件、排除项和来源；明确已有定义中的歧义 | 1至2工作日 |
| 第二阶段 基础动作和字幕 | 扩展三类接口、核对接触、增加局部采样、统一页面与导出文案 | 基础动作原型、三条样片逐事件核对、新版独立视频 | 基础命名可追溯，成功接触与尝试分开，旧数据兼容 | 2至3工作日 |
| 第三阶段 接触关系 | 并手并脚、换手换脚、连续换点、同步关系及人工修正 | 关系解析原型、易混案例、修改和撤销流程 | 不虚构时序，复合动作保留原子事件，修正后显示一致 | 2至3工作日 |
| 第四阶段 专业技术候选 | 先研究交叉手、高抬脚、转髋及外侧旗式；对照局部图和姿态后端 | 按标签的错误报告、候选展示、姿态对照结果 | 专业候选不混入已确认字幕，每类分别满足准入条件 | 3至5工作日 |
| 第五阶段 独立验收和本地交付 | 冻结版本、双人独立标注、留出测试、新旧比较和成本汇总 | 验收报告、合格词条清单、最终样片、回退记录 | 指标与展示回归均通过；未通过类别继续候选或人工 | 验收材料和审核排期决定 |
| 后续模型实验 | 根据误差决定是否使用MMAction2，扩展勾脚跟、勾脚尖和动态动作 | 规则与模型对照、训练记录、标签专用结果 | 专用模型在相同留出材料上证明有益后才接入 | 另行估算 |

第二、三阶段开发工作量合计约4至6工作日，目标是先形成基础细化与关系解析的可试看版本。第一至四阶段合计约8至13工作日，不包含独立效果验收时间。某种技术材料不足时，不阻塞已具备证据的基础动作交付。

第一阶段还需审查旧文档中可能偏宽的等级，例如高抬脚是否仅凭接触即可确认、双脚先后同点是否应算匹配。保留修订依据和版本差异，本计划的细化规则是拟议更新，不静默改写已有词典。

## 七 素材和验收标准

### 材料组织

已有三条样片用于开发演示和展示回归。使用前核对实际读取路径、源片与分析版本及使用范围；获准用于复盘不自动等于获准用于训练。它们不计作独立留出材料，也不承诺覆盖全部技术标签。

开发集起步目标为10至15次完整攀爬，至少100个可核对基础事件，包含正常换点、点内调整、并手与换手、并脚与换脚、遮挡、快速动作和多肢体重叠。这是寻找错误的工作目标，不是通过准确率验收的样本量。

正式留出按攀爬者和线路分组隔离；同人或同线路有关联的材料不能跨开发和留出集。正面、斜侧面、不同墙角度、遮挡程度及快慢动作分别报告。首轮拟放行范围为固定机位、画面清晰且单一攀爬者可跟踪的室内抱石，其他场景保持候选或基础描述。

两名不同审核者先独立查看连续原片，再处理分歧。标注基础事件、接触身份、动作关系、技术标签和不可判定状态；必要时由有抱石教学经验的审核者统一术语。人工确认的个人修改不混入自动识别成绩。

素材与身份资料不放入公开知识库。评估表只保存匿名分组ID、标注结果、版本和证据定位，原片留在获准的本地位置；不读取输出、覆盖或上传 `.local/` 内容。

### 拟议准入门槛

以下为本项目拟议验收目标，不是引用研究给出的行业标准。第一阶段结合错误后果和材料可得性冻结，冻结后不能根据留出结果放宽。

| 项目 | 拟议门槛及口径 |
|---|---|
| 基础命名正确率 | 正式显示的细化基础描述至少95%正确；左右、动作、接触及目标中任一错误均算整条错误 |
| 关系识别正确率 | 每类单独至少95%，不以总体平均掩盖换脚或换手误报 |
| 专业标签正确率 | 每个自动确认标签至少95%，95%区间下界至少90%；不足则仅候选或人工 |
| 最低材料量 | 每个拟自动确认类别至少60个真实正例、60个易混或负例，且至少20个独立分组；用于初步放行，仍结合不确定区间决定 |
| 漏检及覆盖 | 基础动作在人工判定可辨认范围内召回率目标至少85%；同时公布全范围覆盖率、可辨认机会覆盖率和漏检数；零输出不能算通过 |
| 遮挡和冲突 | 必要条件未知时不确认专业标签；留出材料中不得出现依据缺失仍放行的事件 |
| 时间定位 | 粗采样事件起止误差初始目标不超过0.5秒，局部加密目标不超过0.25秒；报告逐类中位数及95分位，低帧率素材单列 |
| 页面与导出 | 同一事件的名称、状态、源片时间和依据一致，暂无确认的技术不能在导出中变成事实 |

正确率、召回率和覆盖率分别报告分子分母。专业标签的多选问答正确率不能代替完整视频中的检测结果；连续多帧不当作多个独立样本。采用分组统计与重采样计算区间，分组或材料不足时明确未达到正式验收条件。

新旧对照使用同一留出材料、同一可辨认范围和盲审方式，报告名称细化程度、事实错误、漏检和无法判定比例。候选状态的误报也单独统计。只有在事实准确度不下降且细化覆盖改善时，才能声称比旧版更有用。

成本按整次攀爬统计，失败、重试和无结果仍计入；记录额外采样数量、模型调用、总费用、延迟、内存及显存峰值。第一阶段测出旧版基线后确定目标设备上的费用与延迟上限，未测量前不承诺低成本或实时。

### 功能回归

针对有实际误报风险的场景编写检查：左右交叉、遮挡后的假离点、并手与换手、点内调整与换点、同时动作、碰点后离开、快速伸手与腾空、未知关键点和旧版记录兼容。

页面核对电脑和窄屏下的动作跳转、字幕切换、重叠事件、修正撤销及长中文显示。视频核对独立导出、完整解码、字体、基础画幅保留和源片时间。结尾继续按线路总岩点、去重使用岩点、使用比例及其他指标的既有顺序展示，未观测区间不计停留，圆球展开和收起行为保持。

## 八 展示与人工修正

主字幕采用一到两句短描述，建议每句约12至24个汉字，先写主要肢体和动作，再写确有证据的接触或关系。按屏幕实际宽度验收换行，不通过字号缩小来塞入全部标签。沿用思源或Noto黑体、白色主文字与少量青色强调。

同一原子动作的状态随原片时间变化：够点过程中不提前写“抓住”，接触建立后才显示接触；重复播放、拖动和半速重看都按同一源片时间切换。候选标签在详情中显示“候选”，人工确认明确标记，不能抹去证据状态。

修正入口区分“肢体错了、动作名错了、岩点错了、接触未成立、技术标签错了”。修改只产生当前分析版本下的修订记录，可撤销。改变岩点或接触后，受影响的关系、标签和使用岩点统计标记需重算；不只改文字而保留错误计算。

基础视频中的既有动作图可能属于较早版本。解析叠加必须明确对应关系，不能直接把旧图编号当作新岩点身份；有版本差异时保留可核对说明。新结果独立保存和导出，既有原片、基础复盘和历史分析保留。

从当前指定本地工作区的最新状态继续，保留已有未提交改动。功能通过独立分析版本和开关回退；不批量改写历史数据、不改照片线路默认识别链路。生产部署在用户明确提出部署任务后，按项目标准发布通道执行。
