# 视频岩点识别准确度增强方案

更新日期：2026-09-23
适用范围：AI 攀岩复盘中的线路岩点识别、颜色辅助筛选、既有照片线路复用和手脚接触计算。
当前性质：分层实施中；只完成的层级以本节记录为准，不代表整体方案已经验收或部署。

## 1. 目标与原则

本方案只增强视频中“哪些对象是岩点、岩点轮廓在哪里、哪些岩点属于本次线路”的准确度，并为后续手脚接触判断提供更稳定的固定岩点地图。

目标链路调整为：

> 视频质量检查 → 多帧选取 → 墙面配准 → 多帧专项模型识别 → 实例融合 → 已保存线路优先匹配 → 样本颜色辅助筛选 → 用户快速复核 → 固定岩点地图 → 姿态与接触计算

长期遵守以下原则：

1. **岩点身份由几何、跨帧稳定性、专项模型置信度和用户确认共同决定，颜色不能单独决定岩点身份。**
2. **颜色只用于缩小候选范围和线路成员排序。**颜色判断失败不得删除模型置信度较高或已被用户确认的岩点。
3. **已保存、已确认的照片线路优先级最高。**但必须先完成照片与视频坐标配准，不能直接复制像素坐标。
4. **默认继续使用攀岩岩点专项实例分割模型的原生掩膜。**不恢复整墙 MobileSAM、云端视觉复核、孔位推断或背景生成。
5. **保留完整证据。**每个最终岩点都能追溯到来源帧、模型结果、配准结果、颜色相似度和用户修改。
6. **不自动改写历史照片线路。**视频分析产生的校正只属于本次复盘；用户明确保存时，才形成视频侧的确认结果。

## 2. 当前问题

改造前的视频识别从视频 5%～95% 区间均匀取 9 帧，计算中位数背景，再只对该合成背景运行一次专项模型。之后依据用户选择的固定颜色名称进行硬筛选。

该方式存在以下主要误差：

- 人物持续遮挡同一区域时，中位数背景仍会保留人体、镁粉或残影。
- 相机轻微移动、电子防抖、自动对焦和曝光变化会让多帧合成后的岩点边缘变软。
- 运动模糊、视频压缩和斜拍透视与照片模型的训练分布不同。
- 一次推理无法利用“同一岩点在其他帧更清楚”这一证据。
- 颜色分类错误会把轮廓正确的岩点直接过滤掉。
- 黑、白、灰等低饱和颜色容易与阴影、墙面和镁粉混淆。
- 上传时虽然能关联已有线路，但当前分析仍主要依赖线路颜色，没有真正复用已确认的线路几何。

这十二个名称是产品快捷入口，不是十二个绝对 HSV 区间。系统内部保留连续的 Lab/HSV 颜色特征和现场样本色；即使两个场馆都叫“绿色”，也允许它们具有不同的实际颜色中心和容差。

颜色选择规则：

- 用户可以直接选择十二种快捷颜色之一。
- 用户也可以在视频画面中点选一个清晰的样本岩点，以该视频中的真实颜色为准。
- 选择快捷颜色后仍可补充样本点；此时名称用于展示，样本用于计算。
- 已保存线路已包含确认过的线路成员时，不要求用户重新选择颜色；颜色只用于发现可能遗漏的同线路岩点。
- 同色线路无法仅靠颜色区分时，必须依靠已保存线路、空间结构和用户复核。

## 4. 总体架构

### 4.1 两条入口、一个统一结果

#### 入口 A：关联已保存线路

优先用于用户已经通过照片线路流程确认过岩点的场景：

1. 读取已保存线路的原照片、岩点原生轮廓、线路成员和确认状态。
2. 从视频选取清晰墙面帧。
3. 计算照片到视频基准帧的墙面配准变换。
4. 将已保存线路轮廓投影到视频坐标系。
5. 使用视频多帧专项模型结果对投影轮廓做匹配和验证。
6. 保留匹配成功、配准可信的线路成员；将冲突和遮挡对象交给用户复核。

#### 入口 B：没有已保存线路

1. 用户选择十二种快捷颜色，或从画面点选样本岩点。
2. 多帧运行专项模型，得到整墙岩点候选。
3. 对齐并融合跨帧实例。
4. 使用颜色相似度对候选排序，而不是硬删除。
5. 用户确认线路成员后生成固定岩点地图。

两个入口最终输出相同的版本化结果：墙面基准帧、配准信息、岩点轮廓、线路成员、颜色证据、跨帧证据、用户复核状态和模型版本。

### 4.2 置信度分层

每个最终岩点分别记录四类分数，避免把不同含义压成一个数字：

- `detector_confidence`：专项实例模型对“这是岩点”的置信度。
- `temporal_stability`：该实例在多少个清晰且未遮挡帧中稳定出现。
- `registration_confidence`：跨帧或照片到视频的配准可靠程度。
- `route_similarity`：与样本颜色、已保存线路空间结构的相似程度。

最终状态分为：

- **已确认**：来自已保存线路且配准、视频候选匹配通过，或用户人工确认。
- **高可信候选**：专项模型和跨帧证据充分，但尚未人工确认。
- **需复核**：颜色、几何、遮挡或配准存在冲突。
- **已排除**：用户排除，或多项证据一致表明不是岩点。

颜色相似度低只能把对象降为“需复核”，不能把已确认岩点自动删除。

## 5. 多帧识别、对齐与合并

### 5.1 候选帧选择

不再固定只取 9 帧并合成一次背景。建议把视频分成时间段，每段选取清晰度和墙面可见度较好的帧。

初始参数建议：

- 90 秒视频最多生成 24 个岩点检测候选帧。
- 每 3～5 秒至少检查一个帧窗口，而不是只按总时长等距抽取。
- 最终进入专项模型的帧建议为 8～16 帧，按质量和覆盖率动态决定。
- 至少保留视频前段、中段、后段各一帧，防止只覆盖攀爬过程的局部状态。

帧质量评分包含：

- 拉普拉斯清晰度或等价的模糊评分；
- 过曝、欠曝比例；
- 与相邻帧的相机位移；
- 人体对墙面的遮挡比例；
- 墙面可见面积；
- 解码完整性。

严重模糊、曝光失败或墙面大面积离开画面的帧不进入岩点推理，但仍可用于姿态分析。

### 5.2 基准帧

从候选帧中选择一张作为固定岩点地图的基准帧。优先条件为：

1. 墙面覆盖完整；
2. 人体遮挡少；
3. 清晰度高；
4. 与多数候选帧可以稳定配准；
5. 若关联已保存线路，则与线路原照片的配准质量高。

中位数背景仍可保留为辅助证据和展示备选，但不再作为唯一的模型输入。

### 5.3 墙面配准

对每个候选帧计算到基准帧的几何变换：

- 第一选择：墙面纹理与稳定特征点匹配，使用 RANSAC 估计单应性矩阵。
- 特征不足但相机基本固定时：使用光流或仿射变换作为受限回退。
- 相机明显平移、变焦、墙面非近似平面或残差过大时：该帧不参与实例融合。

配准必须记录：匹配点数量、内点比例、重投影误差、变换类型和失败原因。

建议初始门槛由验证集确定，不能直接写死为生产结论。开发起点可使用：

- 有效匹配点不少于 20；
- RANSAC 内点比例不低于 50%；
- 中位重投影误差不超过基准帧短边的 0.5%；
- 投影后有效墙面面积不低于原帧的 70%。

### 5.4 多帧专项模型推理

对通过质量门和配准门的每个候选帧分别运行现有攀岩岩点专项实例分割模型：

- 继续使用模型原生掩膜；
- 保留每个实例的原始置信度、类别、掩膜和帧号；
- 不先按线路颜色删除候选；
- 不使用整墙通用分割模型补点；
- 可以按资源限制分批执行，并复用同一次模型加载，避免每帧重复加载权重。

### 5.5 跨帧实例融合

先把每帧掩膜投影到基准帧，再按以下证据聚类：

- 掩膜 IoU；
- 轮廓中心距离；
- 面积比例；
- 形状相似度；
- 内部颜色分布相似度；
- 帧间出现关系。

每个实例簇形成一个最终岩点。建议：

- 使用加权中位数或置信度加权投票生成融合掩膜；
- 人物遮挡明显的帧降低权重，不参与被遮挡区域的负证据计算；
- 某岩点只在一张非常清晰的帧出现时可以保留为“需复核”，不能因为跨帧次数不足直接删除；
- 多帧稳定出现但颜色不同的对象仍保留，标记颜色冲突；
- 两个相邻岩点被某一帧合并、但在其他帧稳定分开时，优先采用分开的实例；
- 同一岩点在单帧产生嵌套或重复掩膜时，先在帧内消重，再参加跨帧融合。

推荐的融合结果同时保存：代表轮廓、各来源帧轮廓、出现次数、可见次数、遮挡次数和冲突原因。

## 6. 从画面点选样本岩点

### 6.1 用户流程

1. 系统默认展示最清晰的基准帧。
2. 用户选择“从画面取样”。
3. 用户点击一个完整、清晰、尽量少镁粉和反光的目标线路岩点。
4. 如果点击位置落在已有岩点候选内，系统高亮该候选并显示取样预览。
5. 如果多个候选重叠，显示局部放大图让用户选择。
6. 如果点击处没有候选，提示用户换一帧取样；后续可增加受控的局部专项检测，但不默认引入整墙通用分割。
7. 用户确认后，系统从多帧中的同一实例提取颜色样本。

用户可以补充第 2、3 个同线路样本，用于处理同一套岩点因朝向、阴影或磨损产生的色差。样本之间差异过大时，不自动扩大范围，而是提示检查是否点到了不同线路。

### 6.2 样本提取

从岩点融合掩膜向内腐蚀后取样，避开边缘墙面；同时剔除：

- 低亮度深阴影；
- 接近纯白的高光和镁粉；
- 被手脚遮挡的像素；
- 与主体颜色差异显著的小簇。

内部颜色表示建议包含：

- Lab 中位数与稳健协方差；
- HSV 色相分布、饱和度和亮度范围；
- 多帧样本的一致性；
- 十二色展示标签；
- 是否低饱和、是否容易受镁粉影响。

候选线路相似度主要使用 Lab 色差和分布距离。HSV 只用于辅助解释和处理色相环，不再用固定桶作为唯一判定。

### 6.3 颜色的使用方式

候选进入以下三个区间：

- **高相似**：默认勾选为线路候选。
- **邻近/不确定**：展示在“可能属于本线路”区域，等待用户确认。
- **明显不同**：默认折叠，但仍可查看和加入。

阈值必须通过标注验证集按颜色和困难条件校准。黑、白、灰、棕等低饱和颜色应采用独立阈值，不和高饱和颜色共用一套距离标准。

## 7. 优先复用已保存线路

### 7.1 复用内容

从已保存照片线路读取：

- 原照片尺寸与摘要；
- 用户确认过的岩点轮廓；
- 线路成员关系；
- 每个成员的颜色标签和确认状态；
- 允许使用时的原照片视觉特征缓存。

不复用未确认候选、旧版粗轮廓或已经失效的自动结果。

### 7.2 照片到视频配准

先尝试自动配准照片与视频基准帧。自动配准成功后，把线路轮廓投影到视频坐标系，再与多帧融合候选匹配。

自动配准不通过时进入手工辅助：

1. 系统并排显示已保存线路照片和视频基准帧。
2. 用户依次点选至少 4 个分布在墙面不同区域的共同岩点。
3. 系统计算单应性并实时显示投影轮廓。
4. 用户确认投影位置，或继续补充校准点。

如果墙面不是近似平面、镜头角度差异过大或只拍到局部墙面，应允许使用分区变换或明确回退到“本次视频重新识别”，不能伪装为成功复用。

### 7.3 保存线路与视频候选匹配

投影后的已保存岩点与视频融合候选进行一对一匹配：

- 几何匹配良好：采用视频融合轮廓，继承已保存线路成员身份。
- 只有投影轮廓、视频中被人物持续遮挡：保留为“来源于已保存线路、视频不可见”，不用于要求可见像素的质量统计。
- 视频找到相邻候选但形状冲突：标记为“需复核”，禁止静默替换。
- 视频发现颜色相似但保存线路中不存在的岩点：列为“可能遗漏”，由用户决定是否加入本次复盘；不得自动回写照片线路。
- 配准失败：不使用旧轮廓，只保留已选择线路的名称和颜色样本作为辅助。

## 8. 用户复核界面

识别完成后，在开始姿态与接触计算前增加一个轻量复核步骤：

- 主画面显示基准帧和融合轮廓。
- 默认突出“需复核”和“可能遗漏”，不要求逐个检查所有高可信岩点。
- 点击岩点可查看其在不同帧中的小图、模型置信度、出现次数和颜色相似度。
- 支持加入线路、移出线路、标记非岩点、切换代表轮廓。
- 支持切换到其他清晰帧检查被遮挡区域。
- 明确区分“这是岩点”和“属于本线路”两个判断。
- 显示已保存线路复用状态：自动配准、手工校准、配准失败或未关联。
- 用户确认后锁定固定岩点地图；后续姿态分析不得重新编号或改变轮廓。

为了避免增加上传等待，可将流程拆成：

1. 本地岩点多帧识别完成；
2. 用户快速确认固定岩点地图；
3. 再开始需要第三方调用和费用的姿态抽帧分析。

这样可以在岩点明显不正确时提前停止，不产生无意义的姿态调用费用。

## 9. 与手脚接触计算的衔接

本方案完成后，接触计算统一使用基准帧中的固定融合轮廓，并把每个姿态帧的关键点通过该帧到基准帧的配准矩阵转换到同一坐标系。

需要同步调整：

- 相机移动时不能直接拿归一化屏幕坐标判断接触；必须先做帧间配准。
- 接触距离应参考岩点尺寸、关键点置信度和配准误差动态设置，不使用所有岩点相同的固定边距。
- 手脚关键点置信度低、被遮挡或配准失败时输出“未知”，不能自动判定为未接触。
- 现有约 0.4 秒停留规则保留为初始基线，但快速点触应作为独立事件类型评估。
- 岩点编号在固定地图确认后生成，叠加视频、右侧岩点图和动作时间线使用同一编号。

## 10. 数据与接口方案

第一阶段优先复用现有复盘任务及其版本化分析 JSON，不立即新增业务表。建议在分析结果中增加以下结构：

```json
{
  "hold_map": {
    "version": "multiframe-holds-v1",
    "reference_frame": 360,
    "reference_size": [1080, 1920],
    "source_route_id": "optional",
    "reuse_mode": "saved_route_auto|saved_route_manual|fresh|fallback",
    "registration_summary": {},
    "color_profile": {
      "display_label": "青色",
      "source": "preset|sample|saved_route",
      "samples": []
    },
    "holds": []
  }
}
```

每个 `hold` 至少包含：

- 稳定 ID；
- 基准帧轮廓和外接框；
- 是否属于线路；
- 来源：已保存线路、视频模型、两者匹配或用户新增；
- 模型置信度和跨帧稳定性；
- 来源帧列表及对应轮廓；
- 十二色展示标签和连续颜色特征摘要；
- 颜色相似度；
- 配准置信度；
- 复核状态和冲突原因；
- 模型、阈值、融合算法和颜色算法版本。

隐私和存储要求：

- 不把原视频或岩点画面发送给新的第三方服务；岩点识别继续在服务器本地完成。
- `.local/`、本地视频、照片、模型和密钥不得提交或上传仓库。
- 失败任务保存必要的数值诊断，但不得在普通日志输出完整图像、账号隐私或密钥。
- 删除整次复盘时，新增的候选帧缓存、颜色样本和融合证据必须随任务一起删除。

## 11. 实施阶段

### 阶段 0：评测基线与标注

在改算法前先建立视频岩点真值集，否则无法判断改善还是退化。

- 至少 12 段视频，覆盖不少于 4 面墙。
- 至少包含固定机位、轻微抖动、斜拍、人物遮挡、明暗变化和手机压缩场景。
- 十二种颜色尽量都有样本；黑、白、灰、青、棕必须单列。
- 每段选择若干基准帧，标注所有可见岩点轮廓和本次线路成员。
- 至少 3 段视频与已保存照片线路配对，用于评估复用与配准。
- 数据划分为开发、验证和独立留出；同一面墙不得跨验证与留出集合。

### 阶段 1：十二色与样本颜色

- 前后端统一十二色枚举和展示色值。
- 将青色、棕色加入快捷选择、历史兼容和测试。
- 引入连续 Lab 颜色描述，不再仅依赖固定 HSV 桶。
- 完成画面点选、候选确认、多帧内部取样和相似度排序。
- 保持旧记录中的八色或十色值可正常显示，不批量重算历史任务。

### 阶段 2：多帧识别与融合

- 完成帧质量评分和动态选帧。
- 完成基准帧选择、帧间配准和失败回退。
- 同一次模型加载内执行多帧专项推理。
- 完成帧内消重、跨帧聚类和融合轮廓。
- 输出完整来源证据和诊断报告。

### 阶段 3：已保存线路复用

- 接通线路原照片、确认轮廓和成员读取。
- 完成照片到视频自动配准。
- 完成 4 点以上的手工辅助校准。
- 完成投影轮廓与视频融合候选匹配。
- 明确配准失败、部分墙面和持续遮挡的降级路径。

### 阶段 4：复核与接触坐标统一

- 增加固定岩点地图复核界面。
- 锁定岩点编号和轮廓版本。
- 姿态帧坐标统一转换到基准帧。
- 根据关键点、配准和岩点尺寸调整接触容差。
- 保证原视频、叠加视频、岩点图和动作时间线同源。

### 阶段 5：观察性发布

- 先对白名单内部账号启用。
- 同时保留旧版单背景链路作为只读对照，不自动覆盖新结果。
- 记录新旧方案的漏检、误检、耗时、内存和用户修改数量。
- 达到门槛后再将多帧方案设为默认；旧任务不自动重算。

## 12. 验收指标

### 12.1 岩点识别

在独立留出视频上：

- 岩点实例精确率 ≥ 92%。
- 岩点实例召回率 ≥ 92%。
- 实例 F1 ≥ 92%。
- 边界 F1 ≥ 0.78，并报告中位数、P10 和最差视频。
- 严重轮廓错误为 0：不得把两个岩点合成一个、把同一岩点重复计数，或大面积包含墙面/人物。
- 相比当前单一中位数背景基线，召回率提升不少于 5 个百分点，且精确率下降不超过 1 个百分点。

### 12.2 线路成员与颜色

- 十二色总体标签准确率 ≥ 90%。
- 使用画面样本后的线路成员 F1 ≥ 92%。
- 黑、白、灰、青、棕分别报告，不得只给总体平均值。
- 低饱和、阴影、镁粉、高光和双色岩点分别报告。
- 颜色错误不得导致已保存线路中已确认岩点被自动删除。

### 12.3 已保存线路复用

- 自动配准成功的样本中，投影后岩点中心中位误差不超过岩点等效直径的 15%。
- 配准不可靠时必须正确进入手工校准或重新识别，不得错误标记为成功。
- 复用已保存线路后，用户需要手工增删的线路成员数量比完全重识别至少降低 50%。
- 视频分析不得修改原照片线路和历史版本。

### 12.4 用户复核

- 普通完整线路的岩点地图复核目标在 30 秒内完成。
- 高可信结果只需确认，不强迫用户逐个重选。
- 所有自动排除、冲突和新增候选均可追溯和恢复。
- 手机端可以完成取样、局部放大、加入、移出和确认操作。

### 12.5 性能与稳定性

- 单个 90 秒视频的岩点阶段目标 ≤ 120 秒，上限 240 秒；姿态阶段单独计时。
- 记录专项模型加载、每帧推理、配准、融合和颜色计算耗时。
- 记录进程树峰值内存；目标生产环境不得发生 OOM 或影响现有服务健康。
- 某些帧失败时任务可使用其余有效帧继续，并在结果中说明降级。
- 服务重启后能够恢复任务，确认过的固定岩点地图不丢失、不重新编号。

## 14. 主要风险与控制

### 14.1 多帧推理增加耗时和内存

控制方式：模型只加载一次；逐帧推理后及时释放不再需要的张量；掩膜使用压缩表示；候选帧数量有上限；先做质量门再推理。

### 14.2 墙面不是严格平面

单应性只适合近似平面区域。明显折面墙应分区处理，或提示用户改用重新识别。第一版不承诺复杂洞穴、强曲面和大范围环拍的精确复用。

### 14.3 颜色数量增加反而增加混淆

十二色只用于展示与快捷选择；内部使用连续颜色样本。相邻颜色不做绝对硬边界，并通过“需复核”处理歧义。

### 14.4 已保存线路可能已经过时

岩馆换点、移点或重置线路后，旧线路几何可能不再成立。系统应显示保存日期，并在大量轮廓无法与视频候选匹配时提示“墙面可能已变更”，停止自动继承线路成员。

### 14.5 过度依赖候选出现次数

被长期遮挡的真实岩点可能只出现一次。融合算法必须区分“没有检测到”和“该区域不可见”，不能把遮挡当成反证。

## 15. 完成定义

只有同时满足以下条件，才能称为“视频岩点识别准确度增强完成”：

1. 十二种快捷颜色和画面样本颜色均可使用，旧记录兼容。
2. 默认岩点结果来自多帧专项模型、配准和实例融合，而不是单一中位数背景。
3. 关联已保存线路时确实复用了用户确认轮廓和成员，并完成坐标配准。
4. 颜色只是排序和筛选证据，不会单独删除已确认岩点。
5. 用户可在姿态计费调用前完成固定岩点地图复核。
6. 叠加视频、岩点图、动作时间线和接触计算使用同一份锁定岩点地图。
7. 独立留出集达到质量、性能、内存和恢复门槛。
8. `.local/`、个人照片、视频、模型、密钥和历史数据没有被覆盖、删除或上传。

## 16. 推荐开发顺序

推荐按以下顺序推进，避免同时改变太多变量：

1. 先建立视频真值集和当前单背景基线成绩。
2. 完成十二色兼容和画面样本颜色，但暂不改岩点模型。
3. 完成多帧选帧、配准、专项推理与融合，单独证明岩点精确率和召回率提升。
4. 接入已保存线路自动/手工配准，证明人工修改数量下降。
5. 最后调整姿态帧到基准帧的坐标转换和接触容差。
6. 白名单观察通过后再替换默认链路。

该顺序能够分别回答三个核心问题：多帧是否提高“找到岩点”的能力、样本颜色是否提高“找对线路”的能力、已保存线路复用是否减少用户复核成本。
