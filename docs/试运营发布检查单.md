# 当前生产发布检查单

标签、提交 SHA、上一版本、门禁链接、维护时间、备份、验证与观察结果按 [记录模板](试运营发布记录模板.md) 登记。执行说明见 [运维手册](试运营上线运维手册.md)。

## 发布前

- [ ] 唯一基线差异全部审核，已有有效功能和设计保留
- [ ] 私密目录、真实数据、照片、数据库和密钥排除上传
- [ ] 本地后端／前端／页面验证和生产构建通过
- [ ] PR 合入 main；最终提交和新不可变标签的 release-gate 全部通过
- [ ] 当前版本与回退版本记录完整、发布前备份可完成
- [ ] 无编辑、AI 或备份任务冲突；空间足以构建和备份
- [ ] 使用 root 固定 deploy_release.sh 或已登记 root 运维包装，不手工同步

## 发布后

- [ ] current、release.env、健康 SHA 与标签提交一致
- [ ] ai-climbing 和 nginx active，正式 HTTPS 域名正常
- [ ] 未登录业务接口拒绝访问，生产调试和仿真接口关闭
- [ ] 现有授权账号的照片线路保存／重开正常
- [ ] AI 复盘真人／骨架／线路图／动作顺序保留
- [ ] 默认 0.75，主动作简短，原片时钟与导出正确
- [ ] 结束总结顺序正确并收盘，手动重开保持，重播不重复自动演示
- [ ] 桌面与手机布局正常，30 分钟观察无新增严重错误
- [ ] 结果、限制、清理／归档内容和未完成项目已登记

未实际完成的项目保持未勾选，异常按固定脚本回退程序，不恢复或删除业务数据。
