# 试运营部署包

本目录用于 1–5 人、30 天私有试运营。生产服务只能通过 Tailscale 访问，不得把 Nginx、FastAPI 或 Vite 开发端口直接暴露到公网。

## 目录内容

- `nginx/`：仅监听 `127.0.0.1:8080` 的静态站点和反向代理。
- `systemd/`：单进程后端、每日备份和五分钟健康记录。
- `scripts/`：服务器门禁、数据迁移、发布、备份、恢复、回退及每日检查。
- `env/`：不含密钥的生产配置模板。
- `tailscale/`：仅允许试运营成员访问 HTTPS 的最小权限策略示例。
- `journald/`：30 天日志保留上限。

## 安全原则

1. `/root/ai_climbing_code` 只用于 GitHub 同步和构建。
2. `/opt/ai-climbing/releases` 保存不可变程序版本。
3. `/var/lib/ai-climbing/data` 保存真实数据，发布脚本不会覆盖它。
4. `/etc/ai-climbing` 保存生产配置，权限受限且不进入 Git。
5. 数据恢复必须交互输入准确的 `确认执行`；程序回退不回退数据。
6. 每日和发布前备份必须上传并重新下载校验，缺少对象存储配置时任务失败。

完整执行顺序见 `docs/试运营上线运维手册.md`。
