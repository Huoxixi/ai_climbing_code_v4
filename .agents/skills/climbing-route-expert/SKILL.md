# climbing-route-expert

仅在用户明确要求创建线路、修改岩点或动作、评估难度时使用。

1. 先读取任务涉及的现有线路、数据结构和项目校验逻辑，不预设岩板规格或字段。
2. 检查起步、结束、手脚分配、跨度、方向变化、身体平衡和目标难度；人体工学判断应标明为经验性判断。
3. 优先使用项目现有难度模型和验证器，不虚构复用率门槛、学习效果或精度结论。
4. `backend/data/optimal_patterns.json` 只是研究参考，仅在任务确实需要历史模式时读取，不描述为运行中的强化学习。
5. 只有现有业务流程或用户任务要求时才写入线路数据或修改日志；写入后执行相应验证，不额外建立“永久记忆”。
