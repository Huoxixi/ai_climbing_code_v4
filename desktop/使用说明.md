# 攀岩 Windows 桌面版 0.1.12 重点动作与重心预览版

评语只保留有证据的高抬腿、蹬腿发力、重心调整。普通移动、微小调整与遮挡片段不写评语；点击重要动作卡片回看。视觉解释必须结合动作前后、膝部屈伸、脚位保持和身体移动过程，不能仅写“向上移动”；模型判断证据不足时可明确省略该动作。

右侧骨架白点与移动路线改为“估算重心”：按头部、躯干与四肢的质量权重计算二维投影，抬腿、伸臂都会影响位置。头、手、脚末端使用姿态点近似；未测量深度、个体质量分布或真实受力。关键关节缺失时留空，轨迹断开，不回退成躯干中心。

动作列表按本地轨迹切分的动作事件显示，相关手脚和身体描述放在同一段内。未切分出至少两个有证据的不同时间段时，不能生成收费评语。视觉返回立即保存；评语处理失败后只在本地重试，不再次发送视觉请求。相同账号、同一视频及同一分析版本复用已保存视觉返回；部分视觉请求失败时，只有明确确认费用后才请求未完成部分。

复盘视频按窗口剩余高度完整显示，真人与线路图保持相同比例。去掉全部总结卡片、结束自动弹出、总结按钮和右下角圆盘；基础数据统计直接显示在视频下方。慢放、动作回看、修正和导出继续使用。

动作评语配置统一在“设置 → AI 服务”；“设置 → 账号”显示文件存储路径。填写服务地址、模型和密钥即可生成评语。费用估算与预算在默认折叠的“高级设置”中按需启用，关闭时无需填写价格，实际费用以服务账单为准。长表单可在窗口内滚动。

这是本机桌面迁移候选包。独立干净 Windows 电脑验收和完整第三方分发材料尚待完成；先按验收记录确认可使用范围。

## 启动

完整解压 AiClimbing 文件夹，再双击 `AiClimbing.exe`。不要只复制 EXE。需要 Windows 10/11 x64、.NET Framework 4.6.2 或更新版本、Microsoft WebView2 Evergreen Runtime。程序携带 Python、分析依赖、FFmpeg、前端和字体；不需要安装 Python、Node 或 Codex。

缺少 WebView2 时会明确停止。请从微软官方网站下载安装 Evergreen Standalone Installer x64：
https://developer.microsoft.com/microsoft-edge/webview2/#download-section
离线电脑请在另一台电脑取得微软签名的完整安装程序后安装。程序不静默安装系统组件，不降级为旧 IE 播放器。

首次启动需要校验资源并打开本机服务。重复启动会唤起已有窗口。关闭窗口会停止本实例服务和子进程；未结束任务按已有恢复机制保留草稿。下次打开后查看原任务；骨架须确认全部岩点后单独点击开始，视觉 AI 评语仍须独立授权。若识别阶段正在使用原生模型，退出可能需要几秒。

## 照片与视频

照片：选择本机照片 → 原图取色／调色盘选色 → 点击识别 → 复核／补点 → 保存。上传不会自动识别。

视频：选择本机视频 → 从画面取色 → 点击“上传并识别岩点” → 逐个补点／删点 → 确认全部岩点 → 点击“开始本地分析”。0.1.7 右侧合并为一个“线路取色”面板，移除关联线路、保留与授权、视频设置及分页；点击上传主动复制原片并识别岩点。超过 90 秒的视频默认分析前 90 秒，完整原片保留。视觉 AI 评语仍需独立授权。骨架使用 RTMW-L 384×288，无姿态接口费用，无需阿里云配置。模型随包，断网可分析；优先使用 DirectML 核显／显卡，无法加速时回退本机 CPU，不调用云端替代。

原片固定保留，支持主动删除；常见竖屏分析副本 720×1280。骨架默认 10 FPS，4 FPS 可作对照，重点窗口 15／20 FPS 为实验档。结束总结提供有证据的回看重点；专业技术命名和技术调整仍待独立验证，不能认为工程接入已经证明准确率。

0.1.3 修复确认岩点后文字被挤成竖排、画面高度缩小的问题；视频和单帧缩放增加连续过渡。进入精修默认自由描边，调整顶点仍可手动选择。

0.1.5 加宽真人画面，在视频下方展示基础数据，原动作回看时间轴保留。中心路线只在结束总结的右侧线路图中显示，从四肢同时在已确认线路岩点上开始，到双手同时到达完攀点结束；未确认起攀或完攀时按页面提示显示已有证据。总结每次展示一张卡片，可切换、跳过、收起后再查看；未使用岩点在真人和线路图中同步闪烁三次后常亮。

人物选择加入线路位置与镜头配准约束，修复先跟随旁观者而错过攀爬者的问题。短时恢复需要外观、位置及连续真实观测；无法区分时留空，不用插值冒充新骨架。旧结果保留；主动完整重新分析时先确认岩点，成功后另存新版。

旧复盘、逐点草稿、已保存姿态的本地重算、重生成岩点图和导出可以在本机完成，不新增姿态或百炼请求。保留左真人／骨架与右当前用点图，默认 0.75 倍速。旧版视频页面可按保存的布局重排显示，原文件不改写。HEVC 上传前预览可能因系统解码能力不可用；请按页面提示重新加载或更换可预览的视频，取色须来自当前视频画面。

下载／导出使用窗口的保存文件对话框。请选择有写入权限的目录。旧基础视频与修订版本按原逻辑保留。

## 数据与配置

默认数据位置为 `%LOCALAPPDATA%\AiClimbing\data`，缓存位于 `cache`，临时文件位于 `tmp`，启动状态日志位于 `logs`。这与开发项目的数据完全隔离，不自动导入真实历史记录。桌面版复用原本的本地 `owner` 账号；同一 Windows 用户共享该本地账号，不要求生产邀请码。

在“设置 → AI 服务”填写兼容服务地址、模型和密钥；保存立即生效但不发送请求。费用估算与预算是“高级设置”中的可选功能，默认关闭，无价格时仍可使用模型。启用后须填写价格与预算，图片预留按服务规则设置；关闭时不承诺人民币预算上限，实际费用以服务账单为准。生成评语仍需单独授权发送动作证据并确认费用。密钥由当前 Windows 用户加密保存，不回显。历史配置文件保留，不自动迁移或调用。

## 更新、卸载与故障

更新时关闭软件，解压新程序到一个新的文件夹，打开新 EXE；用户数据仍在应用数据目录。不要在运行中覆盖程序文件。卸载解压版只需删除自己解压的程序文件夹，默认不删除素材、结果或云配置。备份可在关闭软件后复制自己的 AiClimbing 用户目录；跨 Windows 用户恢复时重新填写云配置。

资源校验失败：重新解压完整包。缺模型：从已核验来源取得与清单 SHA-256 完全一致的原权重，再按构建说明放入 `models/verified-model_final.pth`；程序不自动下载未知权重。RTMW 缺失或损坏：重新解压完整 RTMW 版本，不会自动收费回退。无视觉评语配置：仍可使用本地照片、骨架和历史复盘功能。

本候选包未签名；正式可分发性、干净环境和最低硬件配置以验收记录为准。已接入本地 RTMW 和 Windows DirectML／CPU；其他系统、自动更新及另一台电脑的性能验收尚待完成。
